# LA0279: Instance Field Requested in a Type with Explicit Layout

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The aspect "<Aspect>" applied to "<Target>" attempts to introduce an instance field <Name>of type "<FieldType>" in "<TargetType>", which has an explicit layout: an instance field introduced into it would have no offset. Introduce a static field, or declare the field in "<TargetType>" with its offset and set the WhenCompatibleFieldExists property of the IntroduceFieldAdviceInstance to Ignore.` |

## Cause

In a class or a struct with an explicit layout, `[StructLayout( LayoutKind.Explicit )]`, every instance field must have its offset, given by <xref:System.Runtime.InteropServices.FieldOffsetAttribute>. When an aspect attempts to introduce an instance field with an <xref:PostSharp.Aspects.Advices.IntroduceFieldAdviceInstance>, PostSharp cannot choose this offset for a new field. It reports LA0279 when such a request must introduce a new field: no existing field matches the request, or its <xref:PostSharp.Aspects.Advices.IntroduceFieldAdviceInstance.WhenCompatibleFieldExists> property is <xref:PostSharp.Aspects.Advices.IntroduceFieldCompatibleAction.IntroduceAnother>. A request for a static field, or a request that uses an existing field, is not affected. LA0279 is always an error.

`<Name>` is the requested name in quotes followed by a space, or nothing when the request has no name. `<Target>` is the declaration to which the aspect is applied, where the error is located.

## Resolution

* Declare the field in the type, with its offset, and make the request use it: the field must have the requested name, or the requested type when the request has no name, and <xref:PostSharp.Aspects.Advices.IntroduceFieldAdviceInstance.WhenCompatibleFieldExists> must be <xref:PostSharp.Aspects.Advices.IntroduceFieldCompatibleAction.Ignore>. With the default value, <xref:PostSharp.Aspects.Advices.IntroduceFieldCompatibleAction.Fail>, PostSharp reports <xref:la0271?text=LA0271> instead.
* Introduce a static field, with <xref:PostSharp.Aspects.Advices.IntroduceFieldAdviceInstance.IsStatic>, when one value for all the objects of the type is enough.
