# LA0179: Method Boundary Aspect Applied to a Constructor of Another Assembly

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply the aspect "<Aspect>" to the instance constructor of type "<Type>": applying OnMethodBoundaryAspect or OnExceptionAspect to an instance constructor of another assembly is not supported. Restrict the aspect to methods.` |

## Cause

An aspect can enhance the declarations of a referenced assembly when you multicast it with the <xref:PostSharp.Extensibility.MulticastAttribute.AttributeTargetAssemblies> property. PostSharp does not modify the other assembly: it replaces the calls that the current assembly makes to the target method with calls to a generated method that runs the aspect. PostSharp does not support this for constructors, and reports LA0179 when an <xref:PostSharp.Aspects.OnMethodBoundaryAspect> or an <xref:PostSharp.Aspects.OnExceptionAspect> reaches an instance constructor of another assembly.

This usually happens by default: the <xref:PostSharp.Extensibility.MulticastAttribute.AttributeTargetElements> of these aspects include the instance and static constructors, so an aspect multicast to a type of another assembly also reaches the constructors that the current assembly calls. `<Type>` is the type that declares the constructor. The message has no location in the source code.

## Resolution

* Restrict the aspect to methods: set <xref:PostSharp.Extensibility.MulticastAttribute.AttributeTargetElements> to <xref:PostSharp.Extensibility.MulticastTargets.Method>.
* When you own the library, apply the aspect in the library itself, where PostSharp can enhance the constructor.
