# LA0185: Method Interception Aspect Without OnInvokeAsync on an Async Method

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp |
| **Message** | `Semantic advising for the "<Aspect>" aspect is enabled for the "<Method>" method, but the OnInvokeAsync advice is not implemented. To suppress this message either implement the OnInvokeAsync method or set the SemanticallyAdvisedMethodKinds property of the aspect to 'None'.` |

## Cause

A <xref:PostSharp.Aspects.MethodInterceptionAspect> intercepts an async method, or a method returning an awaitable type such as <xref:System.Threading.Tasks.Task>, with its <xref:PostSharp.Aspects.MethodInterceptionAspect.OnInvokeAsync(PostSharp.Aspects.MethodInterceptionArgs)> method, which can await the end of the task. This is called semantic advising, and it is enabled by default by the <xref:PostSharp.Aspects.MethodInterceptionAspect.SemanticallyAdvisedMethodKinds> property of the aspect.

When the aspect does not override <xref:PostSharp.Aspects.MethodInterceptionAspect.OnInvokeAsync(PostSharp.Aspects.MethodInterceptionArgs)>, PostSharp falls back to <xref:PostSharp.Aspects.MethodInterceptionAspect.OnInvoke(PostSharp.Aspects.MethodInterceptionArgs)>, and reports LA0185. <xref:PostSharp.Aspects.MethodInterceptionArgs.Proceed> then returns as soon as the method returns its task, at the first `await` that does not complete synchronously, so the code after it runs before the asynchronous operation ends.

## Resolution

* Override <xref:PostSharp.Aspects.MethodInterceptionAspect.OnInvokeAsync(PostSharp.Aspects.MethodInterceptionArgs)> and await <xref:PostSharp.Aspects.MethodInterceptionArgs.ProceedAsync> in it.
* When the aspect must intercept only the call that starts the task, set <xref:PostSharp.Aspects.MethodInterceptionAspect.SemanticallyAdvisedMethodKinds> to <xref:PostSharp.Aspects.SemanticallyAdvisedMethodKinds.None> in the constructor of the aspect.
