# XAM054: Ambiguous Validation or Change Handler Method of a Dependency Property

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Xaml |
| **Message** | `Error in the [<Aspect>] aspect applied to property <Property>: type <DeclaringType> contains more than one method named "<Method>".` |

## Cause

The <xref:PostSharp.Patterns.Xaml.DependencyPropertyAttribute> and <xref:PostSharp.Patterns.Xaml.AttachedPropertyAttribute> aspects look up two methods by name in the class that declares the property:

* the validation method, named `ValidateName` by default, where `Name` is the name of the property, or named by the <xref:PostSharp.Patterns.Xaml.DependencyPropertyBaseAttribute.ValidateValueMethod> property;
* the property-changed method, named `OnNameChanged` by default, or named by the <xref:PostSharp.Patterns.Xaml.DependencyPropertyBaseAttribute.PropertyChangedMethod> property.

Each of these methods can have several signatures, so the aspect does not choose between overloads. PostSharp reports XAM054 when `<DeclaringType>` declares more than one method named `<Method>`, whatever their visibility and signatures. The validation method is looked up first.

## Resolution

Keep a single method with the name, and give the other overloads another name. If the overloads are needed for another purpose, give the handler a distinct name and set it with <xref:PostSharp.Patterns.Xaml.DependencyPropertyBaseAttribute.ValidateValueMethod> or <xref:PostSharp.Patterns.Xaml.DependencyPropertyBaseAttribute.PropertyChangedMethod>.
