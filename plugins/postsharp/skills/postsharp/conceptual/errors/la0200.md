# LA0200: Aspect Applied to an Aspect

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply the aspect "<Aspect>" to "<Target>" because "<Target>" is an aspect or a member of an aspect. The aspect is ignored.` |

## Cause

PostSharp does not apply aspects to aspects. When the target of an aspect is a type that implements <xref:PostSharp.Aspects.IAspect>, or a member of such a type, PostSharp skips the aspect. It reports LA0200 when you applied the aspect directly to this declaration with a custom attribute. When the aspect reaches an aspect class by multicasting, for example from an assembly-level attribute, PostSharp skips it silently.

`<Target>` is the aspect class, or its member that the aspect targets.
