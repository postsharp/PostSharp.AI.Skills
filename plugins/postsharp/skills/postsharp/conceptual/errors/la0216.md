# LA0216: Negative Argument Index

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [Argument(<Index>)], but the index of an argument cannot be negative.` |

## Cause

The <xref:PostSharp.Aspects.Advices.ArgumentAttribute> binding selects an argument of the target method by its index, its name or its type. An index is the zero-based position of the parameter in the target method, so it cannot be negative. In particular, `-1` does not select the last argument. PostSharp reports LA0216 on the advice parameter.

## Resolution

Select the argument in another way:

* By its name, with the <xref:PostSharp.Aspects.Advices.ArgumentAttribute.%23ctor(System.String)> constructor. The name works on target methods whose parameters are in a different order.
* By its zero-based index, with the <xref:PostSharp.Aspects.Advices.ArgumentAttribute.%23ctor(System.Int32)> constructor.
* By its type, with the parameterless constructor, when the target method has a single parameter of the type of the advice parameter.
