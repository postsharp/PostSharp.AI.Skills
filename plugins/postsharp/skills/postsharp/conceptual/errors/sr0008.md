# SR0008: Serializer of the Base Type Does Not Derive from ReferenceTypeSerializer

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply [PSerializable] to a type derived from '<BaseType>' because the serializer '<Serializer>' of '<BaseType>' does not derive from ReferenceTypeSerializer.` |

## Cause

When a [<xref:PostSharp.Serialization.PSerializableAttribute>] class derives from a class whose serializer is written by hand, the serializer that PostSharp generates for the derived class derives from the serializer of the base class. It overrides the methods that serialize and deserialize the fields, and calls the implementations of the base serializer for the fields of the base class. The serializer of a class must therefore derive from <xref:PostSharp.Serialization.ReferenceTypeSerializer>.

PostSharp reports SR0008 on `<BaseType>` when its serializer `<Serializer>` does not derive from <xref:PostSharp.Serialization.ReferenceTypeSerializer>. PostSharp takes as the serializer of `<BaseType>` the type given by its [<xref:PostSharp.Serialization.SerializerAttribute>] or, when it has no such attribute, its nested class named `Serializer`, whatever this class is.

In the following example, the serializer of `Entity` implements the <xref:PostSharp.Serialization.ISerializer> interface instead of deriving from <xref:PostSharp.Serialization.ReferenceTypeSerializer>. PostSharp also reports <xref:ar0101?text=AR0101>, because only the serializer classes of PostSharp may implement <xref:PostSharp.Serialization.ISerializer>.

## Resolution

* Derive the serializer of the base type from <xref:PostSharp.Serialization.ReferenceTypeSerializer>.
* When the base type has a nested class named `Serializer` that is not its serializer, give the base type its real serializer with [<xref:PostSharp.Serialization.SerializerAttribute>], which takes precedence over the nested class.
* Apply [<xref:PostSharp.Serialization.PSerializableAttribute>] to the base type instead of writing its serializer by hand.
