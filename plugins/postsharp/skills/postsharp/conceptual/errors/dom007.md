# DOM007: Property Depends on Too Many Fields of Its Type

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp.Patterns.Model |
| **Message** | `Property <Property> depends on more than five fields whose type is compatible with the type of the property, which makes tracking the changes of its value less efficient. To avoid this warning, split the property into several properties that each depend on fewer fields.` |

## Cause

The <xref:PostSharp.Patterns.Model.NotifyPropertyChangedAttribute> aspect binds each property to the fields that its getter reads and whose type is assignable to the type of the property: any of these fields can hold the object that the property returns. The aspect uses these bindings to notify the property when a property of the returned object changes. Each time the property is read, the aspect compares its value with every bound field to find which one holds it.

PostSharp warns with DOM007 when a property is bound to more than five fields, typically when the getter returns the first of several fields that is set. `<Property>` is the name of the property, without the name of its class. PostSharp reports the message on the property.

The warning is about performance: the property is still notified correctly.

## Resolution

Split the property into several properties that each read at most five of the fields, and make the original property depend on these properties. Alternatively, ignore the warning when the property does not change often.
