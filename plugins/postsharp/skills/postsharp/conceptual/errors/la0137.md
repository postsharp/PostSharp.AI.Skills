# LA0137: Dynamic Advice Bound to a Member Outside the Aspect

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Error in dynamic advice <AdviceType> provided by the IAdviceProvider implementation of aspect "<Aspect>" applied to "<Target>": "<Member>" is not declared in the aspect type.` |

## Cause

An aspect that implements <xref:PostSharp.Aspects.Advices.IAdviceProvider> returns advices from its <xref:PostSharp.Aspects.Advices.IAdviceProvider.ProvideAdvices(System.Object)> method. Some of these advices refer to a member of the aspect class: an <xref:PostSharp.Aspects.Advices.ImportLocationAdviceInstance> or an <xref:PostSharp.Aspects.Advices.ImportMethodAdviceInstance> stores the imported member in a field of the aspect, and an <xref:PostSharp.Aspects.Advices.IntroduceMethodAdviceInstance> copies a method of the aspect into the target class. PostSharp reports LA0137 when this member, `<Member>`, is not declared in the aspect class or in one of its base classes, for example when it is a field of the target class.

`<AdviceType>` is the class of the advice, and `<Target>` the declaration to which the aspect is applied. PostSharp reports the message on the aspect class, once for each faulty advice, and skips these advices.

## Resolution

Pass a member of the aspect class where the advice expects one: for an import advice, the field of the aspect that receives the imported member, which you get with `typeof(MyAspect).GetField( ... )`, and the member of the target class as the location or method to import. For an introduction, pass a public method of the aspect.
