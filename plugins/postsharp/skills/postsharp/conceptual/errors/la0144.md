# LA0144: Advice Method Does Not Return Void

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Advice "<Advice>" is not valid on method "<Method>": method return type must be void.` |

## Cause

PostSharp calls an advice method from the code that it weaves into the target, and ignores what the method returns. To change the return value of the target, an advice sets the `ReturnValue` property of its argument instead. For this reason, the following advices require their method to return `void`:

* <xref:PostSharp.Aspects.Advices.OnMethodEntryAdvice>, <xref:PostSharp.Aspects.Advices.OnMethodSuccessAdvice>, <xref:PostSharp.Aspects.Advices.OnMethodExceptionAdvice>, <xref:PostSharp.Aspects.Advices.OnMethodExitAdvice>, <xref:PostSharp.Aspects.Advices.OnMethodYieldAdvice> and <xref:PostSharp.Aspects.Advices.OnMethodResumeAdvice>;
* <xref:PostSharp.Aspects.Advices.OnMethodInvokeAdvice>;
* <xref:PostSharp.Aspects.Advices.OnLocationGetValueAdvice>, <xref:PostSharp.Aspects.Advices.OnLocationSetValueAdvice> and <xref:PostSharp.Aspects.Advices.OnInstanceLocationInitializedAdvice>;
* <xref:PostSharp.Aspects.Advices.OnEventAddHandlerAdvice>, <xref:PostSharp.Aspects.Advices.OnEventRemoveHandlerAdvice> and <xref:PostSharp.Aspects.Advices.OnEventInvokeHandlerAdvice>.

PostSharp reports LA0144 on the advice method when it returns another type. `<Advice>` is the type of the advice custom attribute. <xref:PostSharp.Aspects.Advices.OnMethodInvokeAsyncAdvice> is the exception: its method must return a <xref:System.Threading.Tasks.Task>, and PostSharp reports <xref:la0165?text=LA0165> otherwise.
