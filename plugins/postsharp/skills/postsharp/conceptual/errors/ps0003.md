# PS0003: Configuration File Cannot Be Read

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Invalid configuration file: <Reason>` |

## Cause

PostSharp reads every `postsharp.config` file from the directory of the project up to the root of the drive, and every configuration file that a `Using` element imports. See <xref:configuration-system>. PostSharp reports PS0003, and stops building the project, when it cannot read one of these files:

* The file is not well-formed XML: an element is not closed, an attribute value has no quotes, or a character is not escaped. `<Reason>` is the message of the XML parser, with the line and the position of the problem.
* The root element of the file is not a `Project` element in the namespace `http://schemas.postsharp.org/1.0/configuration`. `<Reason>` gives the name and the namespace of the root element that PostSharp found. When the root element has no namespace, the namespace is empty in the message.

The location of the message is the configuration file, not a line of your code.

## Resolution

* Make sure that the root element of the file is `<Project xmlns="http://schemas.postsharp.org/1.0/configuration">`. See <xref:configuration-schema> for the elements that it can contain.
* When the message reports an XML error, open the file at the line and the position that the message gives, and correct the XML. An XML editor, such as the one of Visual Studio, shows the error as you type.
* When the file is not a PostSharp configuration file, rename it or move it: PostSharp reads every file named `postsharp.config` in the directory of the project and in its parent directories.
