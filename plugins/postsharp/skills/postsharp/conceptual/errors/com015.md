# COM015: Relationship Attribute on the Backing Field of an Automatic Property

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp.Patterns.Aggregation |
| **Message** | `The [<Attribute>] attribute applied to the backing field of the automatic property <Property> has no effect, because the relationship of an automatic property is read from the property. Apply the attribute to the property, not to its backing field, or set the <MSBuildProperty> MSBuild property to True to read the annotations of an automatic property and of its backing field as one.` |

## Cause

The <xref:PostSharp.Patterns.Model.AggregatableAttribute> aspect reads the relationship of an automatic property from the attributes of the property, and ignores the attributes that the `field:` target applies to its backing field. PostSharp reports COM015 when one of the relationship attributes, <xref:PostSharp.Patterns.Model.ChildAttribute>, <xref:PostSharp.Patterns.Model.ParentAttribute> or <xref:PostSharp.Patterns.Model.ReferenceAttribute>, is on the backing field and:

* the property has no relationship attribute, or
* the property has the same attribute, so the attribute of the field is redundant.

When the property has no attribute and its type requires one, the `[Aggregatable]` aspect also reports the error <xref:com002?text=COM002>, except in a class with a threading model, which reports <xref:com014?text=COM014> for collections only.

`<MSBuildProperty>` is `PostSharpUnifiedAutomaticPropertyAnnotations`. Other cases are reported by <xref:com016?text=COM016> (a `[field: Reference]` on a read-only property), <xref:com017?text=COM017> (another attribute on the property) and <xref:com018?text=COM018> (a property of a string or value type).

## Resolution

* Apply the attribute to the property rather than to its backing field: remove the `field:` target.
* Alternatively, set the `PostSharpUnifiedAutomaticPropertyAnnotations` MSBuild property to `True` in the project. PostSharp then reads the attributes of an automatic property and of its backing field as one set.
