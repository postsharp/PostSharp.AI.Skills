# COM007: IsParentSurrogate Value Not Valid for the Type of the Member

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Common |
| **Message** | `Invalid [Child] custom attribute on <Member>: the value of the IsParentSurrogate property is not valid for the type of this field or property. Remove the IsParentSurrogate property to let PostSharp choose the relationship from the type.` |

## Cause

A field or property with the <xref:PostSharp.Patterns.Model.ChildAttribute> attribute is either a child of the instance or a parent surrogate. A parent surrogate, typically a collection, passes the instance on as the parent of its own items: the items are the children of the instance, not of the collection. The <xref:PostSharp.Patterns.Model.ChildAttribute.IsParentSurrogate> property chooses between the two: `true` for a parent surrogate, `false` for a child. When you do not set it, PostSharp chooses from the type of the field or property.

Some types can have only one of the two relationships. For example, an `ImmutableArray<T>` is a value type, so it cannot be a child, only a parent surrogate. PostSharp reports COM007 when <xref:PostSharp.Patterns.Model.ChildAttribute.IsParentSurrogate> requests a relationship that the type of the field or property cannot have.
