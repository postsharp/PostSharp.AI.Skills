# LA0224: Binding Not Supported in an Instance Constructed Advice

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by <Binding>, which a method annotated with [OnInstanceConstructedAdvice] does not support.` |

## Cause

An advice method annotated with <xref:PostSharp.Aspects.Advices.OnInstanceConstructedAdvice> runs once an object of the target type is constructed, whichever constructor ran. It runs in a method without parameters, and its target is the type, not a method. It therefore has no argument, no return value, no field or property value and no control flow to change. When a parameter of this advice is bound by <xref:PostSharp.Aspects.Advices.ArgumentAttribute>, <xref:PostSharp.Aspects.Advices.ReturnValueAttribute>, <xref:PostSharp.Aspects.Advices.LocationValueAttribute> or <xref:PostSharp.Aspects.Advices.FlowBehaviorAttribute>, PostSharp reports LA0224 on the parameter.

`<Binding>` is the binding attribute as you wrote it, such as `[Argument("name")]`. The other binding attributes that this advice does not accept report <xref:la0151?text=LA0151>.

## Resolution

* Receive the constructed object with a <xref:PostSharp.Aspects.Advices.ThisAttribute> parameter, and read the values that the constructor stored in it.
* To receive the arguments of a constructor, apply a method-level aspect to the constructor instead, with an <xref:PostSharp.Aspects.Advices.OnMethodEntryAdvice> or <xref:PostSharp.Aspects.Advices.OnMethodSuccessAdvice> that binds them with <xref:PostSharp.Aspects.Advices.ArgumentAttribute>.
