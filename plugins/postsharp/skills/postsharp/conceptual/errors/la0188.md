# LA0188: Advice Requires Async Support That the Target Framework Lacks

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply the advice "<Advice>" to method "<Method>": this advice must be applied semantically to any method returning Task, but the target framework does not support async calls. You can suppress this error message by setting the UnsupportedTargetAction property on the master advice.` |

## Cause

By default, the advices derived from <xref:PostSharp.Aspects.Advices.OnMethodBoundaryAdvice>, such as <xref:PostSharp.Aspects.Advices.OnMethodEntryAdvice> and <xref:PostSharp.Aspects.Advices.OnMethodExitAdvice>, advise the methods that return an awaitable type semantically: they run when the task starts, completes or fails, not when the method returns the task. When the target method is not an `async` method, the C# compiler has not generated a state machine for it, so PostSharp generates one. The <xref:PostSharp.Aspects.SemanticallyAdvisedMethodKinds.ReturnsAwaitable> flag of the <xref:PostSharp.Aspects.Advices.OnMethodBoundaryAdvice.SemanticallyAdvisedMethodKinds> property of the master advice enables this behavior.

The generated state machine uses the `System.Runtime.CompilerServices.TaskAwaiter` type. PostSharp reports LA0188 when the target framework of the project does not define this type, which is the case of .NET Framework 4.0 and earlier, and when the <xref:PostSharp.Aspects.Advices.OnMethodBoundaryAdvice.UnsupportedTargetAction> property of the master advice is <xref:PostSharp.Aspects.UnsupportedTargetAction.Fail>, the default. Methods that return an enumerable type do not need async support and do not report the message. `<Advice>` is the master advice method of the aspect. Aspects derived from <xref:PostSharp.Aspects.OnMethodBoundaryAspect> report <xref:la0187?text=LA0187> in the same situation.

Every target framework that PostSharp supports defines `TaskAwaiter`, so no example can show this message.

## Resolution

* Target a framework that supports async methods: .NET Framework 4.5 or later, .NET Standard or .NET.
* Set the <xref:PostSharp.Aspects.Advices.OnMethodBoundaryAdvice.UnsupportedTargetAction> property of the master advice to <xref:PostSharp.Aspects.UnsupportedTargetAction.Fallback>, to advise the method as a plain method, or to <xref:PostSharp.Aspects.UnsupportedTargetAction.Ignore>, to skip it.
* Remove <xref:PostSharp.Aspects.SemanticallyAdvisedMethodKinds.ReturnsAwaitable> from the <xref:PostSharp.Aspects.Advices.OnMethodBoundaryAdvice.SemanticallyAdvisedMethodKinds> property of the master advice.
