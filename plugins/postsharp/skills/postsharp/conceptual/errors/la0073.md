# LA0073: Copied Custom Attribute Already Exists on the Target

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot copy custom attribute "<AttributeType>" to "<Target>" because "<Target>" already has a custom attribute of the same type. Set the OverrideAction property of [CopyCustomAttributes] to ignore, add or merge the attribute instead.` |

## Cause

An aspect member annotated with <xref:PostSharp.Aspects.Advices.IntroduceMemberAttribute> and <xref:PostSharp.Aspects.Advices.CopyCustomAttributesAttribute> copies the custom attributes of the given types from the aspect member to the introduced member. When the target type already defines the member and the introduction overrides it, for example with <xref:PostSharp.Aspects.Advices.MemberOverrideAction.OverrideOrFail>, PostSharp copies the attributes to the existing member, which can already have an attribute of the same type.

PostSharp then follows the <xref:PostSharp.Aspects.Advices.CopyCustomAttributesAttribute.OverrideAction> of the copy. Its default value, <xref:PostSharp.Aspects.Advices.CustomAttributeOverrideAction.Fail>, reports LA0073 instead of adding a second attribute, which most attribute types do not allow, or replacing the attribute that you wrote.

`<Target>` is the member that already has the attribute. PostSharp reports the error on this member.

## Resolution

Choose what PostSharp does when the attribute already exists, with the <xref:PostSharp.Aspects.Advices.CopyCustomAttributesAttribute.OverrideAction> property of <xref:PostSharp.Aspects.Advices.CopyCustomAttributesAttribute>:

* <xref:PostSharp.Aspects.Advices.CustomAttributeOverrideAction.Ignore> keeps the existing attribute and does not copy the attribute of the aspect.
* <xref:PostSharp.Aspects.Advices.CustomAttributeOverrideAction.MergeAddProperty> adds the named properties and fields of the copied attribute to the existing one, and keeps those that the existing attribute already sets.
* <xref:PostSharp.Aspects.Advices.CustomAttributeOverrideAction.MergeReplaceProperty> also merges the two attributes, but the values of the copied attribute replace those of the existing one. Both merge actions ignore the constructor arguments of the copied attribute.
* <xref:PostSharp.Aspects.Advices.CustomAttributeOverrideAction.Add> adds the copied attribute as a second one. Use it only for an attribute type that allows multiple instances.

Otherwise, remove the attribute from the existing member, or exclude its type from the types that the aspect copies.
