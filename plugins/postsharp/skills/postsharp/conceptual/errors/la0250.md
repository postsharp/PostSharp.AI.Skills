# LA0250: Compatibility Level Not Set for OnYield and OnResume Exceptions

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp |
| **Message** | `An exception thrown by the OnYield or OnResume advice of the aspect "<Aspect>" in the async method "<Method>" follows the behavior of PostSharp 2026.0: it skips the catch and finally blocks around the await and the OnExit advices. Set the MSBuild property PostSharpCompatibilityLevel to 2027.0 to let it flow as an exception of the await expression, or to 2026.0 to keep this behavior without this warning.` |

## Cause

Since PostSharp 2027.0, the path of an exception thrown by the <xref:PostSharp.Aspects.OnMethodBoundaryAspect.OnYield(PostSharp.Aspects.MethodExecutionArgs)> or <xref:PostSharp.Aspects.OnMethodBoundaryAspect.OnResume(PostSharp.Aspects.MethodExecutionArgs)> advice of an `async` method depends on the `PostSharpCompatibilityLevel` MSBuild property:

* At `2027.0` or higher, the exception flows through the method as an exception of the `await` expression, so the `catch` and `finally` blocks of the method and the `OnExit` advices run.
* Below `2027.0`, or when the property is not set, the exception keeps the behavior of PostSharp 2026.0: it skips the `catch` and `finally` blocks around the `await` and the `OnExit` advices, and faults the task.

When the property is not set, PostSharp keeps the previous behavior and reports LA0250, so that you choose one. It reports the warning on the `async` method, once per aspect type that has an `OnYield` or `OnResume` advice applied to an `async` method, including the aspects of the Pattern Libraries. The behavior is the same whether the compiler implements the method with a state machine or with runtime async. The warning is reported whether or not the advices throw.

## Resolution

Set the `PostSharpCompatibilityLevel` MSBuild property in your project, or for all the projects of a directory in a `Directory.Build.props` file:

```xml
<PropertyGroup>
  <PostSharpCompatibilityLevel>2027.0</PostSharpCompatibilityLevel>
</PropertyGroup>
```

* Set it to `2027.0` to adopt the new behavior. An aspect must then tolerate that the method continues after its `OnYield` or `OnResume` advice throws, because the user code can catch the exception.
* Set it to `2026.0` to keep the previous behavior without the warning.
