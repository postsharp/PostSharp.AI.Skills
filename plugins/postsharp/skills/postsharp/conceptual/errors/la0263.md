# LA0263: No Method Converts to the Delegate Type of a Required Imported Member

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [ImportMember] with IsRequired set to true, but no method "<Method>" of the type "<TargetType>" converts to the delegate type "<DelegateType>". The first parameter of the delegate receives the object of an instance method, by reference for a struct (in for any method, ref for a method that is not readonly). The other parameters must convert to the parameters of the method, and the return type of the method to the return type of the delegate, by an identity or reference conversion.` |

## Cause

An advice parameter of a delegate type, marked with <xref:PostSharp.Aspects.Advices.ImportMemberAttribute> and a method name, receives an open delegate of a method of the target type. PostSharp selects the method as C# converts a method group to a delegate type:

* For an instance method, the first parameter of the delegate receives the object. For a struct, it must be `in`, or `ref` for a method that is not `readonly`.
* The other parameters of the delegate must convert to the parameters of the method, with the same `ref`, `out` or `in` modifier.
* The return type of the method must convert to the return type of the delegate.

Only identity and reference conversions are allowed. A numeric conversion, such as `int` to `long`, or a boxing conversion, such as `int` to `object`, does not make a method convert.

When no method of this name converts to the delegate type and <xref:PostSharp.Aspects.Advices.ImportMemberAttribute.IsRequired> is `true`, PostSharp reports LA0263 on the target method. PostSharp also reports it when the advice is generic and the method selected for the delegate requires type arguments that contradict those that the other parameters of the advice infer.

## Resolution

* Change the delegate type so that its parameter types and its return type match those of the method.
* If the parameter is optional, set <xref:PostSharp.Aspects.Advices.ImportMemberAttribute.IsRequired> to `false`, its default value: the parameter then receives `null` when no method converts.
* In a type-level aspect whose target types do not all define a suitable method, select the targets with <xref:PostSharp.Aspects.Advices.MatchPointcut>, which skips the targets that the advice does not fit instead of reporting an error.
