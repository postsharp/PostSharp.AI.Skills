# LA0143: Initialization Advice Has an Invalid Signature

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Method "<Method>" must have the signature "void Method(AspectInitializationReason)" because it is annotated with [InitializeAspectInstanceAdvice] or [OnAspectsInitializedAdvice].` |

## Cause

The <xref:PostSharp.Aspects.Advices.InitializeAspectInstanceAdvice> and <xref:PostSharp.Aspects.Advices.OnAspectsInitializedAdvice> advices make PostSharp call a method of the aspect when the aspect instance is initialized, and pass it the reason of the initialization: a constructor, a call of `MemberwiseClone`, deserialization, or a manual initialization. PostSharp calls this method with a single argument of type <xref:PostSharp.Aspects.Advices.AspectInitializationReason>, so the method must take exactly one parameter of this type and return `void`.

PostSharp reports LA0143 on the advice method when it has no parameter, more than one parameter, a parameter of another type, or a return type other than `void`. `<Method>` is the advice method.

## Resolution

Give the advice method the signature `void Method(AspectInitializationReason)`: make it return `void`, and declare one parameter of type <xref:PostSharp.Aspects.Advices.AspectInitializationReason>, even if the method does not use it. The method must also be public, or PostSharp reports <xref:la0087?text=LA0087>.
