# PS0166: Unknown Field or Property in a Configuration File

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The type '<Type>' does not have a public field or property named '<Name>'.` |

## Cause

In some sections of a PostSharp configuration file, such as the `Multicast` section and the logging profiles, each XML element describes a CLR object, and each XML attribute of the element sets a field or a property of this object. In the logging profiles, a child element can also set a field or a property.

PostSharp reports PS0166 when `<Type>` has no field or property named `<Name>`, or when the field or property is not public. Names are case-sensitive. PostSharp skips the attribute and goes on with the others, but the build fails.

## Resolution

* Correct the name of the attribute so that it matches the name of the field or property exactly, with its case.
* When the field or property is not public, make it public, or remove the attribute.
