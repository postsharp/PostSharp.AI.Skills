# LA0225: Argument Index Out of Range

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [Argument(<Index>)], but "<TargetMethod>" has no parameter at this index.` |

## Cause

The <xref:PostSharp.Aspects.Advices.ArgumentAttribute.%23ctor(System.Int32)> constructor binds a parameter of an advice to the argument at a zero-based index in the parameter list of the target method. PostSharp checks the index for each target method of the advice. When the index is not lower than the number of parameters of a target method, it reports LA0225 on that method. A negative index reports <xref:la0216?text=LA0216> instead, whatever the target.

The same aspect often applies to methods whose parameters differ, for example through multicasting. An index that is valid for one target can then be out of range for another one. When the advice uses a pointcut that skips the targets whose signature does not match, such as <xref:PostSharp.Aspects.Advices.MatchPointcut>, PostSharp skips the target instead of reporting the error.

## Resolution

* Select the argument by its name with <xref:PostSharp.Aspects.Advices.ArgumentAttribute.%23ctor(System.String)>, or by its type with the constructor without parameters, so that its position does not matter.
* Otherwise, apply the aspect only to methods that have a parameter at this index.
