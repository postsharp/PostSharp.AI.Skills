# LA0142: Instance Constructed Advice Returns a Value

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Method "<Method>" must have no return type because it is annotated by the advice [OnInstanceConstructedAdvice].` |

## Cause

A method of an aspect annotated with <xref:PostSharp.Aspects.Advices.OnInstanceConstructedAdvice> runs once an instance of the target class is constructed, whichever constructor ran. PostSharp has no use for a value returned by this advice, so the method must return `void`. PostSharp reports LA0142 on the method, `<Method>`, when it returns anything else.

## Resolution

Change the return type of the method to `void`. When other code needs the value that the method computed, store it in a field or a property of the aspect instead. The method must also be public, or PostSharp reports <xref:la0087?text=LA0087>.
