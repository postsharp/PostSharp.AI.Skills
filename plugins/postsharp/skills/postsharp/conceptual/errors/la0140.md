# LA0140: Invalid Type of a Field Bound by a Dynamic Import Advice

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Type of field "<Field>" is invalid. Valid types for fields bound to an ImportLocationAdviceInstance or an ImportMethodAdviceInstance are: Delegate, Event<T>, Property<TValue>, Property<TValue,TIndex>, ILocationBinding, or a class that implements ICollection<ILocationBinding> and has a public default constructor.` |

## Cause

An aspect that implements <xref:PostSharp.Aspects.Advices.IAdviceProvider> imports members of its target class into its own fields with an <xref:PostSharp.Aspects.Advices.ImportLocationAdviceInstance> or an <xref:PostSharp.Aspects.Advices.ImportMethodAdviceInstance>. The type of the aspect field, `<Field>`, tells PostSharp what to assign at run time: a delegate for a method, <xref:PostSharp.Aspects.Advices.Event`1> for an event, <xref:PostSharp.Aspects.Advices.Property`1> or <xref:PostSharp.Aspects.Advices.Property`2> for a property, <xref:PostSharp.Aspects.ILocationBinding> for a field or a property, or a collection that receives one <xref:PostSharp.Aspects.ILocationBinding> per advice. PostSharp reports LA0140 in two cases:

* The field has another type. PostSharp then reports the message on the aspect class.
* The field is a collection of <xref:PostSharp.Aspects.ILocationBinding>, but its type has no public default constructor, for example the interface `IList<ILocationBinding>`. PostSharp creates the collection with this constructor before it adds the bindings. It then reports the message on the aspect field.

With <xref:PostSharp.Aspects.Advices.ImportMemberAttribute>, the same mistake causes <xref:la0074?text=LA0074>.

## Resolution

Give the aspect field a supported type: <xref:PostSharp.Aspects.ILocationBinding> to import one field or property, a class such as `List<ILocationBinding>` to import several of them with one advice each, or a delegate, <xref:PostSharp.Aspects.Advices.Event`1> or <xref:PostSharp.Aspects.Advices.Property`1> for the other kinds of members.
