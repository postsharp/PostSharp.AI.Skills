# DIA003: Execution Time Threshold Ignored Because of the Log Levels

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp.Patterns.Diagnostics |
| **Message** | `The execution time threshold of the logging profile is ignored for method '<Method>' because the level of its default options (<DefaultLevel>) is higher than the level of its exception options, which is the level of slow executions. Set the level of the exception options to <DefaultLevel> or higher, or remove the ExecutionTimeThreshold of the profile.` |

## Cause

The <xref:PostSharp.Patterns.Diagnostics.LoggingProfile.ExecutionTimeThreshold> property of a logging profile, in `postsharp.config`, sets a time in milliseconds. When a method takes longer than that, the logging aspect logs its success with the level of the <xref:PostSharp.Patterns.Diagnostics.LoggingProfile.ExceptionOptions> of the profile, instead of the level of its <xref:PostSharp.Patterns.Diagnostics.LoggingProfile.DefaultOptions>, so that slow executions stand out like exceptions.

This works only when the level of the exception options is at least the level of the default options. When the <xref:PostSharp.Patterns.Diagnostics.LoggingOptions.Level> of the default options is higher, a slow execution would be logged at a lower level than a normal one. PostSharp then ignores the threshold for the method, logs it as if the profile had no threshold, and reports DIA003 on each method that uses the profile. `<DefaultLevel>` is the level of the default options of the profile.

## Resolution

* Set the level of the exception options to the level of the default options or higher. `Warning`, the level of the exception options of a profile that does not set it, makes slow executions stand out.
* Lower the level of the default options.
* When you do not need to detect slow executions, remove the `ExecutionTimeThreshold` attribute of the profile.
