# XAM072: Command Has Both a CanExecute Method and a CanExecute Property

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Xaml |
| **Message** | `Error in the [Command] aspect applied to property <Property>: the CanExecuteMethod and CanExecuteProperty properties cannot both be set.` |

## Cause

The <xref:PostSharp.Patterns.Xaml.CommandAttribute> aspect implements the <xref:System.Windows.Input.ICommand.CanExecute(System.Object)> method of the command with a single member of the class: either a method or a property. When you set both the <xref:PostSharp.Patterns.Xaml.CommandAttribute.CanExecuteMethod> and the <xref:PostSharp.Patterns.Xaml.CommandAttribute.CanExecuteProperty> properties of the aspect, it cannot tell which one to use, and reports XAM072 on the command property. The aspect checks this before it looks for the two members, so the message does not depend on whether they exist.

## Resolution

Set only one of the two properties:

* Use <xref:PostSharp.Patterns.Xaml.CommandAttribute.CanExecuteMethod> when the availability of the command depends on the command parameter: the method can have one parameter.
* Use <xref:PostSharp.Patterns.Xaml.CommandAttribute.CanExecuteProperty> otherwise. In a class with the <xref:PostSharp.Patterns.Model.NotifyPropertyChangedAttribute> aspect, the command then raises its <xref:System.Windows.Input.ICommand.CanExecuteChanged> event when the property changes.
