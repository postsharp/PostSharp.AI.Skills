# CAC003: Invalidating Method Cannot Supply the Instance of the Cached Method

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Caching |
| **Message** | `The [InvalidateCache] aspect applied to <InvalidatingMethod> cannot invalidate <CachedMethod>: the 'this' parameter cannot be mapped because <CachedMethod> is an instance method, the IgnoreThisParameter property of its [Cache] or [CacheConfiguration] attribute is not set to true, and <InvalidatingMethod> is static or its declaring type <InvalidatingType> is not derived from <CachedType>.` |

## Cause

By default, the cache key of an instance method includes the `this` instance, so that two objects do not share their cached values. To remove a value from the cache, the <xref:PostSharp.Patterns.Caching.InvalidateCacheAttribute> aspect must rebuild the same key from the call to the invalidating method, `<InvalidatingMethod>`, and it uses the `this` instance of this call as the `this` instance of the cached method, `<CachedMethod>`. This only works when the invalidating method is an instance method of the type of the cached method, `<CachedType>`, or of a type derived from it.

PostSharp therefore reports CAC003, on `<InvalidatingMethod>`, when all of the following are true:

* `<CachedMethod>` is an instance method;
* the <xref:PostSharp.Patterns.Caching.CacheAttribute.IgnoreThisParameter> property is not set to `true`, neither on the <xref:PostSharp.Patterns.Caching.CacheAttribute> aspect of `<CachedMethod>` nor on a <xref:PostSharp.Patterns.Caching.CacheConfigurationAttribute> of its type, its base types or its assembly;
* `<InvalidatingMethod>` is static, or its declaring type, `<InvalidatingType>`, is not derived from `<CachedType>`.

## Resolution

* If the value of the cached method does not depend on the instance, exclude the instance from the cache key: set the <xref:PostSharp.Patterns.Caching.CacheAttribute.IgnoreThisParameter> property of the `[Cache]` aspect to `true`, or set the <xref:PostSharp.Patterns.Caching.CacheConfigurationAttribute.IgnoreThisParameter> property of a `[CacheConfiguration]` attribute on the type or the assembly.
* If the value depends on the instance, move the invalidating method into the type of the cached method, or into a derived type, as an instance method.
* Otherwise, remove the `[InvalidateCache]` aspect and invalidate the value imperatively with <xref:PostSharp.Patterns.Caching.CachingServices.Invalidation>, passing the instance of the cached method.
