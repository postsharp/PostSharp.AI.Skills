# LA0218: Required Instance on a Static Target

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [This] with IsRequired set to true, but "<Target>" is static.` |

## Cause

A parameter of an advice annotated with <xref:PostSharp.Aspects.Advices.ThisAttribute> receives the instance of the target, that is, the `this` object of the method, field or property. A static target has no instance, so the parameter normally receives `null`, or the default value of its type. When <xref:PostSharp.Aspects.Advices.ThisAttribute.IsRequired> is `true`, the advice states that it needs an instance, and PostSharp reports LA0218 for each static target of the advice instead of passing `null`.

The message is reported on the static target. It is often a member that the aspect reaches by multicasting, when the aspect is applied to a whole type.

## Resolution

* Exclude the static members from the targets of the aspect, for example with the <xref:PostSharp.Extensibility.MulticastAttribute.AttributeTargetMemberAttributes> property set to <xref:PostSharp.Extensibility.MulticastAttributes.Instance>.
* Remove the aspect from the static member, when you applied it explicitly.
* When the advice can work without an instance, set <xref:PostSharp.Aspects.Advices.ThisAttribute.IsRequired> to `false`, which is the default, and handle a `null` instance in the advice.
