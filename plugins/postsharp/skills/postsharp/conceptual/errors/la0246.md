# LA0246: Declaration Parameter of the Wrong Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is of type "<ParameterType>", which cannot receive the reflection object bound by [Declaration] in this kind of advice. The parameter must be of one of these types: <ValidTypes>.` |

## Cause

A [<xref:PostSharp.Aspects.Advices.DeclarationAttribute>] parameter receives the reflection object of the target of the advice. Its type depends on the kind of advice:

* In a method boundary or method interception advice, a <xref:System.Reflection.MethodBase>, which is a <xref:System.Reflection.MethodInfo> for a method and a <xref:System.Reflection.ConstructorInfo> for a constructor.
* In a location advice, a <xref:PostSharp.Reflection.LocationInfo>, or the <xref:System.Reflection.PropertyInfo> of the property. A <xref:System.Reflection.FieldInfo> is not accepted: PostSharp encapsulates an intercepted field into a property, so the target is a property at run time.
* In an <xref:PostSharp.Aspects.Advices.OnInstanceConstructedAdvice>, the <xref:System.Type> of the instance.

PostSharp reports LA0246 when the type `<ParameterType>` of the parameter `<Parameter>` can receive none of these objects. `<ValidTypes>` lists the types accepted in the advice `<Advice>`; a base type of one of them, such as <xref:System.Reflection.MemberInfo> or <xref:System.Object>, is also accepted.
