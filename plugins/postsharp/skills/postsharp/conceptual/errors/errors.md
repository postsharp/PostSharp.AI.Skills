# Errors and Warnings

PostSharp reports errors and warnings at build time, like the C# compiler. Each message has an identifier made of a prefix and a number, such as `LA0250`. The prefix tells which component reports the message:

| Prefix | Reported by |
|---|---|
| `PS` | The PostSharp compiler: configuration, licensing, the build process. |
| `LA` | The aspect framework of PostSharp. |
| `SR` | The serialization of aspects. |
| `AR` | Architecture constraints. |
| `COM` | PostSharp.Patterns.Aggregation and the common patterns. |
| `DOM` | PostSharp.Patterns.Model. |
| `THR` | PostSharp.Patterns.Threading. |
| `XAM` | PostSharp.Patterns.Xaml. |
| `CAC` | PostSharp.Patterns.Caching. |
| `DIA` | PostSharp.Patterns.Diagnostics. |

Each article explains when the message is reported and how to resolve it. Most articles also include an example that reports the message and the same example fixed. Some messages depend on the license, the machine or the build environment, or cannot be reached by ordinary code, so no example can reproduce them: their articles say why, and give the resolution steps. To ignore a warning or turn it into an error, see <xref:ignoring-warnings>.
