# LA0272: Requested Field Name Taken by Another Member

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The aspect "<Aspect>" applied to "<Target>" attempts to introduce a field <Name>of type "<FieldType>" in "<TargetType>", but the member "<Member>" has this name and is not a field of this type and kind. Choose another name, or set the WhenIncompatibleMemberExists property of the IntroduceFieldAdviceInstance to IntroduceAnother to introduce a field whose name is the requested name followed by a number.` |

## Cause

An aspect attempts to introduce a field in its target type by returning an <xref:PostSharp.Aspects.Advices.IntroduceFieldAdviceInstance> with a <xref:PostSharp.Aspects.Advices.IntroduceFieldAdviceInstance.Name>. PostSharp looks for a member of this name in the target type, then in the accessible members of its base types. LA0272 is reported when the first member that has the name cannot hold the requested value:

* a property, an event or a method;
* a field of another type, or a static field when the request is for an instance field, or the reverse;
* a constant, which has no storage.

The request can neither use this member nor introduce a field of the same name when its <xref:PostSharp.Aspects.Advices.IntroduceFieldAdviceInstance.WhenIncompatibleMemberExists> property is <xref:PostSharp.Aspects.Advices.IntroduceFieldIncompatibleAction.Fail>, the default value. This property applies only to a request that has a name: a request without a name finds fields by their type. LA0272 is always an error.

`<Name>` is the requested name in quotes followed by a space. `<Target>` is the declaration to which the aspect is applied, where the error is located, and `<Member>` is the member that has the name.

## Resolution

* To use an existing field, request it by its own name, with <xref:PostSharp.Aspects.Advices.IntroduceFieldAdviceInstance.WhenCompatibleFieldExists> set to <xref:PostSharp.Aspects.Advices.IntroduceFieldCompatibleAction.Ignore>.
* To give the aspect a field of its own, choose a name that no member has, or set <xref:PostSharp.Aspects.Advices.IntroduceFieldAdviceInstance.WhenIncompatibleMemberExists> to <xref:PostSharp.Aspects.Advices.IntroduceFieldIncompatibleAction.IntroduceAnother>. With this action, the new field gets the requested name followed by a number, such as `CallCount2`, and the advices of the aspect still import it by the requested name.
