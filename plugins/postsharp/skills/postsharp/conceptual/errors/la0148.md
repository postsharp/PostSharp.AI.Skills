# LA0148: Aspect Role Dependency Has No Role

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Invalid value for AspectRoleDependencyAttribute: the "role" parameter value cannot be null or empty.` |

## Cause

The <xref:PostSharp.Aspects.Dependencies.AspectRoleDependencyAttribute> custom attribute declares a dependency between the aspect that it is applied to and the aspects or advices of a role, such as ordering them or forbidding them on the same target. The dependency matches the aspects and advices that are enrolled in the role with <xref:PostSharp.Aspects.Dependencies.ProvideAspectRoleAttribute>, by its name. A dependency without a name matches nothing, so PostSharp reports LA0148 when the `role` argument is `null` or an empty string.

PostSharp reports the message without a location, and the message does not name the aspect. Look for an <xref:PostSharp.Aspects.Dependencies.AspectRoleDependencyAttribute> whose role is empty, or comes from a constant or an expression that is empty, on the aspects that the project uses.

## Resolution

Pass the name of a role to the attribute, preferably a constant of <xref:PostSharp.Aspects.Dependencies.StandardRoles>, or the role that the other aspect declares with <xref:PostSharp.Aspects.Dependencies.ProvideAspectRoleAttribute>. If the aspect does not depend on any role, remove the attribute.
