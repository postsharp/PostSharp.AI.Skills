# LA0281: No Member of the Imported Name

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [ImportMember] with IsRequired set to true, but the type "<TargetType>" has no accessible member named "<MemberNames>" that a parameter of type "<ParameterType>" can receive. A ref or out parameter requires a field that is not read-only or a property that returns a reference that is not read-only, a parameter passed by reference requires the exact type of the member, and IEventBinding and Event<T> require an event.` |

## Cause

An advice parameter annotated with <xref:PostSharp.Aspects.Advices.ImportMemberAttribute> with one or more member names receives the first member of these names that the parameter can receive. The candidates are the members of the target type and the accessible members of its base types, except indexers, constants and the fields generated by the compiler. A member of the name is not selected when:

* the parameter is passed as `ref` or `out`, and the member is a read-only field, or a property that does not return a reference that is not read-only;
* the parameter is passed by reference, or is an <xref:PostSharp.Aspects.ILocationBinding`1>, and the member does not have exactly its type;
* the parameter is passed by value, and the type of the member cannot be assigned to `<ParameterType>` without a conversion other than boxing;
* the parameter is a <xref:PostSharp.Aspects.Advices.Property`1> and the member is not a property, or an <xref:PostSharp.Aspects.IEventBinding> or an <xref:PostSharp.Aspects.Advices.Event`1> and the member is not an event.

When no member is selected, the parameter normally receives `null`, the default value, or a reference to a temporary variable. When <xref:PostSharp.Aspects.Advices.ImportMemberAttribute.IsRequired> is `true`, PostSharp reports LA0281 on each target instead. `<MemberNames>` lists the names of the attribute, and `<TargetType>` is the type to which the aspect is applied, or the type that declares the target member. A delegate parameter whose names match no method of the target type also falls back to the fields and properties of the delegate type, and reports LA0281 when it finds none. When the advice uses a pointcut that skips the targets whose signature does not match, such as <xref:PostSharp.Aspects.Advices.MatchPointcut>, PostSharp skips the target instead of reporting the error.

## Resolution

* Correct the name of the member in the attribute, or add a member of this name to the target type.
* To change the member through a `ref` or `out` parameter, import a field that is not read-only, for instance the field behind the property, or pass the parameter by value to read a property.
* Change the type of the advice parameter to the type of the member.
* Set <xref:PostSharp.Aspects.Advices.ImportMemberAttribute.IsRequired> to `false` if the advice can work without the member.
