# LA0109: Method Pointcut Selects a Member of a Generic Type Instance

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Error while evaluating the MethodPointcut "<PointcutMethod>" on "<AspectTarget>": cannot apply an advice to the generic type instance or generic method instance "<Element>". Select the members of the generic type definition or of the generic method definition instead.` |

## Cause

An advice of a type-level aspect can select its targets with <xref:PostSharp.Aspects.Advices.MethodPointcut>, which names a method of the aspect that returns the declarations to enhance. PostSharp adds the advice to the code of each declaration, and code exists only once for a generic type or method: in its definition, such as `Repository<T>`, not in each instance, such as `Repository<Customer>`.

PostSharp reports LA0109 for each element that the pointcut method returns when the element is a generic type instance, a member of a generic type instance, or a generic method instance. The most common cause is a pointcut method that reads the members of a base type: when the target type derives from `Repository<Customer>`, its `BaseType` is the generic type instance, and so are the members it returns. The error is reported on the pointcut method, once for each such element, and the element is skipped.
