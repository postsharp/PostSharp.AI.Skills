# LA0221: Interception Advice Cannot Set the Return Value

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The advice "<Advice>" cannot be applied to "<Target>" because the method returns a value, and the advice has neither a MethodInterceptionArgs parameter nor a [ReturnValue] parameter to set it.` |

## Cause

An <xref:PostSharp.Aspects.Advices.OnMethodInvokeAdvice> replaces the body of the target method, so the value that the method returns is the value that the advice sets. The advice sets it through a parameter annotated with <xref:PostSharp.Aspects.Advices.ReturnValueAttribute>, passed as `out` or `ref`, or through the <xref:PostSharp.Aspects.MethodInterceptionArgs.ReturnValue> property of a <xref:PostSharp.Aspects.MethodInterceptionArgs> parameter. When the target returns a value and the advice has neither of them, PostSharp reports LA0221 on the target, because the method would always return the default value. A target that returns `void` does not need either.

## Resolution

* Add a `[ReturnValue]` parameter passed as `out` to the advice, and assign it the value that <xref:PostSharp.Aspects.IMethodBinding.Invoke*> returns. Make the advice generic, with a parameter of type `T`, to fit any return type.
* Apply the aspect only to methods that return `void`.
