# PS0157: Service Cannot Be Created

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot create an instance of the service type '<TypeName>, <AssemblyFile>': <Reason>` |

## Cause

The `Service` element of a PostSharp configuration file, such as `postsharp.config`, registers a build-time service. When it initializes the project, PostSharp loads the assembly that the `AssemblyFile` attribute names or, when the attribute is omitted, the assembly being built, finds the class that `TypeName` names, and creates an instance of it. PostSharp reports PS0157 when any of these steps throws an exception. `<Reason>` is the message of the exception, and `<AssemblyFile>` is empty when the element has no `AssemblyFile` attribute.

The common causes are:

* `TypeName` is not the full name of a class of the assembly, for example because it lacks the namespace. The reason is then `Value cannot be null. (Parameter 'type')`.
* The file of `AssemblyFile` cannot be found or loaded.
* The class has no parameterless constructor, or its constructor throws an exception.

Because the services are created when the project is initialized, PostSharp also reports <xref:ps0084?text=PS0084> and stops the build.

## Resolution

* Set `TypeName` to the full name of the class, with its namespace. For a nested class, separate it from its declaring class with `+`.
* When the class is in another assembly, set `AssemblyFile` to the path of this assembly. A relative path is resolved from the directory of the configuration file.
* Give the class a public parameterless constructor that does not throw.
* When the service is not needed, remove the `Service` element.
