# LA0189: Advice Parameter Can Write to an In Argument

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply the advice "<Advice>" to the method "<TargetMethod>": the advice has a 'ref' or 'out' parameter that binds to the 'in' parameter #<Index> of the target method. Declare the parameter of the advice as 'in'.` |

## Cause

An advice method receives an argument of its target method through a parameter marked with <xref:PostSharp.Aspects.Advices.ArgumentAttribute>. When the parameter of the advice is `ref` or `out`, the advice can write to the argument. An `in` parameter of the target method is read-only, so PostSharp does not let an advice write to it, and reports LA0189 instead of applying the advice.

`<Index>` is the zero-based position of the parameter in the target method. The message has no location in the source code: it names the advice and the target method.

## Resolution

Declare the parameter of the advice as `in`, or pass it by value when the advice does not need the address of the argument. If the advice must change the argument, the target method must declare the parameter as `ref`.
