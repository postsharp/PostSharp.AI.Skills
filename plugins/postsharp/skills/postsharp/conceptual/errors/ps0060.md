# PS0060: Processing of the Module Failed Without an Error

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The processing of module "<Module>" failed without reporting an error. This is a bug of PostSharp: report it to the support of PostSharp, with the build log.` |

## Cause

PostSharp processes each module of the project in a sequence of tasks. When a task fails, it reports an error that explains why, and PostSharp stops. PostSharp reports PS0060 only when a task fails but no error was reported, so that the build does not end with a failure and no explanation. `<Module>` is the name of the module, usually the name of the assembly.

When another error or a fatal error is reported, PostSharp does not report PS0060. A task that fails silently is a bug of PostSharp, so no example can show this message.

## Resolution

* Look in the build log for warnings that PostSharp reported before PS0060: they may show what the failing task was doing.
* Rebuild the project after deleting its `obj` folder, to rule out stale intermediate files.
* Report the problem to the PostSharp support team, with the build log at the detailed verbosity (`dotnet build -v:d` or `msbuild -v:d`) and, if possible, a project that reproduces it.
