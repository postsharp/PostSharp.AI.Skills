# THR022: Reentrant Method Is Not Async

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Threading |
| **Message** | `Cannot apply [Reentrant] to "<Method>" because the method is not async.` |

## Cause

The <xref:PostSharp.Patterns.Threading.ReentrantAttribute> attribute means that an `async` method can be re-entered at each `await`: with a lock-based threading model such as <xref:PostSharp.Patterns.Threading.SynchronizedAttribute>, the lock of the object is released while the method awaits; with <xref:PostSharp.Patterns.Threading.ActorAttribute>, other methods of the actor can run in the meantime. A method that is not `async` has no `await` at which this could happen.

PostSharp reports THR022 when the attribute is applied to a method that is not `async`, including a method that returns a `Task` without the `async` keyword. PostSharp does not check a method that also has the <xref:PostSharp.Patterns.Threading.ExplicitlySynchronizedAttribute> attribute.

## Resolution

* When the method awaits a task, make it `async` and `await` the task, so that the object can be re-entered while it waits.
* Otherwise, remove the `[Reentrant]` attribute: a method that is not `async` does not need it.
