# XAM059: Handler of an Attached Property Is Not Static

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Xaml |
| **Message** | `Error in the [<Aspect>] aspect applied to property <Property>: the <MethodKind> method "<Method>" must be static.` |

## Cause

An attached property, which the <xref:PostSharp.Patterns.Xaml.AttachedPropertyAttribute> aspect implements, is declared by one class and set on objects of any other class, such as a control in a panel. The objects whose property changes are not instances of the declaring class, so the aspect has no instance to call an instance method on. PostSharp reports XAM059 when the change handler (`On` followed by the name of the property and `Changed`, or the method named by <xref:PostSharp.Patterns.Xaml.DependencyPropertyBaseAttribute.PropertyChangedMethod>) or the validation method (`Validate` followed by the name of the property, or the method named by <xref:PostSharp.Patterns.Xaml.DependencyPropertyBaseAttribute.ValidateValueMethod>) is not static.

`<MethodKind>` is `change handler` or `validator`. PostSharp reports the message on the method, not on the property. The current version of the message shows the method between the brackets, where the name of the aspect should be.

## Resolution

Make the method static. To know which object the property changed on, add a parameter for the instance, of type <xref:System.Windows.DependencyObject> or `object`, after the optional <xref:System.Windows.DependencyProperty> parameter: the aspect passes the object on which the attached property is set.
