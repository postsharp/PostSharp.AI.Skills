# LA0236: Binding Used Twice in an Advice

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by <Binding>, but the advice already has a parameter bound by <Binding>.` |

## Cause

An advice can have at most one parameter annotated with <xref:PostSharp.Aspects.Advices.FlowBehaviorAttribute>, and at most one annotated with <xref:PostSharp.Aspects.Advices.AwaiterAttribute>. PostSharp reports LA0236 on each additional parameter, but still builds the advice:

* With several `[FlowBehavior]` parameters, the woven code reads only the last one, and ignores the values set to the others.
* Several `[Awaiter]` parameters share one awaiter variable.

The same mistake with <xref:PostSharp.Aspects.Advices.ReturnValueAttribute> or <xref:PostSharp.Aspects.Advices.ExceptionAttribute> causes the error <xref:la0214?text=LA0214> instead.
