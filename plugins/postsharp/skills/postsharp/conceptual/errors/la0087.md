# LA0087: Advice Member Not Public

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Advice "<Advice>" is not valid on "<Member>" because this member is not public.` |

## Cause

PostSharp requires the members of an aspect that carry an advice attribute to be public. It reports LA0087 when one of the following members is not public:

* an advice method, such as a method with <xref:PostSharp.Aspects.Advices.OnMethodEntryAdvice>, <xref:PostSharp.Aspects.Advices.OnMethodInvokeAdvice>, <xref:PostSharp.Aspects.Advices.OnLocationGetValueAdvice>, <xref:PostSharp.Aspects.Advices.OnEventAddHandlerAdvice>, <xref:PostSharp.Aspects.Advices.LocationValidationAdvice>, <xref:PostSharp.Aspects.Advices.OnInstanceConstructedAdvice>, <xref:PostSharp.Aspects.Advices.InitializeAspectInstanceAdvice> or <xref:PostSharp.Aspects.Advices.OnAspectsInitializedAdvice>;
* a field annotated with <xref:PostSharp.Aspects.Advices.ImportMemberAttribute>;
* a method, property or event annotated with <xref:PostSharp.Aspects.Advices.IntroduceMemberAttribute>.

`<Advice>` is the type of the advice attribute, and `<Member>` is the member of the aspect that carries it.
