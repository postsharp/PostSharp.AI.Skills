# LA0066: Custom Attribute Derived From an Infrastructure Class of the Advices

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot find an advice analyzer for the custom attribute derived from RequiresAdviceAnalysisAttribute on "<Declaration>". This class is an infrastructure class of PostSharp: do not derive from it.` |

## Cause

The `RequiresAdviceAnalysisAttribute` class of the `PostSharp.Aspects.Internals` namespace is an infrastructure class. PostSharp derives its own sealed custom attributes from it to mark the advice custom attributes whose methods it must analyze before weaving them, and registers an advice analyzer for each of them. When a method or a class carries a custom attribute derived from `RequiresAdviceAnalysisAttribute` for which no analyzer is registered, which is the case of any class derived from it in your code, PostSharp reports LA0066.

`<Declaration>` is the method or the class that carries the custom attribute. PostSharp reports the message without a location.

## Resolution

Do not derive from `RequiresAdviceAnalysisAttribute`. Derive your custom attribute from <xref:PostSharp.Extensibility.MulticastAttribute> when it must be multicast, from <xref:System.Attribute> otherwise, or from an aspect class when it must transform the code.
