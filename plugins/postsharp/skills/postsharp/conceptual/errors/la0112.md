# LA0112: Instance-Scoped Aspect Applied to a Value Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply the aspect "<Aspect>" to "<Target>": instance-scoped aspects cannot be applied to value types or members of value types.` |

## Cause

An instance-scoped aspect, which implements <xref:PostSharp.Aspects.IInstanceScopedAspect> or derives from <xref:PostSharp.Aspects.InstanceLevelAspect>, has one instance per instance of its target type. PostSharp stores this instance in a field that it adds to the target type. PostSharp supports this for classes only, and reports LA0112 when the declaring type of the target is a value type: a struct, or a member of a struct.

## Resolution

* Make the target type a class.
* Or make the aspect static-scoped: remove <xref:PostSharp.Aspects.IInstanceScopedAspect>, so that one instance of the aspect serves all the instances of the target type.
