# LA0068: Aspect Does Not Implement the Interface It Introduces

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The aspect "<Aspect>" cannot introduce the interface "<Interface>" because the aspect type does not implement this interface.` |

## Cause

When an aspect introduces an interface into its target type, with <xref:PostSharp.Aspects.Advices.IntroduceInterfaceAttribute> or with an <xref:PostSharp.Aspects.Advices.IntroduceInterfaceAdviceInstance> that an <xref:PostSharp.Aspects.Advices.IAdviceProvider> provides, the target type implements the interface by delegating each of its members to the aspect instance. The aspect class must therefore implement the interface itself. Otherwise, PostSharp reports LA0068 on the aspect class.

When `<Interface>` is a generic type definition, such as `IComparable<>`, PostSharp introduces every instance of this interface that the aspect class implements, and reports LA0068 when the aspect class implements none.
