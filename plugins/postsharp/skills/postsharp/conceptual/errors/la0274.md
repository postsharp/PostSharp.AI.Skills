# LA0274: Target Type Cannot Receive Dependencies

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The aspect "<Aspect>" applied to "<Target>" attempts to introduce a dependency with ImportDependencyAdviceInstance, but "<TargetType>" cannot receive dependencies from its constructors. Dependencies are supported on classes that have instance constructors only.` |

## Cause

An <xref:PostSharp.Aspects.Advices.ImportDependencyAdviceInstance> makes the target class receive a service from its constructors: PostSharp adds a parameter of the service type to the instance constructors of the class, and stores the service in a field. PostSharp reports LA0274 when `<TargetType>`, the type to which the aspect is applied or the type that declares `<Target>`, has no such constructors:

* a static class, which has no instance constructor;
* a struct, which `default` creates without calling a constructor;
* an interface or a delegate.

## Resolution

* Make the target type a class with instance members, and create its objects with a dependency injection container, or with `new`, which gets the service from <xref:PostSharp.Extensibility.RunTimeServiceLocator>.
* Otherwise, apply the aspect only to members of classes, or do not request the dependency on this target: the advice can get the service from <xref:PostSharp.Extensibility.RunTimeServiceLocator.GetRequiredService*> itself.
