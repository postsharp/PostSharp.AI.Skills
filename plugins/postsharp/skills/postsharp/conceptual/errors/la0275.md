# LA0275: Invalid Dependency Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The aspect "<Aspect>" applied to "<Target>" attempts to introduce a dependency of type "<DependencyType>" with ImportDependencyAdviceInstance, which is not a valid dependency type. A dependency must be a reference type that contains no generic parameters.` |

## Cause

An <xref:PostSharp.Aspects.Advices.ImportDependencyAdviceInstance> adds a constructor parameter and a field of the type passed to its constructor, the <xref:PostSharp.Aspects.Advices.ImportDependencyAdviceInstance.DependencyType>. When the constructor receives `null`, it gets the service from <xref:PostSharp.Extensibility.RunTimeServiceLocator>. This requires a reference type that the target class can declare, so PostSharp reports LA0275 when `<DependencyType>` is:

* a value type, such as a struct or an enum;
* a pointer or by-reference type;
* a type that contains generic parameters, such as the open generic type `IAuditLog<>`.

PostSharp reports the error on `<Target>`, the declaration to which the aspect is applied.

## Resolution

* For a generic service, construct the type in <xref:PostSharp.Aspects.Advices.IAdviceProvider.ProvideAdvices(System.Object)>, for instance with the class that declares the target, and import it with a base type or interface of it.
* For a value, request a reference type that holds it, such as an interface or a class of options.

In the following example, the aspect requests `IAuditLog<OrderService>` for the methods of `OrderService`, and the advice imports it by its <xref:PostSharp.Aspects.Advices.ImportDependencyAdviceInstance.Name> as an `IAuditLog`.
