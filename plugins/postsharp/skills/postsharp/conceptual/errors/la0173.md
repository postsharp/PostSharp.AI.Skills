# LA0173: Async Interception Advice Falls Back to No Advice

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Advice "<Advice>" is not grouped with a non-async OnMethodInvokeAdvice, therefore its UnsupportedTargetAction property cannot be set to Fallback.` |

## Cause

An advice marked with <xref:PostSharp.Aspects.Advices.OnMethodInvokeAsyncAdvice> intercepts only the methods that return a <xref:System.Threading.Tasks.Task> or a <xref:System.Threading.Tasks.Task`1>. When the <xref:PostSharp.Aspects.Advices.OnMethodInvokeBaseAdvice.UnsupportedTargetAction> property of the group is <xref:PostSharp.Aspects.UnsupportedTargetAction.Fallback>, an advice marked with <xref:PostSharp.Aspects.Advices.OnMethodInvokeAdvice>, in the same group, intercepts the other methods without async semantics. The property applies to the whole group, and can be set on any one advice of the group.

PostSharp reports LA0173 on the async advice `<Advice>` when the property is <xref:PostSharp.Aspects.UnsupportedTargetAction.Fallback> and the group has no such advice: there is nothing to fall back to. PostSharp checks the group itself, whatever methods the aspect is applied to.

## Resolution

* Add an advice marked with <xref:PostSharp.Aspects.Advices.OnMethodInvokeAdvice> to the group. An advice without pointcut and without <xref:PostSharp.Aspects.Advices.GroupingAdvice.Group> joins the group of its class that has no advice of its kind yet. When several groups of the class have none, give the two advices the same <xref:PostSharp.Aspects.Advices.GroupingAdvice.Group> value.
* Otherwise, set <xref:PostSharp.Aspects.Advices.OnMethodInvokeBaseAdvice.UnsupportedTargetAction> to <xref:PostSharp.Aspects.UnsupportedTargetAction.Ignore> to leave the unsupported methods alone, or remove the property to get <xref:la0172?text=LA0172> on each of them.
