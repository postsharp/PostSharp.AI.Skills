# LA0269: Invalid Type of a Requested Field

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The aspect "<Aspect>" applied to "<Target>" attempts to introduce a field of type "<FieldType>" with IntroduceFieldAdviceInstance, which is not a valid field type. By-reference types, pointers, void and types that contain generic parameters are not supported, and a byref-like type, such as Span<T>, is supported only as an instance field of a ref struct.` |

## Cause

An aspect attempts to introduce a field by returning an <xref:PostSharp.Aspects.Advices.IntroduceFieldAdviceInstance> from <xref:PostSharp.Aspects.Advices.IAdviceProvider.ProvideAdvices*>. PostSharp reports LA0269 when the <xref:PostSharp.Aspects.Advices.IntroduceFieldAdviceInstance.FieldType> of the request is one of the following:

* A by-reference type, such as the type of a `ref` parameter.
* A pointer type, such as `byte*`.
* `void`.
* A type that contains generic parameters, such as the return type `T` of a generic method, or an open generic type.
* A byref-like type, such as <xref:System.Span`1>, when the request is for a static field (<xref:PostSharp.Aspects.Advices.IntroduceFieldAdviceInstance.IsStatic> is `true`) or when the target type is not a `ref struct`.

`<Target>` is the declaration to which the aspect is applied, where the error is located.

## Resolution

Request a field of a type that a field can have:

* For a pointer, request a <xref:System.IntPtr> (`nint`) field, and convert it to a pointer in the advice.
* For a by-reference type, request a field of the element type, which <xref:System.Type.GetElementType*> returns.
* For a type that depends on a generic parameter of a method, request a field of a closed type, such as <xref:System.Object>.
* For a byref-like type, request an instance field in a `ref struct`, or store the data in a type that is not byref-like, such as an array or <xref:System.Memory`1>.
