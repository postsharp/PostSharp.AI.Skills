# LA0237: Get Advice Without a Location Value

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The advice "<Advice>" cannot get the value of the location because it has neither a LocationInterceptionArgs parameter nor a [LocationValue] parameter.` |

## Cause

An <xref:PostSharp.Aspects.Advices.OnLocationGetValueAdvice> replaces the getter of a field or property, so it must give the value that the getter returns. It gives it either through the `LocationInterceptionArgs.Value` property of a <xref:PostSharp.Aspects.LocationInterceptionArgs> parameter, which is the first parameter and has no binding attribute, or through a parameter annotated with <xref:PostSharp.Aspects.Advices.LocationValueAttribute>. When the advice has neither, PostSharp reports LA0237 on the advice method.

## Resolution

* Add a `[LocationValue]` parameter passed as `out` or `ref`, and assign it the value of the location, which a <xref:PostSharp.Aspects.Advices.BindingAttribute> parameter of type <xref:PostSharp.Aspects.ILocationBinding`1> reads.
* Or declare a <xref:PostSharp.Aspects.LocationInterceptionArgs> parameter as the first parameter, and call <xref:PostSharp.Aspects.LocationInterceptionArgs.ProceedGetValue>.
