# LA0138: Imported Field or Property Not Declared in the Target Class

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Error in ImportMemberAdviceInstance provided by the IAdviceProvider implementation of aspect "<Aspect>" applied to "<TargetType>": imported location "<Location>" is not declared in the target type of the aspect.` |

## Cause

An aspect that implements <xref:PostSharp.Aspects.Advices.IAdviceProvider> can import a field or a property of its target class by giving its <xref:PostSharp.Reflection.LocationInfo> to an <xref:PostSharp.Aspects.Advices.ImportLocationAdviceInstance>. The aspect accesses this location on the instance of the target class, so the location must be declared in the target class, `<TargetType>`, or in one of its base classes. PostSharp reports LA0138 when `<Location>` is declared in another class.

This typically happens when <xref:PostSharp.Aspects.Advices.IAdviceProvider.ProvideAdvices(System.Object)> looks up the field or property in a fixed class instead of the target that it receives: the aspect works on this class and fails on the others. PostSharp reports the message on the aspect class.

## Resolution

Look up the imported field or property in the target of the aspect, which <xref:PostSharp.Aspects.Advices.IAdviceProvider.ProvideAdvices(System.Object)> receives as a <xref:System.Type>. When a target may lack the field or property, skip the advice for this target instead of designating the field or property of another class.
