# PS0205: Invalid Expression in Configuration File

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Invalid XPath expression "<Expression>": <Reason>` |

## Cause

Many attributes of a `postsharp.config` file, such as the `Value` of a `Property` element or a `Condition` attribute, accept expressions. The text between braces, for example `{$Configuration = 'Debug'}`, is an XPath 1.0 expression, in which properties are variables. See <xref:configuration-xpath>.

PostSharp reports PS0205 when the XPath engine of .NET cannot compile or evaluate the expression. `<Expression>` is the text between the braces, and `<Reason>` is the explanation that .NET gives. The usual causes are operators of C# that XPath does not have: `==` instead of `=`, `||` instead of `or`, or `!` instead of `not()`. PostSharp then ignores the element whose condition failed, or gives no value to the attribute.

## Resolution

Write the expression in XPath 1.0: compare with `=` and `!=`, combine conditions with `and` and `or`, negate them with `not()`, and quote strings with single quotes inside an XML attribute in double quotes. See <xref:configuration-xpath> for the functions that PostSharp adds to XPath.
