# CAC011: Cached Method Cannot Receive the Caching Service from Dependency Injection

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp.Patterns.Caching |
| **Message** | `The <Aspect> aspect applied to <Method> uses the default caching service, CachingServices.DefaultService, because <Method> is <Kind>, and only the instance methods of classes receive the caching service from dependency injection. To change the severity of this message, set the StaticMethodFallbackSeverity property of [CacheConfiguration].` |

## Cause

When the <xref:PostSharp.Patterns.Caching.CacheConfigurationAttribute.UseDependencyInjection> property of a <xref:PostSharp.Patterns.Caching.CacheConfigurationAttribute> is `true` for a class, its base classes or its assembly, the objects of the class receive their <xref:PostSharp.Patterns.Caching.ICachingService> from their constructors, and the caching aspects of their methods use this service. A static method, or a method of a struct, has no such object. Its aspect uses <xref:PostSharp.Patterns.Caching.CachingServices.DefaultService> instead, and PostSharp reports CAC011 on the method, because its items do not go to the cache that the container provides.

`<Aspect>` is `[Cache]` or `[InvalidateCache]`, and `<Kind>` is `static` or `a method of a struct`.

The severity of the message is the value of the <xref:PostSharp.Patterns.Caching.CacheConfigurationAttribute.StaticMethodFallbackSeverity> property of the nearest <xref:PostSharp.Patterns.Caching.CacheConfigurationAttribute> that sets it: <xref:PostSharp.Extensibility.SeverityType.Warning?text=SeverityType.Warning> by default, or <xref:PostSharp.Extensibility.SeverityType.Error?text=SeverityType.Error>. With <xref:PostSharp.Extensibility.SeverityType.None?text=SeverityType.None>, PostSharp reports nothing.

## Resolution

* Make the method an instance method of a class, and let the container create the objects of this class, so that the method uses the caching service of the container.
* If the method must stay static, or in a struct, and the default caching service is acceptable for it, set the <xref:PostSharp.Patterns.Caching.CacheConfigurationAttribute.StaticMethodFallbackSeverity> property to <xref:PostSharp.Extensibility.SeverityType.None?text=SeverityType.None>, and configure <xref:PostSharp.Patterns.Caching.CachingServices.DefaultService> at startup.
* To forbid the fallback in the whole project, set <xref:PostSharp.Patterns.Caching.CacheConfigurationAttribute.StaticMethodFallbackSeverity> to <xref:PostSharp.Extensibility.SeverityType.Error?text=SeverityType.Error> on the assembly.
