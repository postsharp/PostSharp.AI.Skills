# LA0207: Advice Parameter Has Several Binding Attributes

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" has more than one advice parameter attribute.` |

## Cause

The parameters of an advice method receive their values from attributes derived from <xref:PostSharp.Aspects.Advices.AdviceParameterAttribute>: [<xref:PostSharp.Aspects.Advices.ArgumentAttribute>] receives an argument of the target method, [<xref:PostSharp.Aspects.Advices.DeclarationNameAttribute>] its name, [<xref:PostSharp.Aspects.Advices.ReturnValueAttribute>] its return value, and so on. Each attribute selects one value, so a parameter can have only one of them. PostSharp reports LA0207 when a parameter `<Parameter>` of the advice method `<Advice>` has two or more.
