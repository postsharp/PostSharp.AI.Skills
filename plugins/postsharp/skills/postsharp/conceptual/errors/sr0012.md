# SR0012: Method of the Base Serializer Is Sealed

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Method '<Method>' cannot be sealed because it must be overridden by the serializer of type '<Type>'.` |

## Cause

When a [<xref:PostSharp.Serialization.PSerializableAttribute>] class derives from a class whose serializer is written by hand, the serializer that PostSharp generates for the derived class `<Type>` derives from the serializer of the base class. It overrides <xref:PostSharp.Serialization.ReferenceTypeSerializer.SerializeObject*> and <xref:PostSharp.Serialization.ReferenceTypeSerializer.DeserializeFields*> to serialize the fields of `<Type>`, and calls the implementations of the base serializer for the fields of the base class.

PostSharp reports SR0012 on `<Method>` when the base serializer overrides one of these two methods as `sealed`.
