# XAM052: Invalid Target of the AttachedProperty Aspect

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Xaml |
| **Message** | `[AttachedProperty] cannot be applied to <Target>: the target must be a static property of type Attached<T> with a public getter.` |

## Cause

An attached property is declared by one class and set on objects of other classes, as `Grid.Column` is set on the children of a `Grid`. The <xref:PostSharp.Patterns.Xaml.AttachedPropertyAttribute> aspect registers the attached property and assigns its target property an <xref:PostSharp.Patterns.Xaml.Attached`1> object, which reads and writes the value on any <xref:System.Windows.DependencyObject>. The target must therefore be a static property of type <xref:PostSharp.Patterns.Xaml.Attached`1>, and its getter must be public.

PostSharp reports XAM052 when the <xref:PostSharp.Patterns.Xaml.AttachedPropertyAttribute> aspect is applied to:

* an instance property;
* a property whose getter is not public;
* a property of another type than <xref:PostSharp.Patterns.Xaml.Attached`1>, typically the type of the value itself;
* a field, which C# allows because the aspect is a location-level aspect.

## Resolution

Declare the target as `public static Attached<T> Name { get; private set; }`, where `T` is the type of the value. Read and write the value on a given object with the <xref:PostSharp.Patterns.Xaml.Attached`1.GetValue(System.Windows.DependencyObject)> and <xref:PostSharp.Patterns.Xaml.Attached`1.SetValue(System.Windows.DependencyObject,`0)> methods, and add a static `SetName` method that calls <xref:PostSharp.Patterns.Xaml.Attached`1.SetValue(System.Windows.DependencyObject,`0)>, which the XAML compiler requires to set the property in XAML.

If you want a property that stores a value in each instance of its own class, use the <xref:PostSharp.Patterns.Xaml.DependencyPropertyAttribute> aspect on an instance property instead.
