# LA0102: Ambiguous Pointcut Method

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot choose the method "<Method>" named by the MethodPointcut of the advice "<Advice>": type "<AspectType>" has more than one method of this name with the signature of a pointcut method. Rename the other methods.` |

## Cause

A <xref:PostSharp.Aspects.Advices.MethodPointcut> names a method of the aspect class by its name only. A pointcut method is an instance method with one parameter, of type <xref:System.Object> or of the reflection type of the target of the aspect, that returns an <xref:System.Collections.Generic.IEnumerable`1> of <xref:System.Object> or of the reflection type of the targets of the advice (see <xref:la0101?text=LA0101>). When the aspect class has several overloads with this name that match this signature, for instance one that takes a <xref:System.Type> and one that takes an <xref:System.Object>, PostSharp cannot choose one and reports LA0102 on the advice method.

PostSharp then also reports <xref:la0049?text=LA0049>, which says that the advice has no pointcut: it ignores the pointcut that it could not resolve. Fixing LA0102 removes <xref:la0049?text=LA0049> too.
