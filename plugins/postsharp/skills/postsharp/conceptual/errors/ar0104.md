# AR0104: [Internal] Applied to a Declaration Other Assemblies Cannot See

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot use [Internal] on <Kind> <Declaration> because the <Kind> cannot be seen from other assemblies. [Internal] applies only to public or protected declarations of public types.` |

## Cause

The <xref:PostSharp.Constraints.InternalAttribute> constraint keeps other assemblies from using a declaration that must be `public` for technical reasons. It has a purpose only on a declaration that other assemblies can see: a `public`, `protected` or `protected internal` member of a type that is itself visible outside of its assembly. When the declaration is `private`, `internal` or `private protected`, or belongs to such a type, C# already keeps other assemblies away from it, and PostSharp reports AR0104 on the declaration.

PostSharp itself rejects the most direct cases before this check: applying `[Internal]` to a member that is not `public` reports <xref:ps0091?text=PS0091>. ## Resolution

* When the declaration does not need to be visible outside of its assembly, remove `[Internal]`: the `internal` keyword already gives the protection.
* When the type must be public for technical reasons, for example because a serializer or a framework requires it, make the type public and keep `[Internal]` on the member.
