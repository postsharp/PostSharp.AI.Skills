# PS0124: Details of Conflicting Aspect Dependencies

| | |
|---|---|
| **Severity** | Info |
| **Reported by** | PostSharp |
| **Message** | `Detail of the dependencies for the previous error or warning: <Details>` |

## Cause

When several aspects transform the same declaration, PostSharp orders their transformations from the dependencies that the aspects declare. When the ordering fails, PostSharp reports one of two messages on the declaration, and immediately after it PS0124, which carries the details:

* <xref:ps0114?text=PS0114>, a warning, when two transformations that do not commute, for example an `OnMethodBoundaryAspect` and a `MethodInterceptionAspect` on the same method, have no order between them, so that their order of execution is not deterministic. `<Details>` lists all the transformations of the declaration.
* <xref:ps0115?text=PS0115>, an error, when the dependencies require a transformation to be both before and after another one. `<Details>` lists the two transformations.

For each transformation, `<Details>` gives its name, such as `OrderService.LogAttribute: Wrapped by advice(s) OnEntry`, and on the following lines the dependencies that it declares, or `(no dependency)`.

PS0124 is an informational message, not an error or a warning. The test framework of this documentation captures only errors and warnings, so no example can show it.

## Resolution

PS0124 needs no action of its own: resolve the <xref:ps0114?text=PS0114> or <xref:ps0115?text=PS0115> message that comes before it, using the details to see which dependencies are missing or contradictory.

* For <xref:ps0114?text=PS0114>, order the aspects: set the <xref:PostSharp.Aspects.Aspect.AspectPriority> property where you apply them, or declare a dependency on the aspect class with <xref:PostSharp.Aspects.Dependencies.AspectTypeDependencyAttribute> or <xref:PostSharp.Aspects.Dependencies.AspectRoleDependencyAttribute>.
* For <xref:ps0115?text=PS0115>, find in `<Details>` the two dependencies that contradict each other, and remove or correct one of them.

See <xref:aspect-dependencies> for how PostSharp orders aspects.
