# PS0275: Unsupported Target Platform

| | |
|---|---|
| **Severity** | Fatal error |
| **Reported by** | PostSharp |
| **Message** | `The project targets or references an unsupported platform: <Framework>.` |

## Cause

PostSharp must know the platform of the project and of each referenced assembly to find their framework assemblies. It reads the platform from the `TargetFrameworkMoniker` of the project and from the <xref:System.Runtime.Versioning.TargetFrameworkAttribute> of each referenced assembly, and supports the following framework identifiers: `.NETFramework`, `.NETCoreApp` (.NET Core and .NET 5 or later), `.NETStandard`, `.NETCore` (UWP and Windows Runtime), `.NETPortable`, `MonoAndroid`, `MonoTouch` and `Xamarin.iOS`.

PostSharp reports PS0275 when the project or a referenced assembly names another framework, for example Silverlight, Windows Phone or the .NET Micro Framework. `<Framework>` is the framework name, with its version. The error is fatal: PostSharp stops processing the project.

## Resolution

* When a referenced library is built for an unsupported platform, reference a build of this library for a supported platform, typically .NET Standard or .NET. Find the platform of a referenced assembly in its <xref:System.Runtime.Versioning.TargetFrameworkAttribute>, for example with ILSpy.
* When the project itself targets an unsupported platform, move the code that uses PostSharp to a .NET Standard library, and reference this library from the project. See <xref:requirements> for the platforms that PostSharp supports.

To see which framework PostSharp failed to recognize, and from which assembly it comes, enable the `AssemblyBinder` trace category with the `PostSharpTrace` MSBuild property (see <xref:msbuild-properties>).
