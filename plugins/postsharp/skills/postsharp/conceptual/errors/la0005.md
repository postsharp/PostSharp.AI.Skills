# LA0005: Base Interface of an Introduced Interface Already Implemented

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot introduce the interface <Interface> into the type <TargetType> because this type already implements its base interface <BaseInterface>. To keep the existing implementation of <BaseInterface>, set AncestorOverrideAction to Ignore.` |

## Cause

When an aspect introduces an interface with <xref:PostSharp.Aspects.Advices.IntroduceInterfaceAttribute>, with an <xref:PostSharp.Aspects.Advices.IntroduceInterfaceAdviceInstance> or as a <xref:PostSharp.Aspects.CompositionAspect>, it also introduces the base interfaces of this interface. When the target type already implements one of these base interfaces, PostSharp follows the `AncestorOverrideAction` of the introduction. Its default value, <xref:PostSharp.Aspects.Advices.InterfaceOverrideAction.Fail>, reports LA0005 on the target type.

`<BaseInterface>` is the base interface that the target type already implements, directly or indirectly. The target type can implement it in its source code, through a base type, or because another aspect introduced it first.

When the target type implements `<Interface>` itself, PostSharp reports <xref:la0004?text=LA0004> instead.

## Resolution

* Set the <xref:PostSharp.Aspects.Advices.IntroduceInterfaceAttribute.AncestorOverrideAction> property of the introduction to <xref:PostSharp.Aspects.Advices.InterfaceOverrideAction.Ignore>: the target type keeps its own implementation of the base interface, and the aspect introduces the other interfaces. A <xref:PostSharp.Aspects.CompositionAspect> sets its <xref:PostSharp.Aspects.CompositionAspect.AncestorOverrideAction> property in its constructor.
* Otherwise, remove the base interface from the target type, or introduce an interface that does not extend it.
