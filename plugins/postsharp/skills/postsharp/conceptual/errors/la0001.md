# LA0001: Aspects Cannot Be Serialized

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot serialize the aspects: <ExceptionMessage>.` |

## Cause

PostSharp creates the aspect instances at build time, initializes them, for example in <xref:PostSharp.Aspects.MethodLevelAspect.CompileTimeInitialize*>, and serializes them into a resource of the assembly. At run time, the aspects are deserialized from this resource instead of being created again. Every field of an aspect that is not excluded from serialization must therefore hold a serializable value.

When the serializer throws an exception, PostSharp reports LA0001, and `<ExceptionMessage>` is the message of this exception. With [<xref:PostSharp.Serialization.PSerializableAttribute>], the most common exception says that PostSharp cannot find a serializer for a type: a field of the aspect holds an object of a type that is neither serializable by PostSharp nor marked with [<xref:PostSharp.Serialization.PSerializableAttribute>]. The message has no location, because the aspects of the assembly are serialized together; the type in the exception message tells you which field to look at.

## Resolution

* Make the type of the field serializable, for example with [<xref:PostSharp.Serialization.PSerializableAttribute>]. A type marked with this attribute must itself have serializable fields.
* When the value is only needed at run time, mark the field with [<xref:PostSharp.Serialization.PNonSerializedAttribute>] and initialize it in <xref:PostSharp.Aspects.MethodLevelAspect.RuntimeInitialize*> instead.
