# CAC004: Invalidating Method Lacks a Parameter of the Cached Method

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Caching |
| **Message** | `The [InvalidateCache] aspect applied to <InvalidatingMethod> cannot invalidate <CachedMethod>: <InvalidatingMethod> does not contain a parameter named '<Parameter>'. Add a parameter named '<Parameter>' to <InvalidatingMethod>, or add the [NotCacheKey] attribute to the '<Parameter>' parameter of <CachedMethod>.` |

## Cause

To remove a value from the cache, the <xref:PostSharp.Patterns.Caching.InvalidateCacheAttribute> aspect rebuilds the cache key of the cached method, `<CachedMethod>`, from the arguments of the invalidating method, `<InvalidatingMethod>`. It matches each parameter of the cached method with the parameter of the same name of the invalidating method, regardless of their order. PostSharp reports CAC004, on `<InvalidatingMethod>`, when the invalidating method has no parameter named `<Parameter>`, and this parameter of the cached method is part of the cache key, that is, it does not have the <xref:PostSharp.Patterns.Caching.NotCacheKeyAttribute> attribute.

The match is by name only, so two parameters of the same type and meaning but with different names do not match.

## Resolution

* Rename the parameter of the invalidating method so that it has the name of the parameter of the cached method, or add a parameter of this name.
* If the parameter of the cached method does not affect its value, exclude it from the cache key with the `[NotCacheKey]` attribute.
