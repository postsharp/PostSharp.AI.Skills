# LA0127: Location Validation Aspect Applied to a Constant

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Aspect "<Aspect>" cannot be applied to field "<Field>" because it is constant.` |

## Cause

A location validation aspect, which implements <xref:PostSharp.Aspects.ILocationValidationAspect`1>, validates the value of a field each time it is assigned. A `const` field is never assigned at run time: the compiler copies its value into the code that reads it. There is no assignment to validate, so PostSharp reports LA0127 and skips the aspect.

## Resolution

* Remove the aspect from the constant. Its value is fixed at compile time, so you can check it when you write it.
* When the value must be validated, declare a field or a property that is assigned at run time instead of a constant, and apply the aspect to it.
