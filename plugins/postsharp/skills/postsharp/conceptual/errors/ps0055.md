# PS0055: Build Stopped After Errors in Multicast Attributes

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The processing of multicast attributes cannot continue because of the previous errors.` |

## Cause

Before it applies aspects, PostSharp reads every multicast attribute of the project, including aspects, and computes where each one applies: it reads the <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute> of the attribute class and the filter properties of each instance, such as <xref:PostSharp.Extensibility.MulticastAttribute.AttributeTargetTypes>. When this step reports an error, PostSharp cannot know where the attributes apply, so it stops the build and reports PS0055.

PS0055 is therefore always reported together with at least one other error, which describes the actual problem. Common ones are:

* <xref:ps0093?text=PS0093>: a filter property, such as <xref:PostSharp.Extensibility.MulticastAttribute.AttributeTargetTypes> or <xref:PostSharp.Extensibility.MulticastAttribute.AttributeTargetMembers>, contains an invalid regular expression.
* <xref:ps0072?text=PS0072>: the <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute> of an aspect class allows more than the one of its base class.
* <xref:ps0090?text=PS0090> or <xref:ps0171?text=PS0171>: the usage or the filter of a multicast attribute is invalid.

PS0055 has no location.
