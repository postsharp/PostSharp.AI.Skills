# DOM026: Recordable Class Has a Public Async or Iterator Method

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Model |
| **Message** | `The [Recordable] aspect cannot open a recording scope for the async or iterator method <Method>. Make the method neither public nor internal, or add the [RecordingScope(RecordingScopeOption.Skip)] attribute to it.` |

## Cause

> [!NOTE]
> Undo/redo, and the <xref:PostSharp.Patterns.Recording.RecordableAttribute> aspect, are deprecated since PostSharp 2026.0.

The <xref:PostSharp.Patterns.Recording.RecordableAttribute> aspect opens a recording scope around each public or internal method of the class, so that all the changes that the method makes are undone as a single operation. A recording scope cannot span an async method or an iterator, whose execution is split between several calls.

PostSharp reports DOM026 on the first public or internal async or iterator method of a recordable class, unless the method has <xref:PostSharp.Patterns.Recording.RecordingScopeAttribute> with <xref:PostSharp.Patterns.Recording.RecordingScopeOption.Skip>. Property getters, event accessors and abstract methods are not checked. `<Method>` is the name of the method, without its type.

## Resolution

* Add `[RecordingScope( RecordingScopeOption.Skip )]` to the method. The aspect then opens no scope for it. To group the changes of the method into one operation, open a scope yourself in the code that calls it, with <xref:PostSharp.Patterns.Recording.Recorder.OpenScope*>.
* Otherwise, make the method `private` or `protected`, which the aspect does not wrap in a scope.
