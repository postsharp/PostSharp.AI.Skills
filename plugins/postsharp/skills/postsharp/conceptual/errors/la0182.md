# LA0182: Method Boundary Advice Applied to a Static Constructor of Another Assembly

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Advice "<Advice>" is not valid on the static constructor of type "<Type>": applying OnMethodEntryAdvice, OnMethodSuccessAdvice, OnMethodExitAdvice or OnMethodExceptionAdvice to a static constructor of another assembly is not supported. Restrict the advice to methods.` |

## Cause

PostSharp can apply advices to a method of a referenced assembly without modifying that assembly: it replaces the calls that the current assembly makes to the method with calls to a generated method that runs the advices. A static constructor is never called by your code, but by the runtime, so PostSharp reports LA0182 when an <xref:PostSharp.Aspects.Advices.OnMethodEntryAdvice>, an <xref:PostSharp.Aspects.Advices.OnMethodSuccessAdvice>, an <xref:PostSharp.Aspects.Advices.OnMethodExitAdvice> or an <xref:PostSharp.Aspects.Advices.OnMethodExceptionAdvice> targets the static constructor of a type of another assembly. `<Advice>` is an advice method of the group, and the message is reported at its location: the advice that has the pointcut of the group, or else the advice that sets a property of the group, or else the first advice of the group. `<Type>` is the type that declares the static constructor.

Multicasting with <xref:PostSharp.Extensibility.MulticastAttribute.AttributeTargetAssemblies> only reaches the members of another assembly that the current assembly references, which never include a static constructor. The message comes from an <xref:PostSharp.Aspects.IAspectProvider> that provides the aspect for the static constructor explicitly, for example from <xref:System.Type.TypeInitializer>.

<xref:la0180?text=LA0180> is the same error for an <xref:PostSharp.Aspects.OnMethodBoundaryAspect> or an <xref:PostSharp.Aspects.OnExceptionAspect>.

## Resolution

* Provide the aspect for methods only, not for the static constructor.
* When the advice selects its targets with another pointcut, such as a <xref:PostSharp.Aspects.Advices.MethodPointcut>, exclude the static constructors from the pointcut.
* When you own the library, apply the aspect in the library itself, where PostSharp can enhance the static constructor.
