# PS0214: Project Language Not Supported

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The project language "<Language>" is not supported. PostSharp supports only C# and Visual Basic projects.` |

## Cause

PostSharp supports C# and Visual Basic projects. It reads the language of the project from the `Language` MSBuild property, which the SDK of the language sets, and uses it to understand the code that the compiler generates: the backing fields of automatic properties, and the classes of iterators and async methods.

When the language is neither `C#` nor `VB`, for example in an F# project, PostSharp still starts, but reports PS0214, a fatal error, as soon as it needs one of these details, for example when it weaves an aspect on an async method. `<Language>` is the value of the `Language` property, or is empty when the project does not set it.

## Resolution

* Move the code that needs aspects to a C# or Visual Basic project, and reference this project from the project in the other language.
* When the project is a C# or Visual Basic project, make sure that nothing overrides the `Language` MSBuild property, for example a custom `.targets` file or the `PostSharpProperties` property.
