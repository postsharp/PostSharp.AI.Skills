# LA0013: Aspect Class Is Private or Protected

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The aspect class <AspectType> has <Visibility> visibility. It should have at least internal visibility.` |

## Cause

PostSharp generates code that stores, deserializes and calls the aspect instances, outside of the class that declares the aspect. The aspect class must therefore be accessible from anywhere in the assembly: it must be `public` or `internal`. C# lets you apply a nested class as an attribute in its containing class, even when the nested class is `private` or `protected`, so the compiler does not catch the problem, and PostSharp reports LA0013 on the aspect class.

`<Visibility>` is `private` for a private nested class, and `family` for a protected one.
