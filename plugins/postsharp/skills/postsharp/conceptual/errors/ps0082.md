# PS0082: Required Attribute of a Task Missing in a Configuration File

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Task "<Task>": the required attribute "<Attribute>" is missing.` |

## Cause

A configuration file, such as `postsharp.config` or a `.psproj` file, can configure the tasks of the PostSharp compiler with a `Tasks` section: each element names a task, and its attributes set the properties of the task. An element replaces the configuration that PostSharp gives the task by default, so it must set every property that the task requires. PostSharp reports PS0082 for each required property, `<Attribute>`, that the element of the task `<Task>` does not set or sets to an empty string.

Among the tasks of PostSharp, the `Compile` task, which writes the woven assembly, has a required attribute: `TargetFile`, the path of the woven assembly.

PostSharp then cannot set up the project and also reports <xref:ps0084?text=PS0084>.

## Resolution

* Remove the element of the task, and the `Tasks` section, from the configuration file, unless you need to change the configuration of the task. PostSharp then configures the task itself.
* When you keep the element, add the missing attribute. For the `Compile` task, set `TargetFile` to `{$Output}`, the path that the build expects.
