# SR0003: Base Constructor Not Accessible from a PSerializable Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply [PSerializable] to type '<Type>' because the base constructor '<BaseConstructor>' is not accessible from '<Type>'.` |

## Cause

[<xref:PostSharp.Serialization.PSerializableAttribute>] generates a deserializing constructor in `<Type>`, which <xref:PostSharp.Serialization.PortableFormatter> calls to create the instance before it restores its fields. This constructor calls `<BaseConstructor>`, a constructor of the base type:

* the deserializing constructor of the base type, which has a single parameter of type `PortableFormatterConstructorContext`, when the base type has one;
* otherwise, when the base type is marked `[Serializer(null)]` because it has no state to serialize, its parameterless constructor.

PostSharp reports SR0003 when `<BaseConstructor>` is not accessible from `<Type>`, for example when it is `private`, or `internal` in another assembly. PostSharp reports the message on `<Type>`, not on the constructor of the base type, and shows `<BaseConstructor>` without its parameters, as `Entity.#ctor`.
