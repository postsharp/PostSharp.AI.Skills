# PS0118: Aspect Initialization Method Is Static

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The method "<Method>" cannot be static, because PostSharp uses it to initialize the aspects of each instance.` |

## Cause

To initialize the instance-scoped aspects of a class, PostSharp generates two methods without parameters in this class, `InitializeAspects` and `OnInstanceConstructed`, and calls them on each new instance. `OnInstanceConstructed` exists when an aspect has an <xref:PostSharp.Aspects.Advices.OnInstanceConstructedAdvice>. When the class already defines a method with one of these names and signatures, PostSharp uses it instead of generating one. It reports PS0118 when this method `<Method>` is static, because it must run on an instance.

When the class is public and not sealed, PostSharp reports <xref:ps0117?text=PS0117> instead, because a static method is not virtual either. PS0118 therefore concerns internal or sealed classes.

## Resolution

* Make the method an instance method, preferably `protected virtual`, so that derived classes can override it. PostSharp then adds its code to your method and calls it when an instance is constructed.
* Otherwise, rename the method, so that PostSharp generates its own one.
