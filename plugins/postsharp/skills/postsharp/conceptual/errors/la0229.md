# LA0229: Parameter of DeclarationName Is Not a String

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is of type "<ParameterType>", but a parameter bound by <Binding> must be of type "<RequiredType>".` |

## Cause

A parameter annotated with <xref:PostSharp.Aspects.Advices.DeclarationNameAttribute> receives the name of the target declaration, which is a constant string. Unlike the bindings that accept a base type of the bound value, such as <xref:System.Object> for <xref:PostSharp.Aspects.Advices.ArgumentAttribute>, this binding requires a parameter of exactly the type <xref:System.String>, because a parameter of type <xref:System.Object> would only box the name. Any other type reports LA0229.

`<Binding>` is the binding attribute as written in source code, `[DeclarationName]`, and `<RequiredType>` is `string`. PostSharp reports the message on the advice parameter. A `ref`, `out` or `in` parameter reports <xref:la0213?text=LA0213> instead.
