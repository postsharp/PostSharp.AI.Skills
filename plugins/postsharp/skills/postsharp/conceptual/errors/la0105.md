# LA0105: Pointcut Returns a Declaration That Cannot Be Found

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Error while evaluating the MethodPointcut "<PointcutMethod>" on "<AspectTarget>": cannot find the <ReflectionType> "<Declaration>" in the current assembly or in the assemblies that it references.` |

## Cause

A <xref:PostSharp.Aspects.Advices.MethodPointcut> selects the targets of an advice with a method of the aspect class. PostSharp runs this method at build time and maps each reflection object that it returns, such as a <xref:System.Type>, a <xref:System.Reflection.MethodInfo> or a <xref:System.Reflection.FieldInfo>, to a declaration of the code model of the project. When it cannot find this declaration in the current assembly or in the assemblies that the project references, it reports LA0105 on the pointcut method and skips the object. Properties, events and parameters have their own messages, <xref:la0103?text=LA0103> and <xref:la0104?text=LA0104>.

This happens when the pointcut method returns a declaration that exists only at build time, for instance an internal member of .NET: the pointcut method runs on the implementation assemblies of .NET, but the project compiles against reference assemblies, which contain only the public API. `<ReflectionType>` is the type of the reflection object, such as `RuntimeMethodInfo` for a method or `RuntimeType` for a type.
