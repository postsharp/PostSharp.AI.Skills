# LA0186: Method Invoke Advice Without an Async Advice on an Async Method

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp |
| **Message** | `Semantic advising for the "<Advice>" advice is enabled for the "<Method>" method, but the OnInvokeAsync advice is not implemented. To suppress this message either implement the [OnMethodInvokeAsyncAdvice] advice or set the SemanticallyAdvisedMethodKinds property of the master advice to 'None'.` |

## Cause

An aspect built from advices intercepts a method with an <xref:PostSharp.Aspects.Advices.OnMethodInvokeAdvice> advice. For an async method, or a method returning an awaitable type such as <xref:System.Threading.Tasks.Task>, it can also have an <xref:PostSharp.Aspects.Advices.OnMethodInvokeAsyncAdvice> advice, which can await the end of the task. This is called semantic advising, and it is enabled by default by the <xref:PostSharp.Aspects.Advices.OnMethodInvokeBaseAdvice.SemanticallyAdvisedMethodKinds> property of the master advice.

When the aspect has no <xref:PostSharp.Aspects.Advices.OnMethodInvokeAsyncAdvice> advice, PostSharp falls back to the <xref:PostSharp.Aspects.Advices.OnMethodInvokeAdvice> advice, `<Advice>`, and reports LA0186 on the target method. <xref:PostSharp.Aspects.MethodInterceptionArgs.Proceed> then returns as soon as the method returns its task, at the first `await` that does not complete synchronously, so the code after it runs before the asynchronous operation ends. Aspects derived from <xref:PostSharp.Aspects.MethodInterceptionAspect> report <xref:la0185?text=LA0185> in the same situation.

## Resolution

* Add a public method with the signature of <xref:PostSharp.Aspects.IAsyncMethodInterceptionAspect.OnInvokeAsync(PostSharp.Aspects.MethodInterceptionArgs)> and the <xref:PostSharp.Aspects.Advices.OnMethodInvokeAsyncAdvice> attribute, and await <xref:PostSharp.Aspects.MethodInterceptionArgs.ProceedAsync> in it.
* When the advice must intercept only the call that starts the task, set the <xref:PostSharp.Aspects.Advices.OnMethodInvokeBaseAdvice.SemanticallyAdvisedMethodKinds> property of the <xref:PostSharp.Aspects.Advices.OnMethodInvokeAdvice> attribute to <xref:PostSharp.Aspects.SemanticallyAdvisedMethodKinds.None>.
