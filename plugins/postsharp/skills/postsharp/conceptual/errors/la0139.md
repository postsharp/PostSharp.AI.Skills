# LA0139: Field Imported into a Property Field

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot import "<Member>" into the aspect field "<AspectField>" because it is not a property. Only properties can be imported into a field of type Property<TValue> or Property<TValue,TIndex>.` |

## Cause

An aspect imports a property of its target class into a field of type <xref:PostSharp.Aspects.Advices.Property`1>, or an indexer into a field of type <xref:PostSharp.Aspects.Advices.Property`2>, with <xref:PostSharp.Aspects.Advices.ImportMemberAttribute> or with an <xref:PostSharp.Aspects.Advices.ImportLocationAdviceInstance>. At run time, the field holds delegates that call the accessors of the property, so PostSharp can only bind it to a property.

PostSharp looks up the member by name among the fields, properties and events of the target class, or takes the field or property that the <xref:PostSharp.Aspects.Advices.ImportLocationAdviceInstance> designates. It reports LA0139 when the member that it finds, `<Member>`, is a field or an event. The message is reported on the aspect field, `<AspectField>`.

## Resolution

* Change the member of the target class into a property, when you own this class.
* To import a field, implement <xref:PostSharp.Aspects.Advices.IAdviceProvider> and import the field with an <xref:PostSharp.Aspects.Advices.ImportLocationAdviceInstance> into an aspect field of type <xref:PostSharp.Aspects.ILocationBinding>, which accepts both fields and properties (see <xref:advice-provider>).
