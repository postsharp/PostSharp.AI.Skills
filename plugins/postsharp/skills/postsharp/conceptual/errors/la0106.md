# LA0106: Pointcut Returns an Object That Is Not a Declaration

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Error while evaluating the MethodPointcut "<PointcutMethod>" on "<AspectTarget>": the pointcut method returned an object of type "<ObjectType>", which is not a declaration. Return reflection objects such as Type, MethodInfo, FieldInfo, PropertyInfo, EventInfo, ParameterInfo or LocationInfo.` |

## Cause

A <xref:PostSharp.Aspects.Advices.MethodPointcut> selects the targets of an advice with a method of the aspect class. This method can return an <xref:System.Collections.Generic.IEnumerable`1> of <xref:System.Object>, but each object that it returns must be the reflection object of a declaration: a <xref:System.Reflection.Assembly>, a <xref:System.Type>, a <xref:System.Reflection.MethodBase>, a <xref:System.Reflection.FieldInfo>, a <xref:System.Reflection.PropertyInfo>, an <xref:System.Reflection.EventInfo>, a <xref:System.Reflection.ParameterInfo> or a <xref:PostSharp.Reflection.LocationInfo>. When the method returns another object, such as a string, PostSharp reports LA0106 on the pointcut method and skips the object.

The current version of PostSharp shows, in place of `<ObjectType>`, the type of the PostSharp declaration of the aspect target, such as `TypeDefDeclaration`, and not the type of the object that the pointcut method returned.
