# PS0090: Multicast Property Requests Unsupported Targets

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Invalid property <Property> for the multicast attribute "<AttributeType>" instantiated on <DeclarationKind> "<Declaration>": targets "<Targets>" are not supported by this custom attribute type.` |

## Cause

The <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute> of an aspect or of another multicast attribute type defines the declarations that the attribute can be applied to: the kinds of declarations in <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute.ValidOn>, and their visibility and scope in properties such as <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute.TargetMemberAttributes>. When you apply the attribute, you can narrow these targets with the properties of <xref:PostSharp.Extensibility.MulticastAttribute>, but you cannot extend them.

PostSharp reports PS0090 when one of the following properties of an instance of the attribute contains a value that the usage of the attribute type excludes. `<Property>` is the name of the property, and `<Targets>` lists the excluded values:

* <xref:PostSharp.Extensibility.MulticastAttribute.AttributeTargetElements> requests a kind of declaration that is not in <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute.ValidOn>, for example properties for an <xref:PostSharp.Aspects.OnMethodBoundaryAspect>, which targets methods and constructors.
* <xref:PostSharp.Extensibility.MulticastAttribute.AttributeTargetTypeAttributes>, <xref:PostSharp.Extensibility.MulticastAttribute.AttributeTargetMemberAttributes>, <xref:PostSharp.Extensibility.MulticastAttribute.AttributeTargetParameterAttributes>, or their counterparts for external assemblies, request a visibility, a scope or another attribute that the usage of the attribute type excludes.

`<DeclarationKind>` and `<Declaration>` are the declaration that the attribute is applied to. PostSharp then stops the build with <xref:ps0055?text=PS0055>, because it does not continue after an error in the multicast attributes. When the attribute is applied to the assembly, the message has no location in the source code.

## Resolution

* Remove the values that `<Targets>` lists from the property. To apply a method-level aspect to properties, target methods: the accessors of the properties are methods.
* When you wrote the attribute type, and it can support these targets, add them to its <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute>.
