# DOM008: OnPropertyChanged Method Is Missing

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Model |
| **Message** | `Class "<Class>" implements INotifyPropertyChanged but does not define a method with the signature void OnPropertyChanged(string propertyName), through which the [NotifyPropertyChanged] aspect raises the PropertyChanged event. The method can also be named NotifyOfPropertyChange or RaisePropertyChanged.` |

## Cause

When a class already implements <xref:System.ComponentModel.INotifyPropertyChanged>, by itself or through a base class, the <xref:PostSharp.Patterns.Model.NotifyPropertyChangedAttribute> aspect does not introduce the interface. It raises the existing <xref:System.ComponentModel.INotifyPropertyChanged.PropertyChanged> event through a method of the class instead, because only the class that declares an event can raise it.

The aspect looks for an instance method that returns `void` and takes a single `string` parameter, named `OnPropertyChanged`, `NotifyOfPropertyChange` or `RaisePropertyChanged`, in the class or in its base classes, with any visibility except `private` in a base class. When it finds none, it reports DOM008 on the class.

## Resolution

* Name the method that raises the event `OnPropertyChanged`, and give it the signature `void OnPropertyChanged(string propertyName)`. The names `NotifyOfPropertyChange` and `RaisePropertyChanged`, used by some MVVM frameworks, also work.
* Otherwise, remove the implementation of <xref:System.ComponentModel.INotifyPropertyChanged> from the class, and let the aspect implement the interface.
