# LA0061: Introduced Member Cannot Override a Non-Virtual or Sealed Member

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot introduce member "<Member>" into type "<TargetType>" because it is already defined in type "<DeclaringType>" and is not virtual or is sealed, so it cannot be overridden.` |

## Cause

When an aspect introduces a method, a property or an event with <xref:PostSharp.Aspects.Advices.IntroduceMemberAttribute> and sets its <xref:PostSharp.Aspects.Advices.IntroduceMemberAttribute.OverrideAction> to <xref:PostSharp.Aspects.Advices.MemberOverrideAction.OverrideOrFail>, PostSharp overrides the member when a base type of the target type already defines it. An override is only possible when the member of the base type is virtual and not sealed. Otherwise, PostSharp reports LA0061.

`<DeclaringType>` is the base type that defines the existing member. For a property or an event, PostSharp checks each accessor, so `<Member>` is the name of the accessor, such as `get_Name`.

## Resolution

* Make the member of the base type `virtual`, or remove the `sealed` modifier of its override, so that the introduced member can override it.
* When you cannot change the base type, set the <xref:PostSharp.Aspects.Advices.IntroduceMemberAttribute.OverrideAction> of the introduction to <xref:PostSharp.Aspects.Advices.MemberOverrideAction.OverrideOrIgnore>: PostSharp then skips the introduction instead of failing when the member cannot be overridden.
* Otherwise, rename the introduced member.
