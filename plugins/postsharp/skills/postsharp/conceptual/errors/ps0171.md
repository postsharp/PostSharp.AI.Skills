# PS0171: Strict Inheritance in the Usage of an Attribute That Targets Properties or Events

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Error in MulticastAttributeUsage applied on type '<AttributeType>': strict attribute inheritance is not supported on properties and events.` |

## Cause

Aspect inheritance makes PostSharp apply an aspect to the declarations that derive from the one where you apply it, as <xref:aspect-inheritance> describes. With <xref:PostSharp.Extensibility.MulticastInheritance.Strict> inheritance, an aspect on a method also applies to the methods that override or implement it. PostSharp does not support this on properties and events.

PostSharp reports PS0171 when the <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute> of an attribute class sets <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute.Inheritance> to <xref:PostSharp.Extensibility.MulticastInheritance.Strict>, and its <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute.ValidOn> includes <xref:PostSharp.Extensibility.MulticastTargets.Property> or <xref:PostSharp.Extensibility.MulticastTargets.Event>, alone or with other targets. The message is reported on the attribute class `<AttributeType>`, whether or not the attribute is applied to a property or an event. PostSharp then stops processing the multicast attributes and also reports <xref:ps0055?text=PS0055>.

## Resolution

* To apply the aspect to the properties or events of derived classes, use <xref:PostSharp.Extensibility.MulticastInheritance.Multicast> inheritance and apply the aspect to the base class: PostSharp copies the aspect to each derived class, then multicasts it to the members of the derived class, including the members that the base class does not have.
* Otherwise, remove <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute.Inheritance> from the usage, and apply the aspect to each property or event, including the overriding ones.
* When the aspect needs strict inheritance for methods, remove the properties and events from <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute.ValidOn>.
