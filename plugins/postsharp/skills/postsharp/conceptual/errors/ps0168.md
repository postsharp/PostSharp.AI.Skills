# PS0168: Member of an Unsupported Type Set in XML

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The type '<MemberType>' of member '<Element>.<Member>' cannot be set in an XML configuration file. Use a field or property of an intrinsic type, an enumeration, System.Type, or an array of these types.` |

## Cause

The `Multicast` element of a `postsharp.config` file adds aspects or other multicast attributes to the project without changing its source code, as <xref:xml-multicasting> describes. Each XML attribute of a child element sets the public field or property of the same name of the attribute class.

PostSharp can convert the text of an XML attribute only into the following types: the intrinsic types (`bool`, `char`, the integer and floating-point types, and `string`), enumerations, <xref:System.Type>, and arrays of these types. PostSharp reports PS0168 when the XML attribute sets a field or property of another type, for example <xref:System.TimeSpan>, <xref:System.DateTime>, <xref:System.Guid>, `decimal` or `object`. `<Element>` is the local name of the XML element, and `<Member>` is the name of the XML attribute. The location of the message is the XML attribute in the `postsharp.config` file.

## Resolution

* Replace the member by one of a supported type, and convert its value in the aspect: for example, an `int` number of milliseconds instead of a <xref:System.TimeSpan>, or a `string` that the aspect parses.
* Set the member in code instead, where the attribute is applied with C#, or initialize it in the aspect.

The formats of the supported types are described in <xref:configuration-serialization>.
