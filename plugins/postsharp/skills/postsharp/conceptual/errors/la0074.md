# LA0074: Invalid Type of an Imported Member Field

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Type of field "<Field>" is invalid. Valid types for fields annotated with [ImportMember] are: Delegate, Event<T>, Property<TValue>, Property<TValue,TIndex>.` |

## Cause

An aspect imports a member of its target class with a field annotated with <xref:PostSharp.Aspects.Advices.ImportMemberAttribute>. At run time, PostSharp does not copy the value of the member into this field: it assigns delegates that invoke the member. The type of the field therefore tells PostSharp which kind of member to import:

* a delegate type imports a method;
* <xref:PostSharp.Aspects.Advices.Property`1> imports a property, and <xref:PostSharp.Aspects.Advices.Property`2> an indexer;
* <xref:PostSharp.Aspects.Advices.Event`1> imports an event.

PostSharp reports LA0074 when the field has any other type, typically the type of the imported property itself.

## Resolution

Change the type of the field to the type that matches the kind of the imported member: a delegate with the signature of the method, <xref:PostSharp.Aspects.Advices.Property`1> or <xref:PostSharp.Aspects.Advices.Property`2> for a property or an indexer, or <xref:PostSharp.Aspects.Advices.Event`1> for an event. Then access the member through the delegates of the field, for example <xref:PostSharp.Aspects.Advices.Property`1.Get>.
