# LA0075: Imported Method Not Found in the Target Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot bind field "<Field>" to type "<TargetType>": cannot find a method named "<MethodName>" with signature "<Signature>" in type "<TargetType>" or its ancestors, or the method is not accessible from type "<TargetType>".` |

## Cause

An aspect imports a method of its target class with a field of a delegate type annotated with <xref:PostSharp.Aspects.Advices.ImportMemberAttribute>. PostSharp looks for a method with the name given to the attribute and with the signature of the `Invoke` method of the delegate, in the target type and in its base types. When the <xref:PostSharp.Aspects.Advices.ImportMemberAttribute.IsRequired> property is `true`, PostSharp reports LA0075 for each target type where it finds no such method. When <xref:PostSharp.Aspects.Advices.ImportMemberAttribute.IsRequired> is `false`, which is the default, the field stays `null` instead.

The method is not found in the following cases:

* No method has this name, for example because of a typo.
* The parameters or the return type of the method differ from those of the delegate. An `in` parameter of the delegate also requires an `in` parameter of the method, not a `ref` one.
* The method exists, but it is not accessible from the target type, for example a `private` method of a base class.

`<MethodName>` lists the names given to the attribute, and `<Signature>` is the signature of the delegate. PostSharp reports the error on the target type, not on the field of the aspect.

## Resolution

* Give the field a delegate type with the same parameters and return type as the method, for example <xref:System.Action`1> for a method that takes one parameter and returns `void`.
* Correct the name given to <xref:PostSharp.Aspects.Advices.ImportMemberAttribute>, or pass several names when the method can have one of several names.
* Make the method of the base class accessible to the target class, for example `protected` instead of `private`.
* When the aspect can work without the method, set <xref:PostSharp.Aspects.Advices.ImportMemberAttribute.IsRequired> to `false` and check that the field is not `null` before invoking it.
