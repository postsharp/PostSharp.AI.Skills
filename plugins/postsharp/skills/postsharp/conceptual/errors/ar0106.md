# AR0106: Experimental Declaration Used

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp |
| **Message** | `The project <Assembly> uses <Kind> <Declaration>, which is an experimental feature and can change in a future version.` |

## Cause

The <xref:PostSharp.Constraints.ExperimentalAttribute> constraint marks a type, a method or a field whose API is not stable yet. When PostSharp processes a project that uses the declaration from another assembly, it reports AR0106 once for each experimental declaration that the project uses. The message has no source location: it is reported on the assembly, not on the code that uses the declaration. `<Assembly>` is the full name of the assembly of the project. The check runs only when the using project is processed by PostSharp.

PostSharp also reports AR0106 when it processes the assembly that declares the experimental declaration, whether or not this assembly uses it. Library authors usually suppress the warning in their own assembly, as the following example does with an assembly-level <xref:PostSharp.Extensibility.SuppressWarningAttribute>.

AR0106 is always a warning: <xref:PostSharp.Constraints.ExperimentalAttribute> has no severity option.

## Resolution

* Use the stable API of the library instead of the experimental declaration.
* When you accept that the declaration can change, suppress the warning for the whole project with `[assembly: SuppressWarning( "AR0106" )]`, or add `AR0106` to the `PostSharpDisabledMessages` property of the project.
