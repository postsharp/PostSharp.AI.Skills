# PS0206: Attribute of XML Configuration in the PostSharp Namespace

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Invalid attribute "<AttributeName>" on the element "<ElementName>": only the Condition attribute can be in the namespace of the PostSharp configuration schema.` |

## Cause

Some elements of a `postsharp.config` file describe CLR objects in XML: the children of the `Multicast` element, which add aspects to the project, and the content of the `Logging` element. Each XML attribute of such an element, without a namespace prefix, sets the field or property of the same name. See <xref:configuration-serialization>.

The only attribute that can be in the namespace of the PostSharp configuration schema, `http://schemas.postsharp.org/1.0/configuration`, is `Condition`, often written `x:Condition`, which PostSharp evaluates instead of passing it to the object. PostSharp reports PS0206 on any other attribute in this namespace, and ignores the element. `<ElementName>` is the name of the element with its XML namespace in braces.
