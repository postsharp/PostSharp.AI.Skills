# LA0277: Delegate Passes a Struct by Reference to a Readonly Method

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [ImportMember] to the readonly method "<Method>" of a struct, but the first parameter of the delegate type "<DelegateType>" passes the struct as ref. A readonly method does not change the struct: declare the first parameter of the delegate as in.` |

## Cause

An advice parameter of a delegate type, marked with <xref:PostSharp.Aspects.Advices.ImportMemberAttribute> and a method name, receives an open delegate of a method of the target type. For an instance method of a struct, the first parameter of the delegate receives the struct by reference, so you declare a delegate type of your own. A `readonly` method receives the struct as `in`, because it does not change it, so the first parameter of the delegate must be `in`. Only a method that is not `readonly` accepts `ref`.

When no method of the name converts to the delegate type, and one of them would convert if the first parameter of the delegate were `in` instead of `ref`, PostSharp reports LA0277 on the target method, whatever the value of <xref:PostSharp.Aspects.Advices.ImportMemberAttribute.IsRequired>.
