# PS0285: Custom Attribute Rejected by Its Validation

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The custom attribute "<Attribute>" cannot be applied to "<Target>": <Reason>` |

## Cause

Any custom attribute, not only an aspect, can check at build time that it is applied to a valid declaration: it implements <xref:PostSharp.Extensibility.IValidableAnnotation>, and PostSharp calls its <xref:PostSharp.Extensibility.IValidableAnnotation.CompileTimeValidate(System.Object)> method for each declaration that it is applied to, with the reflection object of this declaration, such as a <xref:System.Reflection.MethodBase>. To reject the declaration with an error, the method throws an <xref:PostSharp.Extensibility.InvalidAnnotationException>. PostSharp then reports PS0285 on the declaration. `<Reason>` is the message of the exception.

When the method returns `false` instead, PostSharp ignores the attribute on this declaration without reporting anything. For an aspect, the same exception is reported as <xref:la0252?text=LA0252>.
