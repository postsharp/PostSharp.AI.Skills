# LA0085: Invalid Signature of an Advice Method

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Advice "<Advice>" is not valid on method "<Method>": the method does not have the signature that this advice requires.` |

## Cause

Each kind of advice requires a signature of the advice method. PostSharp reports LA0085 in the following cases:

* In a method boundary, method interception or location interception advice, such as <xref:PostSharp.Aspects.Advices.OnMethodEntryAdvice>, <xref:PostSharp.Aspects.Advices.OnMethodInvokeAdvice> or <xref:PostSharp.Aspects.Advices.OnLocationGetValueAdvice>, the first parameter has no binding attribute and is not of the legacy type of the advice: <xref:PostSharp.Aspects.MethodExecutionArgs>, <xref:PostSharp.Aspects.MethodInterceptionArgs> or <xref:PostSharp.Aspects.LocationInterceptionArgs>. A parameter without binding attribute after the first one causes <xref:la0208?text=LA0208> instead.
* In an event interception advice, such as <xref:PostSharp.Aspects.Advices.OnEventAddHandlerAdvice>, the method does not have exactly one parameter of type <xref:PostSharp.Aspects.EventInterceptionArgs>. These advices do not accept bound parameters.
* In a <xref:PostSharp.Aspects.Advices.LocationValidationAdvice>, the method does not have the signature of <xref:PostSharp.Aspects.ILocationValidationAspect`1.ValidateValue(`0,System.String,PostSharp.Reflection.LocationKind,PostSharp.Aspects.LocationValidationContext)>: four parameters, of which the last three are a <xref:System.String>, a <xref:PostSharp.Reflection.LocationKind> and a <xref:PostSharp.Aspects.LocationValidationContext>, and the return type <xref:System.Exception>.

`<Advice>` is the type of the advice attribute. Depending on the kind of advice, PostSharp reports the error on the advice method or on its invalid parameter.

## Resolution

* Add a binding attribute, such as <xref:PostSharp.Aspects.Advices.DeclarationNameAttribute> or <xref:PostSharp.Aspects.Advices.ArgumentAttribute>, to each parameter that receives a value of the target.
* In an advice that does not accept bound parameters, give the method the parameter of the legacy signature, for example <xref:PostSharp.Aspects.EventInterceptionArgs> for an event interception advice.
* In a <xref:PostSharp.Aspects.Advices.LocationValidationAdvice>, give the method the parameters and the return type of <xref:PostSharp.Aspects.ILocationValidationAspect`1.ValidateValue(`0,System.String,PostSharp.Reflection.LocationKind,PostSharp.Aspects.LocationValidationContext)>.
