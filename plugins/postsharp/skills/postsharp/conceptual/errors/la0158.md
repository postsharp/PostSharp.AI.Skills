# LA0158: Validation Advice Applied to a Read-Only Property

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `LocationValidationAdvice cannot be applied to property "<Property>" because it is read-only.` |

## Cause

A method of an aspect annotated with <xref:PostSharp.Aspects.Advices.LocationValidationAdvice> validates the values assigned to a field, a property or a parameter. For a property, PostSharp inserts the validation into the setter. When the property has no setter, PostSharp has no place to insert it and reports LA0158.

A get-only auto-property such as `public decimal Balance { get; }` has no setter: its constructor assigns the backing field directly, so PostSharp cannot validate the value either.

## Resolution

Choose one of the following fixes:

* Add a setter to the property. A `private` setter is enough: the validation runs each time the setter is called, also from the constructor.
* Validate the parameter of the constructor or of the method that receives the value, with an aspect that can target parameters, instead of the property.
* Remove the aspect from the property.
