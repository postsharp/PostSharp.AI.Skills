# DOM023: Property Depends on a Type That Does Not Notify Changes

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp.Patterns.Model |
| **Message** | `NotifyPropertyChangedAttribute: automatic analysis of property <Property> failed. Method <Method> depends on property <OtherProperty> of type <OtherType>, but neither this type nor any type derived from it implements the INotifyPropertyChanged interface or has the [NotifyPropertyChanged] aspect. To solve this message, add the [NotifyPropertyChanged] aspect to the <OtherType> type or make it implement the INotifyPropertyChanged interface. To ignore this message, add the [SafeForDependencyAnalysis] attribute to the property <Property>.` |

## Cause

The <xref:PostSharp.Patterns.Model.NotifyPropertyChangedAttribute> aspect analyzes the getter of each property to find what the property depends on. A dependency on a property of another object, in the form `this.Address.City`, is supported: the aspect subscribes to the <xref:System.ComponentModel.INotifyPropertyChanged.PropertyChanged> event of that object and raises the notification of the dependent property when `City` changes. This works only when the other object notifies its changes.

PostSharp reports DOM023 when `<OtherType>`, the type that declares `<OtherProperty>`, does not implement <xref:System.ComponentModel.INotifyPropertyChanged> and does not have the <xref:PostSharp.Patterns.Model.NotifyPropertyChangedAttribute> aspect, and no type derived from it does. `<Method>` is the getter of `<Property>`, or a method of the same class that the getter calls. The message is a warning: the build succeeds, but the dependent property is not notified when the other property changes.

## Resolution

* Add the <xref:PostSharp.Patterns.Model.NotifyPropertyChangedAttribute> aspect to `<OtherType>`, or implement <xref:System.ComponentModel.INotifyPropertyChanged> in it.
* When the value of `<OtherProperty>` never changes, or when you do not need the notification, add <xref:PostSharp.Patterns.Model.SafeForDependencyAnalysisAttribute> to `<Property>` to remove the warning.
