# LA0271: Requested Field Already Exists in the Target Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The aspect "<Aspect>" applied to "<Target>" attempts to introduce a field <Name>of type "<FieldType>" in "<TargetType>", but the field "<Field>" already exists, and the WhenCompatibleFieldExists property of the IntroduceFieldAdviceInstance is Fail. Set it to Ignore to skip the introduction and use this field, or to IntroduceAnother to introduce another field.` |

## Cause

An aspect attempts to introduce a field in its target type by returning an <xref:PostSharp.Aspects.Advices.IntroduceFieldAdviceInstance> from <xref:PostSharp.Aspects.Advices.IAdviceProvider.ProvideAdvices*>. Before introducing a new field, PostSharp looks for an existing field that matches the request, in the target type and in the accessible fields of its base types:

* When the request has a <xref:PostSharp.Aspects.Advices.IntroduceFieldAdviceInstance.Name>, the matching field has this name, the requested type, and the same static or instance kind.
* When the request has no name, a matching field has the requested type and kind, whatever its name. LA0271 is then reported when exactly one field matches; when several fields match, PostSharp reports <xref:la0273?text=LA0273> instead.

The <xref:PostSharp.Aspects.Advices.IntroduceFieldAdviceInstance.WhenCompatibleFieldExists> property of the request decides what happens with a matching field. Its default value, <xref:PostSharp.Aspects.Advices.IntroduceFieldCompatibleAction.Fail>, reports LA0271, so that the aspect does not silently share a field that the source code or another aspect uses. LA0271 is always an error.

`<Name>` is the requested name in quotes followed by a space, or nothing when the request has no name. `<Target>` is the declaration to which the aspect is applied, where the error is located, and `<Field>` is the field that matches.

## Resolution

Set the <xref:PostSharp.Aspects.Advices.IntroduceFieldAdviceInstance.WhenCompatibleFieldExists> property of the request to what the aspect must do with the existing field:

* <xref:PostSharp.Aspects.Advices.IntroduceFieldCompatibleAction.Ignore> makes the aspect use the existing field instead of introducing one. This is how the aspect shares a field with the source code or with other aspects.
* <xref:PostSharp.Aspects.Advices.IntroduceFieldCompatibleAction.IntroduceAnother> introduces another field and leaves the existing one alone. With a requested name, the new field gets this name followed by a number.

Otherwise, choose another name, or rename the existing field.
