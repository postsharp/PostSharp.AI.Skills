# PS0101: Hosted Invocation Requests Recursive Processing

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `This method does not support recursive module processing. Set the ProcessDependenciesFirst property to false.` |

## Cause

PS0101 does not concern projects that use PostSharp through its NuGet package and MSBuild. It concerns a program that hosts the PostSharp compiler itself, through the `IPostSharpObject` interface of the hosting API.

The `InvokeProject` method of `IPostSharpObject` processes a single project. Its argument, a `ProjectInvocation`, carries a `ProjectInvocationParameters` object whose `ProcessDependenciesFirst` property asks PostSharp to process the dependencies of the module before the module itself. `InvokeProject` does not support this, so it throws an <xref:System.ArgumentException> with the PS0101 message when the property is `true`, before it loads the project.

This message concerns a program that hosts the PostSharp compiler, not a project, so no example can show it.

## Resolution

In the program that hosts PostSharp, leave the `ProcessDependenciesFirst` property of the `ProjectInvocationParameters` to its default value, `false`. When the dependencies of the module must be processed by PostSharp too, invoke a project for each of them, before the module.
