# COM009: Struct Child Is Read-Only

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Aggregation |
| **Message** | `The field or property "<Member>" cannot be read-only because it is a [Child] of a struct type. Remove the readonly modifier of the field, or add a setter to the automatic property.` |

## Cause

A child of an <xref:PostSharp.Patterns.Model.AggregatableAttribute> class can be a struct when the struct implements <xref:PostSharp.Patterns.Model.IAttachable>. When PostSharp attaches the child to its parent, it calls <xref:PostSharp.Patterns.Model.IAttachable.AttachToParent*>, which stores the parent in the struct. A struct is a value, so attaching it changes the struct stored in the field, which a read-only field does not allow. PostSharp therefore reports COM009 when a field marked with <xref:PostSharp.Patterns.Model.ChildAttribute> has a struct type and is `readonly`, or when such an automatic property has only a getter, whose backing field is read-only.
