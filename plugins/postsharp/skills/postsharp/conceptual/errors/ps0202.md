# PS0202: No Constructor Matches the Arguments of an ObjectConstruction

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Invalid ObjectConstruction: cannot find a suitable constructor in type '<AspectType>' for arguments (<ArgumentTypes>).` |

## Cause

An aspect that implements <xref:PostSharp.Aspects.IAspectProvider> can add aspects to other declarations, as <xref:iaspectprovider> describes. Instead of an aspect object, the <xref:PostSharp.Aspects.AspectInstance> that it returns can hold an <xref:PostSharp.Reflection.ObjectConstruction>: the type of the aspect, the arguments of its constructor and the values of its properties, from which PostSharp builds the aspect as it would build a custom attribute.

PostSharp reports PS0202 when no constructor of the aspect class accepts the arguments of the <xref:PostSharp.Reflection.ObjectConstruction>: their number differs, an argument has a type that the parameter does not accept, or an argument is `null` for a parameter of a value type. `<AspectType>` is the assembly-qualified name of the aspect class, and `<ArgumentTypes>` lists the types of the arguments, empty when there is none. PS0202 has no location; PostSharp also reports <xref:la0117?text=LA0117>, which names the aspect provider and the target declaration.

## Resolution

Pass to the <xref:PostSharp.Reflection.ObjectConstruction> the arguments of one of the constructors of the aspect class, in the order and with the types of its parameters. Set the other values with the <xref:PostSharp.Reflection.ObjectConstruction.NamedArguments> of the object construction. Alternatively, create the aspect object yourself and pass it to the <xref:PostSharp.Aspects.AspectInstance> constructor.
