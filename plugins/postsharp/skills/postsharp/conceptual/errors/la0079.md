# LA0079: Aspect That Imports Members Is Not Instance-Scoped

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot use [ImportMember] in aspect "<Aspect>" because the aspect is not instance scoped.` |

## Cause

An aspect imports a member of its target class with a field annotated with <xref:PostSharp.Aspects.Advices.ImportMemberAttribute>. PostSharp assigns this field with delegates bound to one object of the target class, so each object needs its own instance of the aspect: the aspect must be instance-scoped.

An aspect is instance-scoped when it implements <xref:PostSharp.Aspects.IInstanceScopedAspect>, as <xref:PostSharp.Aspects.InstanceLevelAspect> does. Other aspects are static-scoped: a <xref:PostSharp.Aspects.TypeLevelAspect>, for example, has a single instance for the whole target class. PostSharp reports LA0079 on the aspect class when a static-scoped aspect has an <xref:PostSharp.Aspects.Advices.ImportMemberAttribute> field.
