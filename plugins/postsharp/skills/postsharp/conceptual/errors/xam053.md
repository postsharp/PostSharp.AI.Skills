# XAM053: Validation Method of a Dependency Property Not Found

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Xaml |
| **Message** | `Error in the [<Aspect>] aspect applied to property <Property>: type <DeclaringType> does not declare any method named "<Method>".` |

## Cause

The <xref:PostSharp.Patterns.Xaml.DependencyPropertyAttribute> and <xref:PostSharp.Patterns.Xaml.AttachedPropertyAttribute> aspects can validate the values assigned to the property with a method of the class. By default, they look for a method named `ValidateName`, where `Name` is the name of the property, and skip the validation when there is none. When you set the <xref:PostSharp.Patterns.Xaml.DependencyPropertyBaseAttribute.ValidateValueMethod> property, the method is required.

PostSharp reports XAM053 when the type that declares the property, `<DeclaringType>`, declares no method named `<Method>`, the value of <xref:PostSharp.Patterns.Xaml.DependencyPropertyBaseAttribute.ValidateValueMethod>. The aspect searches the methods of any visibility, static or instance, but only those that `<DeclaringType>` itself declares: a method inherited from a base class is not found. The usual causes are a misspelled name and a method that was renamed or moved to a base class.

## Resolution

Set <xref:PostSharp.Patterns.Xaml.DependencyPropertyBaseAttribute.ValidateValueMethod> to the name of a method declared in the same class as the property, preferably with the `nameof` operator, so that the compiler checks the name. When the validation method is in a base class, declare a method in the class of the property that calls it. The method must also have one of the signatures that <xref:dependency-property> lists, or PostSharp reports <xref:xam055?text=XAM055>.
