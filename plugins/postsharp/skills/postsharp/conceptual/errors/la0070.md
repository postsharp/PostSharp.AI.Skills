# LA0070: Introduced Method Conflicts with a Static Method

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot introduce method "<Method>" into type "<TargetType>" because it is already defined in type "<DeclaringType>" as a static method.` |

## Cause

When an aspect introduces a method with <xref:PostSharp.Aspects.Advices.IntroduceMemberAttribute> and sets its <xref:PostSharp.Aspects.Advices.IntroduceMemberAttribute.OverrideAction> to <xref:PostSharp.Aspects.Advices.MemberOverrideAction.OverrideOrFail> or <xref:PostSharp.Aspects.Advices.MemberOverrideAction.OverrideOrIgnore>, PostSharp replaces or overrides the method of the same name and signature that already exists. A static method can be neither replaced nor overridden by an introduced method, so PostSharp reports LA0070, for both override actions.

`<DeclaringType>` is the type that defines the static method: the target type itself, or one of its base types. For a property or an event, PostSharp checks each accessor, so `<Method>` is the name of the accessor, such as `get_Name`.

## Resolution

* Rename the static method or the introduced method.
* Set the <xref:PostSharp.Aspects.Advices.IntroduceMemberAttribute.OverrideAction> of the introduction to <xref:PostSharp.Aspects.Advices.MemberOverrideAction.Ignore> to skip the introduction whenever the method exists.
