# CAC010: Cached Method Has a ref or out Parameter

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Caching |
| **Message** | `Cannot add the [Cache] aspect to the <Method> method because it has a ref or out parameter.` |

## Cause

The <xref:PostSharp.Patterns.Caching.CacheAttribute> aspect stores the return value of a method, under a key built from its arguments. A method with a `ref` or `out` parameter also returns a value through this parameter, which the cache cannot store. PostSharp therefore reports CAC010 for a method with a `ref` or `out` parameter. An `in` parameter is accepted, because the method cannot assign it.

## Resolution

Return all the results of the method in its return value: a nullable value instead of the `Try` pattern, or a tuple or a record when the method has several results. Then apply the <xref:PostSharp.Patterns.Caching.CacheAttribute> aspect to this method. When you cannot change the method, cache another method that returns the value, and call it from the method that has the `ref` or `out` parameter.
