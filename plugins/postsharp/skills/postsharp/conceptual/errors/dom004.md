# DOM004: Pure Method Has a Parameter of a Mutable Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Model |
| **Message** | `Method <Method> contains parameters of non-intrinsic type. The [Pure] attribute can be applied only to methods with parameters of intrinsic types such as int or string.` |

## Cause

The <xref:PostSharp.Patterns.Model.PureAttribute> attribute tells the <xref:PostSharp.Patterns.Model.NotifyPropertyChangedAttribute> aspect that the result of a method depends only on its arguments, so that a property getter can call the method without the aspect analyzing it. The property then depends on the arguments of the call. This only holds when the arguments cannot change without being passed again, so PostSharp reports DOM004 when a pure method has a parameter of another type than:

* a primitive type, `string`, `decimal`, `DateTime`, an enum, or another value type of the `System` namespace;
* an array of these types;
* `object`, in which case the aspect assumes that the objects passed are immutable, and does not track their changes.

PostSharp checks every method marked with the attribute, also when you apply the attribute to a class, a struct or an assembly. It reports the message on the method.

## Resolution

* Pass the values that the method needs, of immutable types, instead of the object that holds them. The property then depends on each of these values.
* When the method depends on the state of an object, remove the <xref:PostSharp.Patterns.Model.PureAttribute> attribute, and move the logic into a method of the class of the property, which the aspect analyzes.
