# PS0169: Value in XML Cannot Be Converted to the Type of the Member

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Error parsing the value of member '<Element>.<Member>': cannot convert '<Value>' into type '<MemberType>'.` |

## Cause

The `Multicast` element of a `postsharp.config` file adds aspects or other multicast attributes to the project, as <xref:xml-multicasting> describes. Each XML attribute of a child element sets the public field or property of the same name of the attribute class, and PostSharp converts the text of the XML attribute into the type of this member.

PostSharp reports PS0169 when this conversion fails. `<Element>` is the local name of the XML element, `<Member>` the name of the XML attribute, `<Value>` its text, and `<MemberType>` the type of the member; for the intrinsic types, the message shows their IL name, such as `int32` for `int`. The location of the message is the XML attribute in the `postsharp.config` file. The usual causes are:

* A number contains a unit, a thousands separator or a decimal comma. PostSharp converts numbers with the <xref:System.Convert> class and the invariant culture.
* A Boolean is not `true` or `false`.
* The value of an enumeration is not the name or the number of one of its members.
* A <xref:System.Type> is not the name of a type that PostSharp can find.

## Resolution

Write the value in the format that <xref:configuration-serialization> gives for the type of the member: a number without unit in the invariant culture, `true` or `false`, enumeration members separated by `|` or `+`, an assembly-qualified type name, or array items separated by `;`.
