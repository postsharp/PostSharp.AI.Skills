# LA0284: Imported Member Requires a Name

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [ImportMember] without a member name, but a parameter of type "<ParameterType>" imports a member by name only. Specify the name of the member.` |

## Cause

Without a member name, <xref:PostSharp.Aspects.Advices.ImportMemberAttribute> selects a field or a property of the target type by its type. Some types of parameters give no type to select a member by, or import members that are always selected by name, as <xref:PostSharp.Aspects.Advices.ImportMemberAttribute> does on an aspect field:

* <xref:PostSharp.Aspects.ILocationBinding>, which reads and writes a field or a property of any type;
* <xref:PostSharp.Aspects.IMethodBinding>, which calls a method;
* <xref:PostSharp.Aspects.Advices.Property`1> and <xref:PostSharp.Aspects.Advices.Event`1>, which import a property or an event.

PostSharp reports LA0284 on the advice parameter when the attribute has none of these names, before it looks at any target.

## Resolution

* Specify the name of the member in the constructor of <xref:PostSharp.Aspects.Advices.ImportMemberAttribute>. When the targets name the member differently, give several names, in order of precedence.
* For a field or a property, you can instead use <xref:PostSharp.Aspects.ILocationBinding`1>, which selects the member by the type argument when there is no name.
