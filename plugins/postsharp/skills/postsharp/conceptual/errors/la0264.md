# LA0264: Several Methods Convert to the Delegate Type of an Imported Member

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [ImportMember], but several methods of the type "<TargetType>" convert to the delegate type "<DelegateType>": <Methods>. Use a delegate type whose parameter types are those of one of the methods.` |

## Cause

An advice parameter of a delegate type, marked with <xref:PostSharp.Aspects.Advices.ImportMemberAttribute> and a method name, receives an open delegate of a method of the target type. The delegate type selects the overload, as when C# converts a method group to a delegate type: a parameter of the delegate converts to a parameter of the method by an identity or reference conversion.

When several overloads convert, PostSharp selects the one whose parameter types are the more specific, as C# overload resolution does: a type is more specific than another when it converts to it by a reference conversion, for example `string` than `object`. When no overload is more specific than all the others, PostSharp reports LA0264 on the target method. `<Methods>` lists the overloads that convert. This happens with parameter types that do not convert to each other, such as two interfaces that a parameter type of the delegate implements, or with an instance method and a static method that both convert.
