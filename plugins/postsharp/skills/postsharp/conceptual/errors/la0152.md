# LA0152: Awaiter Parameter Not Passed by Reference or of a Wrong Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Incorrect type of the [Awaiter] parameter in "<Advice>". The parameter must be passed by reference and implement ICriticalNotifyCompletion or INotifyCompletion.` |

## Cause

An entry or resume advice of an async method can make the method await an awaiter of the aspect before it continues: the advice assigns the awaiter to a parameter annotated with <xref:PostSharp.Aspects.Advices.AwaiterAttribute> and sets its `[FlowBehavior]` parameter to <xref:PostSharp.Aspects.FlowBehavior.Yield?text=FlowBehavior.Yield>. The advice gives the awaiter to the method through the parameter, so the parameter must be passed by reference, as `out` or `ref`, and its type must be an awaiter, which implements <xref:System.Runtime.CompilerServices.INotifyCompletion> or <xref:System.Runtime.CompilerServices.ICriticalNotifyCompletion>. PostSharp reports LA0152 when the parameter is passed by value or when its type implements neither interface.

## Resolution

* Pass the `[Awaiter]` parameter as `out` or `ref`, and assign the awaiter in the advice.
* Give the parameter the type of an awaiter, such as the one that `Task.Yield().GetAwaiter()` returns, or a type of your own that implements <xref:System.Runtime.CompilerServices.INotifyCompletion>. A task is not an awaiter: use the awaiter that its `GetAwaiter` method returns.
