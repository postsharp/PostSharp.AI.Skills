# LA0260: No Member of the Imported Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [ImportMember] with IsRequired set to true, but the type "<TargetType>" has no accessible field or property that a parameter of type "<ParameterType>" can receive.` |

## Cause

An advice parameter annotated with <xref:PostSharp.Aspects.Advices.ImportMemberAttribute> without a member name receives the field or the property of the target type whose type matches the type of the parameter. The candidates are the fields and properties of the target type and the accessible ones of its base types, except indexers, constants and the fields generated by the compiler. A member matches when:

* the parameter is passed by value, and the type of the member can be assigned to `<ParameterType>` without a conversion other than boxing;
* the parameter is passed by reference, with `in`, `ref` or `out`, or is an <xref:PostSharp.Aspects.ILocationBinding`1>, and the member has exactly its type. A `ref` or `out` parameter also requires a field that is not read-only.

When no member matches, the parameter normally receives `null`, the default value, or a reference to a temporary variable. When <xref:PostSharp.Aspects.Advices.ImportMemberAttribute.IsRequired> is `true`, PostSharp reports LA0260 on each target instead. `<TargetType>` is the type to which the aspect is applied, or the type that declares the target member. When several members match, PostSharp reports <xref:la0283?text=LA0283>. When the advice uses a pointcut that skips the targets whose signature does not match, such as <xref:PostSharp.Aspects.Advices.MatchPointcut>, PostSharp skips the target instead of reporting the error.

## Resolution

* Add a field or a property of the expected type to the target type.
* Change the type of the advice parameter to a type that a member of the target type can be assigned to, or pass the parameter by value to accept boxing.
* Set <xref:PostSharp.Aspects.Advices.ImportMemberAttribute.IsRequired> to `false` if the advice can work with the default value.
* Otherwise, apply the aspect only to the types that have such a member.
