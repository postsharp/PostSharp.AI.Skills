# LA0016: Composition Aspect Applied to an Interface

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply a CompositionAspect (<Aspect>) to an interface (<Interface>).` |

## Cause

A <xref:PostSharp.Aspects.CompositionAspect> makes its target type implement one or more interfaces, and delegates their members to an implementation object that the aspect creates at run time. Only a class or a struct can hold this implementation, so PostSharp reports LA0016 when the target of the aspect is an interface.

Multicasting does not apply a <xref:PostSharp.Aspects.CompositionAspect> to interfaces, because the aspect targets only classes and structs. The message usually comes from an aspect that adds the composition aspect programmatically with <xref:PostSharp.Aspects.IAspectProvider>, without excluding interfaces from its targets. `<Aspect>` is the composition aspect, and `<Interface>` the interface that received it.

## Resolution

* In an <xref:PostSharp.Aspects.IAspectProvider>, provide the composition aspect only to the types that are not interfaces, for example by testing <xref:System.Type.IsInterface>.
* When you apply the aspect yourself, apply it to the classes that implement the interface instead of the interface.
