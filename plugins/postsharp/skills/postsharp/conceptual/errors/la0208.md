# LA0208: Advice Parameter Without Binding Attribute

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" has no advice parameter attribute. Only the first parameter of a method boundary or interception advice can be passed without attribute, and it must then be of the AdviceArgs type of the advice.` |

## Cause

An advice method receives each value that it needs through a parameter annotated with a binding attribute, such as <xref:PostSharp.Aspects.Advices.ArgumentAttribute> or <xref:PostSharp.Aspects.Advices.DeclarationNameAttribute>. The attribute tells PostSharp which value to pass. The only parameter that can have no binding attribute is the first parameter of a method boundary, method interception or location interception advice, which then receives the <xref:PostSharp.Aspects.AdviceArgs> object of the advice, for instance <xref:PostSharp.Aspects.MethodExecutionArgs>.

PostSharp reports LA0208 on a parameter without binding attribute in the following cases:

* The parameter is not the first parameter of a method boundary or interception advice, for instance when you add a parameter for an argument of the target method and forget the `[Argument]` attribute.
* The parameter belongs to an <xref:PostSharp.Aspects.Advices.OnInstanceConstructedAdvice>, which receives no <xref:PostSharp.Aspects.AdviceArgs> object, so even its first parameter needs a binding attribute.

The rules of an advice signature are described in [Rules of an advice signature](xref:advice-parameter-binding#rules-of-an-advice-signature).

## Resolution

* Add the binding attribute that selects the value of the parameter, for instance `[Argument( 0 )]` for the first argument of the target method. The table in [Binding attributes](xref:advice-parameter-binding#binding-attributes) lists the values that you can bind.
* Otherwise, remove the parameter.
