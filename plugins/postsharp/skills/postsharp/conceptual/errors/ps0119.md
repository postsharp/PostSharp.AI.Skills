# PS0119: Multicast Pointcut Selects Unsupported Kinds of Declarations

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Invalid MulticastPointcut attribute on the advice "<Advice>": this kind of advice cannot apply to the target(s) "<Targets>".` |

## Cause

A <xref:PostSharp.Aspects.Advices.MulticastPointcut> selects the declarations to which an advice of a composite aspect applies. Its <xref:PostSharp.Aspects.Advices.MulticastPointcut.Targets> property filters the kinds of declarations, but each kind of advice applies only to some of them, for example:

* <xref:PostSharp.Aspects.Advices.OnMethodEntryAdvice>, <xref:PostSharp.Aspects.Advices.OnMethodSuccessAdvice>, <xref:PostSharp.Aspects.Advices.OnMethodExceptionAdvice> and <xref:PostSharp.Aspects.Advices.OnMethodExitAdvice>: methods, instance constructors and static constructors.
* <xref:PostSharp.Aspects.Advices.OnMethodInvokeAdvice>: methods.
* <xref:PostSharp.Aspects.Advices.OnLocationGetValueAdvice> and <xref:PostSharp.Aspects.Advices.OnLocationSetValueAdvice>: fields and properties.
* <xref:PostSharp.Aspects.Advices.LocationValidationAdvice>: fields, properties, parameters and return values.
* <xref:PostSharp.Aspects.Advices.OnEventAddHandlerAdvice>, <xref:PostSharp.Aspects.Advices.OnEventRemoveHandlerAdvice> and <xref:PostSharp.Aspects.Advices.OnEventInvokeHandlerAdvice>: events.

PostSharp reports PS0119, on the advice method `<Advice>`, when <xref:PostSharp.Aspects.Advices.MulticastPointcut.Targets> contains other kinds. `<Targets>` lists the kinds that the advice does not support.

## Resolution

* Set <xref:PostSharp.Aspects.Advices.MulticastPointcut.Targets> to kinds that the advice supports, or do not set it: the advice then applies to every kind that it supports.
* To enhance the accessors of properties, use the advices of locations (<xref:PostSharp.Aspects.Advices.OnLocationGetValueAdvice>, <xref:PostSharp.Aspects.Advices.OnLocationSetValueAdvice>) with a pointcut that selects properties.
