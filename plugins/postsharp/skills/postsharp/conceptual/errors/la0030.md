# LA0030: Introduced Custom Attribute Has a Value That Cannot Be Stored

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot introduce the custom attribute <AttributeType> on <DeclarationKind> <Declaration>: the value of <Argument> cannot be stored in a custom attribute: <Reason>.` |

## Cause

A <xref:PostSharp.Aspects.CustomAttributeIntroductionAspect> adds a custom attribute to its target declaration. It describes the attribute with an <xref:PostSharp.Reflection.ObjectConstruction>: the constructor, the constructor arguments, and the named arguments that set fields or properties. PostSharp writes these values into the metadata of the assembly, as the C# compiler does for an attribute in the source code.

Custom attribute metadata can only store the values that C# accepts in an attribute: primitive types, strings, enumerations, <xref:System.Type>, and one-dimensional arrays of these types. When a parameter, a field or a property of the attribute has the type `object`, the value must still be of one of these types. <xref:PostSharp.Reflection.ObjectConstruction> checks only that the value is assignable to the parameter, so a value such as a <xref:System.TimeSpan>, a <xref:System.DateTime> or a <xref:System.Decimal> reaches the build and PostSharp reports LA0030.

`<Argument>` says which value fails: `constructor argument` and its position, or `Property` or `Field` and its name. `<Reason>` is the explanation of the serializer of custom attributes; for a type that cannot be stored, it starts with `Invalid image`, although the assembly is valid. PostSharp reports the message on the declaration that receives the attribute, not on the code of the aspect.

## Resolution

* Pass the value in a form that custom attribute metadata can store, and use the constructor of the attribute that converts it. For example, <xref:System.ComponentModel.DefaultValueAttribute> has a constructor that takes a <xref:System.Type> and a string.
* When you own the attribute class, add a constructor or a property of a supported type, for example the number of seconds as an `int`, and convert the value in the attribute.
