# THR036: Background Method in a Thread-Affine Class

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Threading |
| **Message** | `Cannot add [Background] to method "<Method>" because the [ThreadAffine] threading model is applied to the type "<Type>". Apply [Background] to a static method, or to a method of another type.` |

## Cause

The <xref:PostSharp.Patterns.Threading.ThreadAffineAttribute> threading model allows an object to be accessed only from the thread that created it. The <xref:PostSharp.Patterns.Threading.BackgroundAttribute> aspect executes a method in a thread of the thread pool. An instance method of a thread-affine object with this aspect would therefore always access the object from the wrong thread, so PostSharp reports THR036.

The check applies only to instance methods. A static method does not belong to an object, so it can have the <xref:PostSharp.Patterns.Threading.BackgroundAttribute> aspect.

## Resolution

* When the background work does not need the state of the object, make the method `static` and pass it the data it needs as parameters.
* Otherwise, move the background work to a method of another class that does not have the <xref:PostSharp.Patterns.Threading.ThreadAffineAttribute> threading model, and update the thread-affine object from its own thread when the work completes.
