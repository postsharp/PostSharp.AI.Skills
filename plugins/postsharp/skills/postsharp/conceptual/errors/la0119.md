# LA0119: Aspect Class Is Not Serializable

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Aspect type "<AspectType>" must be annotated with [PSerializable].` |

## Cause

PostSharp creates the aspect instances at build time and serializes them into the assembly, so that the run time gets them back with the state they had after build-time initialization. It chooses the serializer from the aspect class:

* the <xref:PostSharp.Aspects.Configuration.AspectConfiguration.SerializerType> of the configuration of the aspect, for example <xref:PostSharp.Aspects.Serialization.MsilAspectSerializer>;
* the PostSharp serializer, when the aspect class has the [<xref:PostSharp.Serialization.PSerializableAttribute>] attribute;
* the binary serializer of .NET, when the aspect class has the [<xref:System.SerializableAttribute>] attribute.

PostSharp reports LA0119 when the aspect class has none of them. The message is reported on the aspect class `<AspectType>`, for each aspect class that needs an instance at run time.

## Resolution

* Add [<xref:PostSharp.Serialization.PSerializableAttribute>] to the aspect class. Mark the fields that must not be serialized with [<xref:PostSharp.Serialization.PNonSerializedAttribute>].
* When the aspect has no state computed at build time, set the <xref:PostSharp.Aspects.Configuration.AspectConfiguration.SerializerType> of its configuration to <xref:PostSharp.Aspects.Serialization.MsilAspectSerializer>: PostSharp then generates code that creates the aspect at run time instead of serializing it.

Do not use [<xref:System.SerializableAttribute>] instead: it requires the binary serializer of .NET, which PostSharp does not allow by default, and PostSharp reports <xref:la0206?text=LA0206>. See <xref:binary-formatter-security>.
