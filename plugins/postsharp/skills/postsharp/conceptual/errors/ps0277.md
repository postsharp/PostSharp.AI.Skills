# PS0277: Copyright Notice of a Plug-In

| | |
|---|---|
| **Severity** | Info |
| **Reported by** | PostSharp |
| **Message** | `<Notice>` |

## Cause

A plug-in of PostSharp adds tasks to the PostSharp compiler, and each task can declare a copyright notice. At the end of the processing of a project, PostSharp writes one PS0277 message for each distinct copyright notice of the tasks that ran. `<Notice>` gives the names of these tasks, a colon, and the notice.

The tasks of PostSharp and of its pattern libraries declare no copyright notice, so you see this message only with a plug-in of another vendor. The message is informational: the build shows it only at a verbosity that includes informational messages.

This message depends on a third-party plug-in, so no example can show it.

## Resolution

No action is required. To hide the message, disable it with the `PostSharpDisabledMessages` MSBuild property, for example:

```xml
<PropertyGroup>
  <PostSharpDisabledMessages>$(PostSharpDisabledMessages),PS0277</PostSharpDisabledMessages>
</PropertyGroup>
```

See <xref:ignoring-warnings> for the other ways to disable a message.
