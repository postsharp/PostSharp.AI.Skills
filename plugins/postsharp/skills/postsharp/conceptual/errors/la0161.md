# LA0161: Debugger Enhancement Requested for an Unsupported Type

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp |
| **Message** | `No IDebuggerAspectEnhancer is available for "<Type>". RequiresDebuggerEnhancementAttribute will be ignored.` |

## Cause

PostSharp marks the code of its advices and aspects so that the debugger steps over the code that PostSharp generates. It does so with `RequiresDebuggerEnhancementAttribute`, an attribute of the `PostSharp.Aspects.Internals` namespace that the advice and aspect types of PostSharp carry. The attribute is internal to PostSharp: it is public only for technical reasons and is not part of the documented API.

When this attribute is applied to a type, PostSharp looks for a debugger enhancer that supports the type. Only the types of PostSharp and of its plug-ins have one. For any other type, PostSharp reports LA0161 on the type and ignores the attribute. The build goes on, and the program runs as without the attribute.
