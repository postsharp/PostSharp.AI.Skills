# THR016: Method of a Reader/Writer Synchronized Class Has No Access Level

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp.Patterns.Threading |
| **Message** | `Method "<Method>" must be annotated with the [Reader], [UpgradeableReader] or [Writer] custom attribute because the class "<Class>" has the [ReaderWriterSynchronized] aspect and the method can be invoked from outside the object. Without one of these attributes, the method acquires no lock.` |

## Cause

The <xref:PostSharp.Patterns.Threading.ReaderWriterSynchronizedAttribute> aspect lets several threads read an object at the same time, but gives exclusive access to a thread that modifies it. PostSharp cannot tell whether a method only reads the object or modifies it, so you declare it with a custom attribute: <xref:PostSharp.Patterns.Threading.ReaderAttribute>, <xref:PostSharp.Patterns.Threading.UpgradeableReaderAttribute> or <xref:PostSharp.Patterns.Threading.WriterAttribute>, or another attribute derived from <xref:PostSharp.Patterns.Threading.AccessLevelAttribute>.

PostSharp reports THR016 for a method without such an attribute that can be invoked from outside the object: a `public`, `internal` or `protected internal` method, a method that implements an interface, or a method with the <xref:PostSharp.Patterns.Threading.EntryPointAttribute> custom attribute. Property accessors are not reported: a getter acquires the read lock and a setter the write lock.

The method then acquires no lock. When run-time verification is enabled, which is the default in the debug configuration, an access to a field of the object from this method throws a <xref:PostSharp.Patterns.Threading.ThreadAccessException>; otherwise, the method accesses the object without synchronization.

## Resolution

Annotate the method with the attribute of the access it needs:

* <xref:PostSharp.Patterns.Threading.ReaderAttribute> for a method that only reads the object;
* <xref:PostSharp.Patterns.Threading.WriterAttribute> for a method that modifies it;
* <xref:PostSharp.Patterns.Threading.UpgradeableReaderAttribute> for a method that reads the object and may call a method that modifies it.

To annotate every method of the class at once, apply the attribute to the class. When the method synchronizes its accesses by itself, or does not access the object, apply the <xref:PostSharp.Patterns.Threading.ExplicitlySynchronizedAttribute> custom attribute to it instead.
