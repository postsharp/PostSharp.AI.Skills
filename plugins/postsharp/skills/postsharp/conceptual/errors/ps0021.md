# PS0021: Unsupported Attribute on a Task Element

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp |
| **Message** | `The attribute "<Attribute>" is not supported on the task "<Task>".` |

## Cause

PostSharp processes an assembly with a set of tasks. A `postsharp.config` file or a PostSharp project file (`.psproj`) can add a task or change its settings with an element under its `Tasks` element: the name of the element is the name of the task, `<Task>` in the message, and its attributes set the properties of the task.

PostSharp reports PS0021 for each attribute of a task element that is neither `Enabled` nor a property that the task can receive from the configuration. The names of these properties are not case-sensitive, but `Enabled` is. PostSharp ignores the attribute, and an attribute with an empty value is ignored without a warning. Every task accepts the `Enabled` and `Disabled` attributes, which disable the task when they are `false` and `true` respectively.

## Resolution

* When the attribute name is misspelled, correct it. The attributes of a task are the names of its configurable properties: see the documentation of the plug-in that defines the task.
* When the attribute belongs to another task, or to a former version of the task, remove it.
