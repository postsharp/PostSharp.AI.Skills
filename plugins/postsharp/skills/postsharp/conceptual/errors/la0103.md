# LA0103: Pointcut Returns a Property or Event That Cannot Be Found

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Error while evaluating the MethodPointcut "<PointcutMethod>" on "<AspectTarget>": cannot find the property or event "<Member>" of type "<DeclaringType>" in the current assembly or in the assemblies that it references. The pointcut method must return properties and events of the current assembly.` |

## Cause

A <xref:PostSharp.Aspects.Advices.MethodPointcut> selects the targets of an advice with a method of the aspect class. PostSharp runs this method at build time, for each declaration to which the aspect applies, and maps each <xref:System.Reflection.PropertyInfo> or <xref:System.Reflection.EventInfo> that it returns to a property or an event of the code model of the project. When it cannot find the declaring type `<DeclaringType>` or the member `<Member>` in the current assembly or in the assemblies that the project references, it reports LA0103 on the pointcut method and skips the member.

This happens when the pointcut method returns a member that exists only at build time, for instance an internal member of .NET: the pointcut method runs on the implementation assemblies of .NET, but the project compiles against reference assemblies, which contain only the public API. `<PointcutMethod>` is the pointcut method, and `<AspectTarget>` is the declaration to which the aspect applies.

Even when PostSharp finds the member, advices can only modify the code of the current assembly, so a pointcut method must return the properties and events of the current assembly.
