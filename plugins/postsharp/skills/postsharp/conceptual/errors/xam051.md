# XAM051: Dependency Property Is Static or Has a Private Getter

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Xaml |
| **Message** | `[DependencyProperty] cannot be applied to <Target>: the target must be an instance property whose getter is not private.` |

## Cause

A dependency property stores one value for each instance of the class that declares it, and the <xref:PostSharp.Patterns.Xaml.DependencyPropertyAttribute> aspect implements the getter and the setter of the target property by reading and writing this value. The aspect therefore requires an instance property whose getter is not private.

PostSharp reports XAM051 when the <xref:PostSharp.Patterns.Xaml.DependencyPropertyAttribute> aspect is applied to:

* a static property;
* a property whose getter is private;
* a field, which C# allows because the aspect is a location-level aspect.

## Resolution

* To store a value in each instance, remove the `static` modifier, and make the getter public, protected or internal.
* To define a property that you can set on objects of other classes, as `Grid.Column`, use the <xref:PostSharp.Patterns.Xaml.AttachedPropertyAttribute> aspect on a static property of type <xref:PostSharp.Patterns.Xaml.Attached`1> instead (see <xref:attached-property>).
* For a field, turn the field into an auto-implemented property.
