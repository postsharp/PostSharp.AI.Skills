# LA0048: Custom Pointcut Type Is Not Supported

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot find a weaver for the pointcut of type "<PointcutType>" used on "<Advice>". Use one of the pointcut types of PostSharp, such as MulticastPointcut or MethodPointcut, instead of a custom type.` |

## Cause

A pointcut is a custom attribute that selects the declarations to which an advice of an aspect applies. PostSharp evaluates each pointcut type that it defines, such as <xref:PostSharp.Aspects.Advices.MulticastPointcut> and <xref:PostSharp.Aspects.Advices.MethodPointcut>. The base class <xref:PostSharp.Aspects.Advices.Pointcut> is public, but deriving from it does not create a new kind of pointcut: PostSharp cannot evaluate the derived type, and reports LA0048.

`<PointcutType>` is the custom pointcut type, and `<Advice>` is the advice method that uses it. The message is reported on the declaration of the pointcut class, not on the advice.

PostSharp then ignores the custom pointcut. When the advice has no other pointcut, it applies to the target of the aspect itself, and PostSharp also reports <xref:la0049?text=LA0049> if the advice cannot apply to this kind of declaration, for example an <xref:PostSharp.Aspects.Advices.OnMethodEntryAdvice> in an aspect applied to a class.

## Resolution

Use a pointcut type of PostSharp:

* <xref:PostSharp.Aspects.Advices.MulticastPointcut> selects members by kind, name and attributes, such as visibility.
* <xref:PostSharp.Aspects.Advices.MethodPointcut> calls a method of the aspect that returns the declarations, for any selection logic that you write in C#.
