# DOM009: Class Defines a Member Reserved by the NotifyPropertyChanged Aspect

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Model |
| **Message** | `Class "<Class>" or one of its base classes already defines the ChildPropertyChanged event or the OnChildPropertyChanged(string) method, whose names the [NotifyPropertyChanged] aspect reserves. Rename the member.` |

## Cause

The <xref:PostSharp.Patterns.Model.NotifyPropertyChangedAttribute> aspect propagates the changes of child objects to their parents. For this purpose, it adds a `ChildPropertyChanged` event and an `OnChildPropertyChanged` method to the class, so these names are reserved for the aspect.

PostSharp reports DOM009 on a class with the aspect when the class, or one of its base classes, already defines an event named `ChildPropertyChanged`, of any type, or a method named `OnChildPropertyChanged` with a single `string` parameter. The check does not apply to a class whose base class has the aspect, because the members then come from the aspect of the base class.
