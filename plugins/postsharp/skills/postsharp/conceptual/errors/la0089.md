# LA0089: Introduced Indexer Conflicts with the Default Member of the Target Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot introduce the indexer "<Indexer>" into type "<TargetType>" because the DefaultMemberAttribute of the type names another member, "<DefaultMember>", and the OverrideAction of the introduction is "<OverrideAction>". Give the introduced indexer the name "<DefaultMember>" with IndexerNameAttribute, or set OverrideAction to Ignore.` |

## Cause

In .NET, an indexer is a property with parameters, and a type makes its indexers usable as indexers with <xref:System.Reflection.DefaultMemberAttribute>, which names the property. All the indexers of a type must have the same name. The C# compiler names them `Item`, or the name given by <xref:System.Runtime.CompilerServices.IndexerNameAttribute>, and adds the <xref:System.Reflection.DefaultMemberAttribute> itself.

When an aspect introduces an indexer with <xref:PostSharp.Aspects.Advices.IntroduceMemberAttribute> and the target type already has a <xref:System.Reflection.DefaultMemberAttribute> that names another member, PostSharp cannot make the introduced indexer an indexer of the type. When the <xref:PostSharp.Aspects.Advices.IntroduceMemberAttribute.OverrideAction> of the introduction is <xref:PostSharp.Aspects.Advices.MemberOverrideAction.Fail>, the default, or <xref:PostSharp.Aspects.Advices.MemberOverrideAction.OverrideOrFail>, PostSharp reports LA0089 on the indexer of the aspect.

`<OverrideAction>` shows `Default` for <xref:PostSharp.Aspects.Advices.MemberOverrideAction.Fail>, because both names have the same value.

## Resolution

* Give the introduced indexer the name of the indexers of the target type, with <xref:System.Runtime.CompilerServices.IndexerNameAttribute> on the indexer of the aspect.
* Otherwise, set the <xref:PostSharp.Aspects.Advices.IntroduceMemberAttribute.OverrideAction> of the introduction to <xref:PostSharp.Aspects.Advices.MemberOverrideAction.Ignore> or <xref:PostSharp.Aspects.Advices.MemberOverrideAction.OverrideOrIgnore>: PostSharp then skips the introduction of the indexer in this type.
