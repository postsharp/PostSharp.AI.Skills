# LA0210: Custom Binding Attribute Not Supported

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" has the advice parameter attribute "<Attribute>", which is not supported. Only the advice parameter attributes defined by PostSharp can be used.` |

## Cause

The binding attributes of advice parameters derive from <xref:PostSharp.Aspects.Advices.AdviceParameterAttribute>. PostSharp generates the code that computes the value of each binding attribute that it defines, such as <xref:PostSharp.Aspects.Advices.ArgumentAttribute> or <xref:PostSharp.Aspects.Advices.DeclarationNameAttribute>. It cannot compute a value for an attribute that your application derives from <xref:PostSharp.Aspects.Advices.AdviceParameterAttribute>, so it reports LA0210 on the parameter that has such an attribute. `<Attribute>` is the type of this attribute.

## Resolution

* Remove the parameter, and get the value in the body of the advice, for instance from a service or a static property of your application.
* When the value is one that PostSharp binds, use the binding attribute of PostSharp instead. The table in [Binding attributes](xref:advice-parameter-binding#binding-attributes) lists them.
