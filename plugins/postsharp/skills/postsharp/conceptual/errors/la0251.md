# LA0251: MatchPointcut Used by an Aspect Not Applied to a Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot use the MatchPointcut of the advice "<Advice>" on "<Target>". MatchPointcut selects methods of the target type of the aspect, so the aspect must be applied to a type.` |

## Cause

The <xref:PostSharp.Aspects.Advices.MatchPointcut> pointcut selects the methods with a given name that the target type of the aspect declares. It therefore requires an aspect applied to a type, such as a <xref:PostSharp.Aspects.TypeLevelAspect>. When the aspect is applied to another declaration, for instance a method with a <xref:PostSharp.Aspects.MethodLevelAspect> or the assembly with an <xref:PostSharp.Aspects.AssemblyLevelAspect>, PostSharp reports LA0251 on that declaration.

`<Advice>` is the advice method, with its parameter types, and `<Target>` is the declaration to which the aspect is applied.

## Resolution

* Derive the aspect from <xref:PostSharp.Aspects.TypeLevelAspect>, or from another aspect class applied to types, and apply it to the type that declares the methods.
* In an aspect applied to a method, remove the pointcut: an advice without pointcut applies to the target of the aspect.
* In an assembly-level aspect, use a <xref:PostSharp.Aspects.Advices.MethodPointcut>, or add type-level aspects with <xref:PostSharp.Aspects.IAspectProvider>.
