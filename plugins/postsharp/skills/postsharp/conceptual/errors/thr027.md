# THR027: Static Field Is Not of a Thread-Safe Type

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp.Patterns.Threading |
| **Message** | `Thread-safety policy: static field <Field> must be of a thread-safe type, or be marked as [ExplicitlySynchronized] or [ThreadStatic].` |

## Cause

A static field is shared by all threads. A `readonly` field always refers to the same object, but threads can still modify this object concurrently. When you add the <xref:PostSharp.Patterns.Threading.ThreadSafetyPolicy> attribute to an assembly, PostSharp therefore checks the type of the static fields of every class and reports THR027 when it is not thread-safe. A type is thread-safe for the policy when it has no instance fields, when it has a threading model, when it is marked as <xref:PostSharp.Patterns.Threading.ExplicitlySynchronizedAttribute>, or when the type analyzer of the threading library recognizes it as immutable, as `string` and the primitive types.

The collections of .NET, such as `Dictionary<TKey,TValue>`, have mutable fields and no threading model, so the policy reports static fields of these types, even when your code synchronizes the access to them.

The policy does not check constants, compiler-generated fields, fields marked as <xref:PostSharp.Patterns.Threading.ExplicitlySynchronizedAttribute> and fields marked as <xref:System.ThreadStaticAttribute>. A field of a type that is declared in a referenced assembly has a threading model only when PostSharp processed that assembly, and the policy does not see <xref:PostSharp.Patterns.Threading.ExplicitlySynchronizedAttribute> on a type of a referenced assembly.

## Resolution

* When every access to the field is synchronized in your code, for example with a `lock` statement, mark the field as <xref:PostSharp.Patterns.Threading.ExplicitlySynchronizedAttribute>.
* When the type of the field is declared in your project, apply a threading model to it.
* When each thread needs its own object, mark the field as <xref:System.ThreadStaticAttribute>.
