# LA0241: Required Return Value Not Available

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [ReturnValue] with IsRequired set to true, but "<TargetMethod>" has no return value that the advice can access: it returns void, returns a task without a result, returns by reference, or is an iterator.` |

## Cause

A parameter annotated with <xref:PostSharp.Aspects.Advices.ReturnValueAttribute> reads or sets the return value of the target method. When the target method has no return value that the advice can access, the parameter receives the default value of its type, and a value that the advice writes to it is ignored. When <xref:PostSharp.Aspects.Advices.ReturnValueAttribute.IsRequired> is `true`, PostSharp reports LA0241 on such a target method instead:

* In a method boundary advice, a method that returns `void`, a <xref:System.Threading.Tasks.Task> or a <xref:System.Threading.Tasks.ValueTask> without a result, or a reference (`ref` or `ref readonly`), and an iterator.
* In an <xref:PostSharp.Aspects.Advices.OnMethodInvokeAdvice>, a method that returns `void`.

## Resolution

* Apply the aspect only to methods that return a value. In a type-level aspect, a <xref:PostSharp.Aspects.Advices.MatchPointcut> skips the methods without a return value instead of reporting the error.
* Or, when the advice can do without the return value, set <xref:PostSharp.Aspects.Advices.ReturnValueAttribute.IsRequired> to `false`.
