# LA0280: Unsupported Type of an ImportMember Parameter

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [ImportMember], but its type "<ParameterType>" is not supported. A parameter bound by [ImportMember] receives a field or a property of the target type, as a value of the type of the member or as ILocationBinding<T> or ILocationBinding, a method, as a delegate whose first parameter receives the object or as IMethodBinding, an event as IEventBinding, or, in an instance advice of an instance-scoped aspect, a property as Property<T> or an event as Event<T>. Property<T, TIndex> is not supported.` |

## Cause

The type of an advice parameter annotated with <xref:PostSharp.Aspects.Advices.ImportMemberAttribute> selects what the parameter receives: the value of a field or a property, a location binding, a delegate or an <xref:PostSharp.Aspects.IMethodBinding> of a method, an <xref:PostSharp.Aspects.IEventBinding> of an event, or a <xref:PostSharp.Aspects.Advices.Property`1> or an <xref:PostSharp.Aspects.Advices.Event`1>. PostSharp reports LA0280 for a parameter of type <xref:PostSharp.Aspects.Advices.Property`2>, which would import an indexer. Indexers are not candidates of an import.
