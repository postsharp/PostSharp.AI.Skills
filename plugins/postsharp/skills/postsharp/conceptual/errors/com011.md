# COM011: Logging Activity Opened in an Async Lambda

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Common |
| **Message** | `Cannot call "<Method>" from "<Caller>" because the calling method is an anonymous async method. Move the call to a named async method.` |

## Cause

When an async method opens a custom activity with the `OpenActivity` method of <xref:PostSharp.Patterns.Diagnostics.Custom.LogLevelSource>, or with the `OpenActivity` and `OpenAsyncActivity` methods of the legacy `Logger` class, PostSharp adds an aspect to this method that tracks when the method is suspended at an `await` expression and when it resumes, so that the activity follows the asynchronous flow of the method. PostSharp can only instrument a method that it can select as an aspect target. The compiler generates the method of a lambda or of an anonymous method, so PostSharp cannot instrument it and reports COM011.

`<Method>` is the method that opens the activity. `<Caller>` is the anonymous method, named after the method that contains it followed by `.Anonymous`. The message has no file location.
