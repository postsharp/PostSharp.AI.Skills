# LA0166: Async Interception Applied to a Method That Does Not Return a Task

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply the aspect "<Aspect>" to target "<Target>": async interception supports only methods that return Task or Task<T>. To intercept other methods, the aspect must implement OnInvoke; when it does, set the UnsupportedTargetAction property of the aspect to Fallback to intercept this method with OnInvoke, or to Ignore to skip it.` |

## Cause

When a <xref:PostSharp.Aspects.MethodInterceptionAspect> overrides <xref:PostSharp.Aspects.MethodInterceptionAspect.OnInvokeAsync*>, PostSharp intercepts async methods with this advice, which awaits the <xref:System.Threading.Tasks.Task> or <xref:System.Threading.Tasks.Task`1> of the method. Async interception does not support the other async methods: those that return `void`, and those that return another awaitable type, such as <xref:System.Threading.Tasks.ValueTask> or <xref:System.Threading.Tasks.ValueTask`1>. PostSharp reports LA0166 in these cases:

* The target is such an async method, and the <xref:PostSharp.Aspects.MethodInterceptionAspect.UnsupportedTargetAction> of the aspect is `Fail`, its default value.
* The aspect overrides `OnInvokeAsync` but not <xref:PostSharp.Aspects.MethodInterceptionAspect.OnInvoke*>, and the target is a method that async interception does not support, async or not. Without `OnInvoke`, the aspect has no other way to intercept the method.

## Resolution

* When the aspect overrides `OnInvoke`, set the <xref:PostSharp.Aspects.MethodInterceptionAspect.UnsupportedTargetAction> property of the aspect:
  * <xref:PostSharp.Aspects.UnsupportedTargetAction.Fallback> intercepts the method with `OnInvoke`. The advice then intercepts the call that starts the method and returns its awaitable object, not the asynchronous execution of the method.
  * <xref:PostSharp.Aspects.UnsupportedTargetAction.Ignore> does not apply the aspect to the method.
* When the aspect overrides only `OnInvokeAsync`, override `OnInvoke` too, or do not apply the aspect to the method. Setting `UnsupportedTargetAction` alone does not help: `Fallback` reports <xref:la0171?text=LA0171> because there is no advice to fall back to.
* Make the method return a <xref:System.Threading.Tasks.Task> or a <xref:System.Threading.Tasks.Task`1>.
