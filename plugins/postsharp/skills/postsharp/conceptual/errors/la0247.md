# LA0247: Exception Parameter of the Wrong Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The [Exception] parameter "<Parameter>" of the advice "<Advice>" is of type "<ParameterType>". The parameter must be of type "System.Exception", or of type "object" when it is passed by value.` |

## Cause

An [<xref:PostSharp.Aspects.Advices.ExceptionAttribute>] parameter of an <xref:PostSharp.Aspects.Advices.OnMethodExceptionAdvice> receives the exception that the method throws, from a variable of type <xref:System.Exception>. The exception can be of any type, so the parameter cannot be of a derived type such as <xref:System.InvalidOperationException>. A parameter passed by value can also be of type <xref:System.Object>. A parameter passed as `out` or `ref` is the variable itself, so it must be exactly of type <xref:System.Exception>.

PostSharp reports LA0247 when the parameter `<Parameter>` of the advice `<Advice>` is of another type, `<ParameterType>`.

## Resolution

Declare the parameter as <xref:System.Exception>, or as <xref:System.Object> when it is passed by value. To handle only some types of exceptions, test the type of the exception in the advice, for instance with the `is` operator.
