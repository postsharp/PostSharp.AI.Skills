# XAM081: Execute Method of a Command Not Found

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Xaml |
| **Message** | `Error in the [Command] aspect applied to property <CommandProperty>: type <DeclaringType> does not contain any method named <ExecuteMethodName> or <AlternateExecuteMethodName>.` |

## Cause

The <xref:PostSharp.Patterns.Xaml.CommandAttribute> aspect implements the <xref:System.Windows.Input.ICommand.Execute(System.Object)> method of the command by calling a method of the view model. When the <xref:PostSharp.Patterns.Xaml.CommandAttribute.ExecuteMethod> property of the aspect is not set, the aspect follows a naming convention: for a command property named `<Name>Command` or `<Name>`, it looks for a method named `Execute<Name>`, `<ExecuteMethodName>` in the message, or `<Name>`, `<AlternateExecuteMethodName>`.

The aspect reports XAM081 when `<DeclaringType>`, the class of the command property, declares no method with either name. Methods inherited from a base class are not considered.

When <xref:PostSharp.Patterns.Xaml.CommandAttribute.ExecuteMethod> is set to the name of a method that does not exist, PostSharp reports <xref:xam071?text=XAM071> instead.

## Resolution

* Set the <xref:PostSharp.Patterns.Xaml.CommandAttribute.ExecuteMethod> property of the aspect to the name of the method that executes the command.
* Otherwise, rename the method to one of the names of the message, or add it to the class of the command property if it is missing or declared in a base class.
