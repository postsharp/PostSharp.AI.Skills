# COM018: Relationship Attribute on the Backing Field of a Value Property

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp.Patterns.Aggregation |
| **Message** | `The [<Attribute>] attribute applied to the backing field of the automatic property <Property> is ignored because the type of the property is a string, a delegate, or a value type.` |

## Cause

Strings, delegates and value types such as `int` or `DateTime` are values: they are never children, parents or references of an object model. A relationship attribute, <xref:PostSharp.Patterns.Model.ChildAttribute>, <xref:PostSharp.Patterns.Model.ParentAttribute> or <xref:PostSharp.Patterns.Model.ReferenceAttribute>, on a member of such a type is an error, <xref:com004?text=COM004>, when it is on the property. When the `field:` target applies it to the backing field of an automatic property, and the property has no relationship attribute, PostSharp ignores it and reports the warning COM018 instead.
