# LA0249: Type Requested for Ahead-of-Time Compilation Cannot Be Instantiated

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp |
| **Message** | `The type "<Type>" that the aspect "<Aspect>" requests with InstantiateTypeAdviceInstance is not instantiated, because <Reason>. An application compiled ahead of time may have no native code for this type.` |

## Cause

In an application compiled ahead of time, such as with NativeAOT, a generic type instance over a value type has native code only when the code of the application instantiates it. An aspect that creates such a type by reflection at run time returns an <xref:PostSharp.Aspects.Advices.InstantiateTypeAdviceInstance> from <xref:PostSharp.Aspects.Advices.IAdviceProvider.ProvideAdvices(System.Object)>, and PostSharp adds an instantiation of the type to the woven assembly, in a method that is never called.

The advice has an effect only when the MSBuild property `PostSharpAotCompatibleWeaving` is `true`, which is its default when the project sets `PublishAot`, `IsAotCompatible` or `EnableAotAnalyzer`. PostSharp then reports LA0249 and skips the type when it cannot write the instantiation. `<Reason>` tells why:

* The type is a generic type definition, contains generic parameters, or is an interface, an abstract class, an array, a pointer or a by-reference type.
* The type cannot be resolved in the woven module.
* The type is a class without a parameterless constructor.

PostSharp reports the warning on the aspect class, not on the code that returns the advice.

In the following example, the `[LogArguments]` aspect creates an `ArgumentFormatter<T>` for each parameter of the target method, but requests the generic type definition `ArgumentFormatter<>`. The `@Property(AotCompatibleWeaving=True)` directive sets the property as `PostSharpAotCompatibleWeaving` would.

## Resolution

Request the type that the aspect creates at run time:

* For a generic type, close it with the type arguments that the aspect uses, with <xref:System.Type.MakeGenericType*>, for instance with the type of a parameter of the target method.
* Request a concrete class with a parameterless constructor, or a structure. The constructor can have any accessibility, because the woven code never calls it.
