# LA0267: Property or Event Object Outside an Instance-Scoped Advice

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [ImportMember] and is of type "<ParameterType>", which is bound to one object. Property<T> and Event<T> are supported only on the instance advices of an instance-scoped aspect, whose aspect instance belongs to one object. Use ILocationBinding<T>, or import the event as a field of the aspect.` |

## Cause

An advice parameter of type <xref:PostSharp.Aspects.Advices.Property`1> or <xref:PostSharp.Aspects.Advices.Event`1> annotated with <xref:PostSharp.Aspects.Advices.ImportMemberAttribute> receives delegates that read and write a property, or add and remove handlers of an event, of one target object. PostSharp creates these objects once per target object, so only an advice that runs for one object can receive them: an instance method of an aspect that implements <xref:PostSharp.Aspects.IInstanceScopedAspect>, such as an <xref:PostSharp.Aspects.InstanceLevelAspect>, whose aspect instance belongs to one object.

PostSharp reports LA0267 in the following cases:

* The advice is a static method, even in an instance-scoped aspect.
* The aspect is statically scoped, for example a <xref:PostSharp.Aspects.MethodLevelAspect> that does not implement <xref:PostSharp.Aspects.IInstanceScopedAspect>: one aspect instance serves all the objects of the target type.

## Resolution

* Import the property as an <xref:PostSharp.Aspects.ILocationBinding`1>, which reads and writes the property of the object passed to its methods, typically received by a `[This]` parameter. It works in any advice. To read the value only, a parameter of the type of the property also works.
* Make the aspect instance-scoped by implementing <xref:PostSharp.Aspects.IInstanceScopedAspect>, and make the advice an instance method. See <xref:aspect-lifetime>.
* For an event in an <xref:PostSharp.Aspects.InstanceLevelAspect>, import the event into an <xref:PostSharp.Aspects.Advices.Event`1> field of the aspect instead.
