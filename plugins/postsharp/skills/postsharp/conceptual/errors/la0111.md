# LA0111: Aspect Stores a FieldInfo

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot serialize a FieldInfo into an aspect, because a field can be transformed into a property by the weaver. Use a LocationInfo instead.` |

## Cause

PostSharp serializes the aspects at build time, after their `CompileTimeInitialize` method, and deserializes them at run time. A field of the aspect can hold a reflection object, such as a <xref:System.Type> or a <xref:System.Reflection.MethodInfo>, but not a <xref:System.Reflection.FieldInfo>: when an aspect such as a <xref:PostSharp.Aspects.LocationInterceptionAspect> is applied to a field, the weaver turns the field into a property, so the field no longer exists at run time.

PostSharp reports LA0111 when it serializes a <xref:System.Reflection.FieldInfo> in an aspect, whether the aspect uses <xref:PostSharp.Serialization.PSerializableAttribute> or binary serialization. The error is reported on the assembly, without the location of the aspect, and the message does not name the aspect or the field: look for the fields of type <xref:System.Reflection.FieldInfo>, or of arrays and collections of it, in your aspects.

## Resolution

Store a <xref:PostSharp.Reflection.LocationInfo> instead of the <xref:System.Reflection.FieldInfo>. A <xref:PostSharp.Reflection.LocationInfo> represents a field, a property or a parameter, and remains valid when the weaver turns a field into a property. Create it with <xref:PostSharp.Reflection.LocationInfo.ToLocationInfo*> or <xref:PostSharp.Reflection.LocationInfo.ToLocationInfoArray*>.
