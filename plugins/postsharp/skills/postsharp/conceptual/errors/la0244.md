# LA0244: Required Current Task with an Awaiter in the Entry Advice

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [CurrentTask] with IsRequired set to true, but the entry advice "<EntryAdvice>" has an [Awaiter] parameter: when it yields on an awaiter that is already completed, the resume advice runs before the method has yielded, when the task does not exist yet.` |

## Cause

A [<xref:PostSharp.Aspects.Advices.CurrentTaskAttribute>] parameter receives the task that the caller of an async method observes. This task exists only once the method has yielded. With <xref:PostSharp.Aspects.Advices.CurrentTaskAttribute.IsRequired> set to `true`, the advice guarantees that the parameter is not `null`, which is accepted only in an <xref:PostSharp.Aspects.Advices.OnMethodResumeAdvice>, the advice that normally runs after the method has yielded.

An <xref:PostSharp.Aspects.Advices.OnMethodEntryAdvice> with an [<xref:PostSharp.Aspects.Advices.AwaiterAttribute>] parameter breaks this guarantee. It can set <xref:PostSharp.Aspects.FlowBehavior.Yield?text=FlowBehavior.Yield> and give an awaiter that is already completed. The method then does not suspend: the resume advice runs at once, in the same step of the state machine, before the method has yielded and before the task exists. PostSharp reports LA0244 on the `<Parameter>` parameter of the resume advice `<Advice>` when an entry advice `<EntryAdvice>` of the same advice group has an [<xref:PostSharp.Aspects.Advices.AwaiterAttribute>] parameter, whatever awaiter it gives at run time.

## Resolution

Remove <xref:PostSharp.Aspects.Advices.CurrentTaskAttribute.IsRequired> from the [<xref:PostSharp.Aspects.Advices.CurrentTaskAttribute>] parameter, and handle a `null` task in the resume advice. When the advice cannot do without the task, read it in another advice that runs later, such as the success or exit advice of an execution that has yielded, or remove the [<xref:PostSharp.Aspects.Advices.AwaiterAttribute>] parameter from the entry advice.
