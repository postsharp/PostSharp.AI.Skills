# LA0107: Instance Advice Applied to a Static Member

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply an instance advice of the instance-scoped aspect "<Aspect>" to the static member "<Member>" (make the advice static).` |

## Cause

An instance-scoped aspect, such as an <xref:PostSharp.Aspects.InstanceLevelAspect> applied to a class, has one instance for each instance of its target class. An advice method that is not static runs on this aspect instance. A static member, such as a static property, is not related to any instance of the class, so no aspect instance exists to run the advice.

When the pointcut of an instance advice method selects a static member, PostSharp reports LA0107 on that member. This often happens with a <xref:PostSharp.Aspects.Advices.MulticastPointcut> that sets only <xref:PostSharp.Aspects.Advices.MulticastPointcut.Targets>, which selects the static members as well as the instance ones.

## Resolution

* Exclude the static members from the pointcut, for instance with `Attributes = MulticastAttributes.Instance` in the <xref:PostSharp.Aspects.Advices.MulticastPointcut>, or by filtering them out in the method of a <xref:PostSharp.Aspects.Advices.MethodPointcut>.
* Or make the advice method static, as the message suggests, when it does not use the state of the aspect instance. PostSharp does not report LA0107 for a static advice method.
