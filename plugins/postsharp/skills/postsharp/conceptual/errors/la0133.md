# LA0133: Type-Level Aspect on the Module Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The aspect "<Aspect>" cannot be applied to the "<Module>" special type.` |

## Cause

Every module of .NET has a special type named `<Module>`, which holds the global fields and methods of the module and its module initializer. It is not a class of the program, so a type-level aspect, such as a <xref:PostSharp.Aspects.TypeLevelAspect>, cannot be applied to it.

Multicasting never selects this type, and <xref:System.Reflection.Assembly.GetTypes*> does not return it. PostSharp reports LA0133 when an aspect provider, an implementation of <xref:PostSharp.Aspects.IAspectProvider>, gets the `<Module>` type in another way, for example from its metadata token, and returns an <xref:PostSharp.Aspects.AspectInstance> for it. The message has no location: look for the aspect provider that adds the aspect named in the message.
