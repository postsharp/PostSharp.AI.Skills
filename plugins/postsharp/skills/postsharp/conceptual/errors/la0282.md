# LA0282: Instance Field Imported by Reference on a Static Target

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [ImportMember] and passed by reference to the instance field "<Field>", but "<Target>" is static and has no instance. Pass the parameter by value, which receives the default value on a static target.` |

## Cause

An advice parameter annotated with <xref:PostSharp.Aspects.Advices.ImportMemberAttribute> and passed as `in`, `ref` or `out` receives a reference to a field of the target object. When the advice is applied to a static member, there is no target object, so an instance field has no storage that the parameter could reference, and PostSharp reports LA0282 on the static member.

A parameter passed by value does not cause this error: on a static target, it receives the default value of an instance member.

## Resolution

Choose one of the following:

* Make the field static, when its value does not belong to one object. A static field can be imported by reference on any target.
* Do not apply the aspect to static members. When you apply it with multicasting, exclude them with `AttributeTargetMemberAttributes = MulticastAttributes.Instance`.
* Pass the parameter by value, when the advice only reads the field and can accept the default value on a static target.
