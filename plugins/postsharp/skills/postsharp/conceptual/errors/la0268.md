# LA0268: Field Requested in a Type That Cannot Have Fields

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The aspect "<Aspect>" applied to "<Target>" attempts to introduce a field with IntroduceFieldAdviceInstance, but a field cannot be introduced into "<TargetType>". Fields can be introduced into classes and structs only.` |

## Cause

An aspect attempts to introduce a field by returning an <xref:PostSharp.Aspects.Advices.IntroduceFieldAdviceInstance> from <xref:PostSharp.Aspects.Advices.IAdviceProvider.ProvideAdvices*>. The field goes into the *target type*: the type to which the aspect is applied, or the type that declares the member to which it is applied. Only a class or a struct can receive the field. PostSharp reports LA0268 when the target type is an interface, an enum or a delegate, and when the aspect is applied to an assembly, which has no target type; `<TargetType>` is then the assembly.

`<Target>` is the declaration to which the aspect is applied, where the error is located.

## Resolution

Apply the aspect to a class or a struct, or to a member of a class or a struct. When the aspect is meant for the implementations of an interface, apply it to the methods of the classes that implement the interface.
