# LA0196: Aspect Cannot Semantically Advise an Async Iterator

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply aspect "<Aspect>" to method "<Method>": this aspect does not support semantic advising of C# 8 async iterator methods. Set the UnsupportedTargetAction property of the aspect to Fallback or Ignore to suppress this error.` |

## Cause

An async iterator is a method that is both `async` and an iterator: it returns <xref:System.Collections.Generic.IAsyncEnumerable`1> or <xref:System.Collections.Generic.IAsyncEnumerator`1> and contains both `await` and `yield return`. By default, PostSharp applies method-level aspects to such a method semantically, that is, to the code that you wrote rather than to the method that creates the enumerator (see <xref:semantic-advising>). Some advices are not supported by semantic advising of async iterators:

* the <xref:PostSharp.Aspects.OnMethodBoundaryAspect.OnYield(PostSharp.Aspects.MethodExecutionArgs)> and <xref:PostSharp.Aspects.OnMethodBoundaryAspect.OnResume(PostSharp.Aspects.MethodExecutionArgs)> advices of an <xref:PostSharp.Aspects.OnMethodBoundaryAspect>, which run at each `await`;
* the <xref:PostSharp.Aspects.MethodInterceptionAspect.OnInvokeAsync(PostSharp.Aspects.MethodInterceptionArgs)> advice of a <xref:PostSharp.Aspects.MethodInterceptionAspect>.

When the aspect implements one of these advices and its <xref:PostSharp.Aspects.Aspect.UnsupportedTargetAction> property is <xref:PostSharp.Aspects.UnsupportedTargetAction.Fail>, which is the default, PostSharp reports LA0196 on the target method instead of applying the aspect. When the aspect defines its advices as advice methods instead of overriding them, PostSharp reports <xref:la0197?text=LA0197>.

## Resolution

* Set the <xref:PostSharp.Aspects.Aspect.UnsupportedTargetAction> property of the aspect, where you apply it or in its constructor:
  * <xref:PostSharp.Aspects.UnsupportedTargetAction.Fallback> applies the aspect non-semantically: the aspect runs when the method is called and creates the async enumerator, not during the enumeration, and `OnYield` and `OnResume` are not called. A <xref:PostSharp.Aspects.MethodInterceptionAspect> then intercepts the method with its `OnInvoke` advice.
  * <xref:PostSharp.Aspects.UnsupportedTargetAction.Ignore> skips the aspect for this method.
* For an <xref:PostSharp.Aspects.OnMethodBoundaryAspect>, remove the `OnYield` and `OnResume` advices if you do not need them: PostSharp then applies the other advices semantically to the async iterator.
* Exclude async iterators from the methods that the aspect targets.
