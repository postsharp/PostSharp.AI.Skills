# XAM075: Ambiguous Execute or CanExecute Method of a Command

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Xaml |
| **Message** | `Error in the [Command] aspect applied to property <Property>: type <Type> contains more than one method named "<Name>" or "<AlternateName>". Keep a single method with these names.` |

## Cause

The <xref:PostSharp.Patterns.Xaml.CommandAttribute> aspect binds a command to exactly one `Execute` method and at most one `CanExecute` method of its class. For a `SaveCommand` property, it looks by default for a method named `ExecuteSave` or `Save`, and for a method named `CanExecuteSave` or `CanSave`. When you set the <xref:PostSharp.Patterns.Xaml.CommandAttribute.ExecuteMethod> or <xref:PostSharp.Patterns.Xaml.CommandAttribute.CanExecuteMethod> property, it looks for this name only.

PostSharp reports XAM075 on the command property when the class declares more than one method with these names, whatever their signatures: two methods that each follow one of the conventions, or overloads of the same method. When the name comes from an aspect property, `<AlternateName>` is empty.

## Resolution

* Rename the methods that do not implement the command, so that only one method of the class has one of the names that the message shows.
* When the command method has overloads, keep a single method with this name, with zero parameters or one parameter that receives the command parameter.
