# LA0183: Aspect Applied to a Virtual Method of Another Assembly

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp |
| **Message** | `Applying the aspect "<Aspect>" to the virtual external method "<Method>" may lead to unexpected behavior. Applying OnMethodBoundaryAspect, OnExceptionAspect, or MethodInterceptionAspect to external virtual methods is not fully supported.` |

## Cause

An aspect can enhance the methods of a referenced assembly when you multicast it with the <xref:PostSharp.Extensibility.MulticastAttribute.AttributeTargetAssemblies> property, or when an <xref:PostSharp.Aspects.IAspectProvider> provides it. PostSharp does not modify the other assembly: it replaces the calls that the current assembly makes to the method with calls to a generated method that runs the aspect. With a virtual method, the implementation that runs is chosen at run time, and the calls that do not come from the current assembly, such as the calls that the library makes to its own method, do not run the aspect. PostSharp therefore warns with LA0183 when an <xref:PostSharp.Aspects.OnMethodBoundaryAspect>, an <xref:PostSharp.Aspects.OnExceptionAspect> or a <xref:PostSharp.Aspects.MethodInterceptionAspect> targets a virtual method of another assembly, and applies the aspect anyway.

`<Method>` is the virtual method. The message has no location in the source code.

## Resolution

* Exclude the virtual methods: set <xref:PostSharp.Extensibility.MulticastAttribute.AttributeTargetExternalMemberAttributes> to <xref:PostSharp.Extensibility.MulticastAttributes.NonVirtual>. <xref:PostSharp.Extensibility.MulticastAttribute.AttributeTargetMemberAttributes> does not filter the members of other assemblies.
* When you own the library, apply the aspect in the library itself, where PostSharp enhances the method itself instead of the calls.
* When the behavior at the call sites of the current assembly is what you need, keep the aspect and disable the warning with the `PostSharpDisabledMessages` MSBuild property.
