# CAC006: Null or Empty Method Name in [InvalidateCache]

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Caching |
| **Message** | `Invalid [InvalidateCache] aspect on <Method>: the constructor parameters cannot contain a null or empty string.` |

## Cause

The <xref:PostSharp.Patterns.Caching.InvalidateCacheAttribute> aspect removes from the cache the values of the cached methods whose names you pass to its constructor. PostSharp looks up each name in the type that declares these methods. When one of the names is `null` or an empty string, PostSharp cannot look it up and reports CAC006. It stops validating the aspect at this point, so it does not check the other names.

`<Method>` is the invalidating method, the one to which the aspect is applied. PostSharp reports the message on the declaration of this method.

## Resolution

Pass only the names of cached methods to the <xref:PostSharp.Patterns.Caching.InvalidateCacheAttribute> aspect, and remove the null or empty ones. Prefer the `nameof` operator to string literals: the C# compiler then checks that each name exists.
