# LA0228: Several Arguments Match an Argument Selected by Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [Argument] to an argument of its type, but several parameters of "<TargetMethod>" match: <MatchingParameters>. Select the argument by its index or by its name, or set the AmbiguityResolution property.` |

## Cause

The <xref:PostSharp.Aspects.Advices.ArgumentAttribute> constructor without parameter selects the argument of the target method by its type: the argument whose type can be assigned to the type of the advice parameter without conversion, except boxing. When several parameters of the target method match, the <xref:PostSharp.Aspects.Advices.ArgumentAttribute.AmbiguityResolution> property decides which one is bound. Its default value, <xref:PostSharp.Aspects.Advices.ArgumentAmbiguityResolution.Error>, reports LA0228 rather than choosing an argument that the aspect may not expect.

`<MatchingParameters>` lists the names of the matching parameters of `<TargetMethod>`. PostSharp reports the message on the target method, not on the advice, and once for each target method where the ambiguity occurs. A parameter of type <xref:System.Object> matches every parameter of the target method.

## Resolution

* Select the argument by its name with the <xref:PostSharp.Aspects.Advices.ArgumentAttribute.%23ctor(System.String)> constructor, or by its index with the <xref:PostSharp.Aspects.Advices.ArgumentAttribute.%23ctor(System.Int32)> constructor.
* Set <xref:PostSharp.Aspects.Advices.ArgumentAttribute.AmbiguityResolution> to <xref:PostSharp.Aspects.Advices.ArgumentAmbiguityResolution.First> or <xref:PostSharp.Aspects.Advices.ArgumentAmbiguityResolution.Last> to bind the first or the last matching argument, in the order of the parameter list.
* Make the type of the advice parameter more specific, so that only one parameter of the target method matches it.
