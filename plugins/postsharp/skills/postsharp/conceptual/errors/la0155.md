# LA0155: FlowBehavior Parameter Not Passed by Reference or of a Wrong Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Incorrect type of the [FlowBehavior] parameter in "<Advice>". The parameter must be passed by reference and be of type "PostSharp.Aspects.FlowBehavior".` |

## Cause

An advice changes the control flow of the target method by setting a parameter annotated with <xref:PostSharp.Aspects.Advices.FlowBehaviorAttribute>, for instance to <xref:PostSharp.Aspects.FlowBehavior.Return?text=FlowBehavior.Return> or <xref:PostSharp.Aspects.FlowBehavior.Yield?text=FlowBehavior.Yield>. The woven code reads the value after the advice returns, so the parameter must be passed by reference, as `out` or `ref`, and be of type <xref:PostSharp.Aspects.FlowBehavior>. PostSharp reports LA0155 when the parameter is passed by value or has another type, such as `int`. A value set to a parameter passed by value would be lost when the advice returns.
