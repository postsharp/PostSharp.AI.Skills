# DOM030: IgnoreAutoChangeNotification Applied to a Method

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp.Patterns.Model |
| **Message** | `Usage of <Attribute> on "<Method>" is deprecated. <Reason> This warning may become an error in a future version.` |

## Cause

The <xref:PostSharp.Patterns.Model.IgnoreAutoChangeNotificationAttribute> attribute, applied to a property, prevents the <xref:PostSharp.Patterns.Model.NotifyPropertyChangedAttribute> aspect from raising the change notifications of this property. For historical reasons, the attribute can also be applied to a method. The aspect then accepts the calls to the method without analyzing them, so the properties whose getters call the method lose the dependencies that the method hides.

PostSharp reports DOM030 on each method that has the attribute. `<Attribute>` is `[IgnoreAutoChangeNotification]`, and `<Reason>` is `The attribute should not be used on methods.`

## Resolution

Remove the attribute from the method. Then, depending on what the method does:

* When the method belongs to the same class, the aspect analyzes it and finds its dependencies.
* When the method depends only on its arguments, mark it with <xref:PostSharp.Patterns.Model.PureAttribute>.
* Otherwise, add <xref:PostSharp.Patterns.Model.SafeForDependencyAnalysisAttribute> to the properties that call the method, and declare their dependencies with <xref:PostSharp.Patterns.Model.Depends.On*>.
