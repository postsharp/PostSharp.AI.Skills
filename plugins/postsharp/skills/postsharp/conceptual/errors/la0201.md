# LA0201: Introduced Member Copies an Internal Attribute into Another Assembly

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot copy the internal attribute "<AttributeType>" to "<Target>", which is in another assembly. Make the attribute public, or remove it from the member of the aspect.` |

## Cause

When an aspect introduces a member with <xref:PostSharp.Aspects.Advices.IntroduceMemberAttribute>, PostSharp copies some custom attributes of the member of the aspect onto the introduced member:

* the attributes of the member itself that <xref:PostSharp.Aspects.Advices.CopyCustomAttributesAttribute> selects;
* all the attributes of the parameters, of the return value and of the generic parameters of an introduced method.

The introduced member belongs to the target type. When the target type is in another assembly than the aspect, and the type of a copied attribute is not visible from there, for example because it is `internal`, the target assembly would reference a type that it cannot access. PostSharp reports LA0201 instead.

`<AttributeType>` is the attribute type. `<Target>` is the introduced member for the attributes selected by <xref:PostSharp.Aspects.Advices.CopyCustomAttributesAttribute>, and the target type for the attributes of parameters, return values and generic parameters. When `<Target>` is an introduced member, the message has no file and line, because the member has no source code: look for the aspect that introduces it.

## Resolution

* Make the attribute type `public`, so that every assembly that uses the aspect can see it.
* Otherwise, remove the attribute from the member of the aspect, or from the <xref:PostSharp.Aspects.Advices.CopyCustomAttributesAttribute> that selects it. The attributes of parameters, return values and generic parameters are always copied, so removing them is the only way to keep them internal.
