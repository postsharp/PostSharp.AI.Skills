# LA0047: Custom Advice Type Is Not Supported

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot find a weaver for the advice of type "<AdviceType>". Use one of the advice types of PostSharp instead of a custom type.` |

## Cause

An advice is a member of an aspect class that PostSharp weaves into the target code. PostSharp knows how to weave each advice type that it defines, such as <xref:PostSharp.Aspects.Advices.OnMethodEntryAdvice> or <xref:PostSharp.Aspects.Advices.IntroduceInterfaceAdviceInstance>. The base classes <xref:PostSharp.Aspects.Advices.Advice> and <xref:PostSharp.Aspects.Advices.AdviceInstance> are public, but deriving from them does not create a new kind of advice: PostSharp has no weaver for the derived type, and reports LA0047.

PostSharp reports the message in two cases:

* A member of the aspect class has a custom attribute derived from <xref:PostSharp.Aspects.Advices.Advice>. The message is reported on this member.
* The <xref:PostSharp.Aspects.Advices.IAdviceProvider.ProvideAdvices*> method of the aspect returns an object of a custom class derived from <xref:PostSharp.Aspects.Advices.AdviceInstance>. The message is reported on the aspect class.

`<AdviceType>` is the custom advice type.

## Resolution

Use an advice type of PostSharp. The behavior that you meant to add belongs in the method of the advice, not in its type: for example, <xref:PostSharp.Aspects.Advices.OnMethodEntryAdvice> runs the method of the aspect before each method that its pointcut selects. To provide advices from code, return the advice instances of PostSharp from <xref:PostSharp.Aspects.Advices.IAdviceProvider.ProvideAdvices*>.
