# THR042: ExplicitlySynchronized Applied Only to the Backing Field of an Automatic Property

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp.Patterns.Threading |
| **Message** | `The [ExplicitlySynchronized] attribute is applied to the backing field of the automatic property <Property> but not to the property, and has no effect, because the threading model reads it from the property. Apply the attribute to the property, or set the <MSBuildProperty> MSBuild property to True to read the annotations of an automatic property and of its backing field as one.` |

## Cause

The <xref:PostSharp.Patterns.Threading.ExplicitlySynchronizedAttribute> attribute tells the threading model of a class that you synchronize a declaration yourself, so that the threading model neither locks nor verifies it. On an automatic property, the threading models read the attribute from the property. With the `field:` target, C# applies the attribute to the compiler-generated backing field instead, where the threading models do not read it.

When the threading model of a class analyzes its fields, it reports THR042 for each backing field that has the attribute while its automatic property does not. The property is then treated as if it had no attribute. `<MSBuildProperty>` is `PostSharpUnifiedAutomaticPropertyAnnotations`.

## Resolution

* Apply the attribute to the property itself, without the `field:` target.
* Alternatively, set the `PostSharpUnifiedAutomaticPropertyAnnotations` MSBuild property to `True` in the project. PostSharp then reads the attributes of an automatic property and of its backing field as one set, so `[field: ExplicitlySynchronized]` has the effect of the attribute on the property. This setting also changes how other attributes of automatic properties are read, for example `[field: Child]` of the PostSharp.Patterns.Aggregation library.

```xml
<PropertyGroup>
    <PostSharpUnifiedAutomaticPropertyAnnotations>True</PostSharpUnifiedAutomaticPropertyAnnotations>
</PropertyGroup>
```
