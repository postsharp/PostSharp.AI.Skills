# LA0254: Method Interception Advice on an Abstract Method

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp |
| **Message** | `The advice "<Advice>" is applied to the abstract method "<Method>". PostSharp gives the method an implementation that throws NotSupportedException, unless another aspect implements the method, so the advice gets this exception when it proceeds, and the overrides of the method in derived classes are not intercepted. If the aspect is applied by multicasting, set the AttributeTargetMemberAttributes property of the aspect, or the TargetMemberAttributes property of its MulticastAttributeUsage, to MulticastAttributes.NonAbstract. If an aspect provider or a pointcut selects the method, exclude abstract methods from its selection.` |

## Cause

A method interception advice, declared with <xref:PostSharp.Aspects.Advices.OnMethodInvokeAdvice> in a composite aspect such as a <xref:PostSharp.Aspects.MethodLevelAspect>, can be applied to an abstract method of the current project, by multicasting, by an <xref:PostSharp.Aspects.IAspectProvider> or by a pointcut. PostSharp then gives the abstract method an implementation, which the advice intercepts. This rarely does what you expect:

* Calls to the method are dispatched to the overrides of the derived classes, which PostSharp does not intercept, so the advice does not run.
* When the advice runs, for example when no derived class overrides the method, the implementation that it proceeds to throws <xref:System.NotSupportedException>, unless another aspect implements the method.

PostSharp reports this warning on the abstract method. `<Advice>` is the advice method of the aspect.

## Resolution

Exclude the abstract methods from the targets of the advice:

* When the aspect is applied by multicasting, set the <xref:PostSharp.Extensibility.MulticastAttribute.AttributeTargetMemberAttributes> property of the aspect, or the <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute.TargetMemberAttributes> property of its <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute>, to <xref:PostSharp.Extensibility.MulticastAttributes.NonAbstract>.
* When an aspect provider or a pointcut selects the method, skip the abstract methods in its selection.

To intercept the overrides, apply the aspect to the derived classes, for example by setting the <xref:PostSharp.Extensibility.MulticastAttribute.AttributeInheritance> property of the aspect to <xref:PostSharp.Extensibility.MulticastInheritance.Multicast>.
