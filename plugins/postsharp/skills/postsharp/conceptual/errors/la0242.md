# LA0242: Current Task Required in an Advice That Runs Before the Method Yields

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [CurrentTask] with IsRequired set to true, but the advice can run before the method yields, when the task does not exist yet. Only an OnMethodResumeAdvice always runs after the method has yielded.` |

## Cause

A parameter annotated with <xref:PostSharp.Aspects.Advices.CurrentTaskAttribute> receives the task that the caller of the async method observes. This task exists only once the method has yielded, that is, once one of its `await` expressions has suspended it. Before, the parameter is `null`: in the entry advice, in the first yield advice, and in all the advices of an execution that completes without yielding.

When <xref:PostSharp.Aspects.Advices.CurrentTaskAttribute.IsRequired> is `true`, the parameter must never be `null`. Only an <xref:PostSharp.Aspects.Advices.OnMethodResumeAdvice> always runs after the method has yielded, so PostSharp reports LA0242 on the parameter when it is in any other advice. The error does not depend on the target methods.

## Resolution

* Move the parameter to an <xref:PostSharp.Aspects.Advices.OnMethodResumeAdvice>. If the entry advice of the same aspect has an <xref:PostSharp.Aspects.Advices.AwaiterAttribute> parameter, the resume advice can also run before the method yields, and PostSharp reports <xref:la0244?text=LA0244>.
* Or set <xref:PostSharp.Aspects.Advices.CurrentTaskAttribute.IsRequired> to `false`, and handle a `null` task in the advice.
