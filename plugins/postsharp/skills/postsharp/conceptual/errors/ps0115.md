# PS0115: Contradictory Dependencies Between Two Aspects

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Conflicting aspects on "<Declaration>": according to aspect dependencies, transformation "<Transformation1>" should be located both before and after transformation "<Transformation2>".` |

## Cause

An aspect class can have several dependencies, for example an <xref:PostSharp.Aspects.Dependencies.AspectRoleDependencyAttribute> for a role and an <xref:PostSharp.Aspects.Dependencies.AspectTypeDependencyAttribute> for an aspect type. When PostSharp compares two transformations on the same declaration, it looks for the dependencies of the first one, with the <xref:PostSharp.Aspects.Dependencies.AspectDependencyAction.Order> or <xref:PostSharp.Aspects.Dependencies.AspectDependencyAction.Require> action and a position, that match the second one. It reports PS0115 when two of these dependencies give opposite positions, `Before` and `After`.

This usually happens when the other aspect matches two dependencies in different ways: by its type and by a role that it provides, or by a role and by an effect. PostSharp follows the error with an informational message that lists the dependencies of both transformations.

## Resolution

Keep the dependency that describes the order you want, and remove or reverse the other one. When the second aspect matches both dependencies by accident, for example because it provides a role that you did not expect, make one of the dependencies more specific.
