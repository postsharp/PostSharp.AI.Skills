# LA0086: Advice Named by the Master Property Not Found

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The Master property of the custom attribute "<Advice>" on "<Method>" names "<Master>", but this name gives no group: no advice of the same family has this name, or the Master properties form a cycle. Set the Group property instead: Master is obsolete.` |

## Cause

The advices of a family, for example the method boundary advices <xref:PostSharp.Aspects.Advices.OnMethodEntryAdvice> and <xref:PostSharp.Aspects.Advices.OnMethodExitAdvice>, are grouped so that PostSharp weaves them as one transformation. An advice selects its group with the <xref:PostSharp.Aspects.Advices.GroupingAdvice.Group> property. The <xref:PostSharp.Aspects.Advices.GroupingAdvice.Master> property, which selects the group of the advice method that it names, is obsolete, and the C# compiler reports its use with the warning CS0618. It keeps working, and <xref:PostSharp.Aspects.Advices.GroupingAdvice.Group> is its replacement.

PostSharp reports LA0086 when the name given to <xref:PostSharp.Aspects.Advices.GroupingAdvice.Master> leads to no group: no advice of the same family is applied to a method of this name, because the name has a typo, the method has no advice attribute, or its advice belongs to another family; or the <xref:PostSharp.Aspects.Advices.GroupingAdvice.Master> properties of several advices name each other in a cycle. `<Master>` is the value of the property, `<Advice>` the type of the advice attribute that sets it, and `<Method>` the advice method that carries this attribute.

In the following example, the `OnExit` advice names `OnEnter` in its <xref:PostSharp.Aspects.Advices.GroupingAdvice.Master> property, but the entry advice of the aspect is `OnEntry`. The `#pragma` directive disables the warning CS0618 about the obsolete property.

## Resolution

* Remove <xref:PostSharp.Aspects.Advices.GroupingAdvice.Master>, when the class of the advice has only one group that has no advice of its kind: PostSharp then puts the advice in this group.
* Otherwise, replace <xref:PostSharp.Aspects.Advices.GroupingAdvice.Master> with <xref:PostSharp.Aspects.Advices.GroupingAdvice.Group>, and set the same name on all the advices of the group.

In the following example, the `OnExit` advice has no <xref:PostSharp.Aspects.Advices.GroupingAdvice.Master> property any more. The group of `OnEntry` is the only group of the class, so `OnExit` joins it, and the pointcut of `OnEntry` applies both advices to the methods of `OrderService`.
