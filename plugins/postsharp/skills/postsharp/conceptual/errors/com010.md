# COM010: Range Contract Cannot Be Satisfied by the Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Common |
| **Message** | `[<Attribute>] cannot be applied to "<Target>" because no value of the type <Type> is within its range.` |

## Cause

The range contracts, <xref:PostSharp.Patterns.Contracts.RangeAttribute> and the attributes derived from it such as <xref:PostSharp.Patterns.Contracts.GreaterThanAttribute>, <xref:PostSharp.Patterns.Contracts.LessThanAttribute> or <xref:PostSharp.Patterns.Contracts.StrictlyGreaterThanAttribute>, check at run time that a value is between a minimum and a maximum. At build time, PostSharp compares the bounds with the range of the type of the field, property or parameter, ignoring `Nullable<T>`. When the minimum is greater than the largest value of the type, or the maximum is smaller than its smallest value, every assignment would fail, so PostSharp reports COM010.

`<Attribute>` is the name of the contract class, `<Target>` the field, property or parameter, and `<Type>` the name of its type.

## Resolution

* Change the type of the field, property or parameter to a type that can hold the values of the range, for example `short` or `int` instead of `byte`.
* Otherwise, correct the bounds of the contract so that they fall within the range of the type.
