# LA0083: Imported Event Has Another Delegate Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot bind field "<Field>" to event "<Event>": the event type is incompatible with the field type.` |

## Cause

An aspect imports an event of its target class with a field of type <xref:PostSharp.Aspects.Advices.Event`1> annotated with <xref:PostSharp.Aspects.Advices.ImportMemberAttribute>. PostSharp finds the event by its name, then compares its delegate type with the type argument of the field. The two types must be the same: a delegate type with the same signature, such as `EventHandler<PropertyChangedEventArgs>` for a <xref:System.ComponentModel.PropertyChangedEventHandler> event, is not accepted.

When they differ, PostSharp reports LA0083 on the target type, not on the field of the aspect. The severity depends on the <xref:PostSharp.Aspects.Advices.ImportMemberAttribute.IsRequired> property: an error when it is `true`, a warning when it is `false`, which is the default. After the warning, PostSharp still binds the field to the event.
