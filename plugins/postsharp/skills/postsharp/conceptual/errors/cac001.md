# CAC001: Cached Method Does Not Return a Value

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Caching |
| **Message** | `Cannot add the [Cache] aspect to the <Method> method because it does not return a value: its return type is "void" or "Task".` |

## Cause

The <xref:PostSharp.Patterns.Caching.CacheAttribute> aspect stores the return value of a method in the cache, and returns the stored value instead of executing the method again when it is called with the same arguments. A method that returns `void` has no value to store, and neither has an asynchronous method that returns the non-generic `Task`. PostSharp therefore reports CAC001 when you apply the aspect to such a method.

## Resolution

* Make the method return the value that you want to cache, and let the caller use it. For an asynchronous method, return `Task<T>` instead of `Task`.
* If the method performs an action rather than computing a value, remove the `[Cache]` aspect: there is nothing to cache.
