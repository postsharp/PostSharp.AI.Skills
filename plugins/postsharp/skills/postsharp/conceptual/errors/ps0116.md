# PS0116: Aspect Initialization Method of the Base Class Is Not Virtual

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The method "<Method>" must be virtual and not sealed, because PostSharp needs to override it in the type "<DerivedType>" to initialize aspects.` |

## Cause

To initialize the instance-scoped aspects of a class, PostSharp generates two methods without parameters in this class, `InitializeAspects` and `OnInstanceConstructed`, and calls them from the constructors. `OnInstanceConstructed` exists when an aspect has an <xref:PostSharp.Aspects.Advices.OnInstanceConstructedAdvice>. The methods are protected and virtual, so that a derived class that has aspects of its own overrides them and calls the method of its base class.

When a class already defines a method with one of these names and signatures, PostSharp uses it instead of generating one. When a derived class `<DerivedType>` needs the method and the base class defines it, PostSharp must override the method of the base class. It reports PS0116, on the method of the base class, when this method `<Method>` is not virtual or is sealed.

## Resolution

* Make the method of the base class `protected virtual`, and do not seal it in an intermediate class. PostSharp then overrides it in the derived class: the override calls the method of the base class and then the advices of the aspects. Note that PostSharp then calls your method after each constructor of the derived class.
* Otherwise, rename the method of the base class, so that PostSharp generates its own methods.
