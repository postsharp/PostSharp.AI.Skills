# SR0013: Serializer of the Base Type Is Sealed

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Class '<BaseSerializer>' cannot be sealed because the serializer of type '<Type>' must derive from it.` |

## Cause

[<xref:PostSharp.Serialization.PSerializableAttribute>] generates a serializer class for the type `<Type>`. When `<Type>` derives from a class that has its own serializer, the generated serializer derives from this serializer, so that the fields of the base class are serialized by the code written for them.

The serializer of the base class is the class named by its [<xref:PostSharp.Serialization.SerializerAttribute>] attribute, or its nested class named `Serializer`. PostSharp reports SR0013, on the serializer class `<BaseSerializer>`, when this class is sealed.

## Resolution

Its <xref:PostSharp.Serialization.ReferenceTypeSerializer.SerializeObject> and <xref:PostSharp.Serialization.ReferenceTypeSerializer.DeserializeFields> methods must not be sealed either, or PostSharp reports <xref:sr0012?text=SR0012>.
