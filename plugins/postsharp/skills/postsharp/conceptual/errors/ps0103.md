# PS0103: MulticastAttributeUsage Inheritance Specified Twice

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `On type "<Type>", cannot override the <Property> property of [MulticastAttributeUsage] because a base type already specifies it.` |

## Cause

An attribute class inherits the <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute> of its base classes. PostSharp combines the usages from the root base class down to the attribute class: most properties can only be restricted by a derived class (see <xref:ps0072?text=PS0072>), but the <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute.Inheritance> property, which says whether the attribute is inherited by derived classes and overriding members (see <xref:multicast-inheritance>), can be set only once in the class hierarchy. PostSharp reports PS0103 when a class sets `Inheritance` in its `[MulticastAttributeUsage]` although a base class already sets it, even to the same value.

`<Type>` is the class whose `[MulticastAttributeUsage]` sets the property again, and `<Property>` is `Inheritance`. Because PostSharp cannot know where the attribute applies, it also stops with <xref:ps0055?text=PS0055>.

## Resolution

* When the aspect classes derived from a base class need different inheritance modes, remove the `Inheritance` property from the `[MulticastAttributeUsage]` of the base class, and set it in each derived class.
* When the inheritance mode of the base class suits the derived class, remove the `Inheritance` property from the `[MulticastAttributeUsage]` of the derived class.
* To change the inheritance of a single usage of the aspect, set the <xref:PostSharp.Extensibility.MulticastAttribute.AttributeInheritance> property where you apply the aspect, instead of changing the class.
