# XAM080: Manually Implemented Command Property Without Getter or Setter

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Xaml |
| **Message** | `Error in the [Command] aspect applied to property <CommandProperty>: a manually implemented command property must have both a getter and a setter. Add a setter, which can be private, or make the property automatic.` |

## Cause

The <xref:PostSharp.Patterns.Xaml.CommandAttribute> aspect assigns the command object that it creates to the command property through the setter of the property. The view reads it through the getter.

The aspect reports XAM080 when the command property is implemented manually, with accessor bodies, and has no getter or no setter. The accessors can have any visibility. Automatic properties are not subject to this check.
