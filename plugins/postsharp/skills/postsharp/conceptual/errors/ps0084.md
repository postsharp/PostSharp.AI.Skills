# PS0084: Project Could Not Be Initialized

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The project could not be initialized because of the previous errors.` |

## Cause

Before it processes an assembly, the PostSharp compiler sets up the project: it instantiates the services and the tasks that the configuration files, such as `postsharp.config` or a `.psproj` file, and the plug-ins define, and reads the attributes of each task. When the build has reported an error by the end of this setup, PostSharp reports PS0084, which stops the build.

PS0084 is a consequence: the cause is in the errors that PostSharp reports with it. The common ones come from a `Tasks` section of a configuration file:

* <xref:ps0079?text=PS0079>: an element names a task that no plug-in defines.
* <xref:ps0082?text=PS0082>: an element does not set an attribute that the task requires.
* <xref:ps0075?text=PS0075>: the `Compile` element sets `SignAssembly` without a private key.
