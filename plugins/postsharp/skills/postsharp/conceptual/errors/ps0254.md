# PS0254: Invalid Attribute Value in a Configuration Object

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot convert the value '<Value>' to type <MemberType>: <Reason>` |

## Cause

Some sections of `postsharp.config`, such as the logging profiles of the `Logging` section, describe CLR objects in XML, as <xref:configuration-serialization> explains. Each XML attribute sets the property or the field of the same name. PostSharp converts the text of the attribute to the type of the member: an enumeration value is the name of a member, or several names separated by `|` or spaces for a flags enumeration, and other values are converted with the <xref:System.Convert> class, with the invariant culture.

PostSharp reports PS0254 when this conversion fails. `<MemberType>` is the type of the property or the field, and `<Reason>` is the error of the conversion. The location of the message is the XML attribute in `postsharp.config`.

## Resolution

* For an enumeration, use the exact name of a member, with the same case. Separate the members of a flags enumeration with `|`.
* For a number or a Boolean value, use the invariant format: a period as the decimal separator, and `true` or `false`.
* Check the type of the property in the API reference, for example <xref:PostSharp.Patterns.Diagnostics.LoggingOptions.Level> for the level of logging options.
