# LA0258: Advice Sets Both Group and Master

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The advice "<Advice>" sets both the Group and the Master property. Set only one of them.` |

## Cause

An advice selects its group explicitly with the <xref:PostSharp.Aspects.Advices.GroupingAdvice.Group> property, which names the group. The <xref:PostSharp.Aspects.Advices.GroupingAdvice.Master> property, which puts the advice in the group of another advice, is the former way of doing it. It is obsolete, so the C# compiler reports CS0618 when you use it, but it keeps working.

The two properties are two ways of selecting the group of an advice, so PostSharp reports LA0258 when an advice sets both.

## Resolution

Remove the <xref:PostSharp.Aspects.Advices.GroupingAdvice.Master> property. When the class has only one group that has no advice of the kind of the advice, PostSharp puts the advice in this group, and the <xref:PostSharp.Aspects.Advices.GroupingAdvice.Group> property is not needed either: PostSharp reports it with the warning <xref:la0255?text=LA0255>. Otherwise, keep the <xref:PostSharp.Aspects.Advices.GroupingAdvice.Group> property, and set the same name on all the advices of the group.
