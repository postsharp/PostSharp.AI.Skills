# SR0002: Base Type Has No Deserializing Constructor

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply [PSerializable] to type '<Type>' because its base type does not have a deserializing constructor, which takes a single parameter of type PortableFormatterConstructorContext. Apply [PSerializable] to the base type.` |

## Cause

[<xref:PostSharp.Serialization.PSerializableAttribute>] generates a deserializing constructor in `<Type>`, which <xref:PostSharp.Serialization.PortableFormatter> calls to create the instance before it restores its fields. This constructor must call a constructor of the base type: the deserializing constructor of the base type, which has a single parameter of type `PortableFormatterConstructorContext`. [<xref:PostSharp.Serialization.PSerializableAttribute>] generates this constructor in the base type too, but a base type whose serializer is written by hand usually does not have it.

PostSharp reports SR0002 when the base type has a serializer, either a nested class named `Serializer` or a type given by [<xref:PostSharp.Serialization.SerializerAttribute>], but no deserializing constructor. When the base type is marked `[Serializer(null)]`, so that it has no serializer, PostSharp also accepts its parameterless constructor, and reports SR0002 only when the base type has neither.

The base types <xref:System.Object>, <xref:System.ValueType>, <xref:System.Attribute> and <xref:System.MarshalByRefObject> do not need a deserializing constructor. A base type that has no serializer at all is reported with <xref:sr0006?text=SR0006> instead.

## Resolution

* Apply [<xref:PostSharp.Serialization.PSerializableAttribute>] to the base type instead of writing its serializer by hand. PostSharp then generates its serializer and its deserializing constructor, and the serializer of the derived type extends the one of the base type.
* When the base type has no state to serialize, mark it with `[Serializer(null)]` and give it a parameterless constructor that the derived type can access.
