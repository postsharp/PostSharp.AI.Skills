# LA0153: Awaiter Parameters of Different Types in One Advice Group

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The advice "<Advice>" has an [Awaiter] parameter of type "<AwaiterType>", which is different from the type "<FirstAwaiterType>" of the [Awaiter] parameter of another advice of the same group.` |

## Cause

The advices of an aspect that apply to the same target method form a group, and the woven method stores the awaiter of all their <xref:PostSharp.Aspects.Advices.AwaiterAttribute> parameters in a single variable. All the `[Awaiter]` parameters of a group must therefore have the same type. PostSharp compares each `[Awaiter]` parameter of the group with the first one, `<FirstAwaiterType>`, and reports LA0153 for each advice whose parameter has another type.

In the following example, the entry advice of the `[SwitchToThreadPool]` aspect has an awaiter of type `YieldAwaitable.YieldAwaiter`, and the resume advice an awaiter of type `TaskAwaiter`.

## Resolution

* Give the same awaiter type to all the `[Awaiter]` parameters of the group.
* When the advices need different awaiters, write an awaiter type of your own that implements <xref:System.Runtime.CompilerServices.INotifyCompletion> and wraps them, and use it in all the advices.
