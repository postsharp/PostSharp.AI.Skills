# PS0135: Property Is Not a Boolean Value

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Invalid expression "<Expression>": cannot convert "<Value>" to a <Type>. Expected values: <ExpectedValues>.` |

## Cause

Several properties of PostSharp are switches: for example `WriteWeavingSymbols`, `SignAssembly` or `Deterministic`. PostSharp receives them from MSBuild properties such as `PostSharpWriteWeavingSymbols`, from the `PostSharpProperties` MSBuild property, or from a `Property` element of a `postsharp.config` file, and the `Condition` attributes of configuration files are switches too. When PostSharp evaluates a switch, it accepts `True`, `False`, in any case, or an empty value, which means `False`. Any other value, such as `Yes`, `1` or `On`, makes PostSharp report PS0135.

`<Expression>` is the expression that PostSharp evaluated, usually a reference to a property such as `{$WriteWeavingSymbols}`, and `<Value>` the text it evaluated to. `<Type>` is always `bool`, and `<ExpectedValues>` is `True | False`. The message has no location in the source code.

When the property configures a task of the PostSharp compiler, the task cannot be created and PostSharp also reports <xref:ps0084?text=PS0084>, which stops the build.

## Resolution

Find where the property is set, from its name in `<Expression>`, and set it to `True` or `False`:

* In the project file or in a `Directory.Build.props` file, for an MSBuild property such as `<PostSharpWriteWeavingSymbols>True</PostSharpWriteWeavingSymbols>`, or in the `PostSharpProperties` property.
* In a `postsharp.config` file, for a `Property` element or a `Condition` attribute.
* On the command line, for a property passed with `-p:`.
