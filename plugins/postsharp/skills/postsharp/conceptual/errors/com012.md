# COM012: Relationship Attribute on a Static Member

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp.Patterns.Aggregation |
| **Message** | `Attribute [<Attribute>] cannot be applied to "<Member>" because it is a static member; it will be ignored.` |

## Cause

The <xref:PostSharp.Patterns.Model.ChildAttribute>, <xref:PostSharp.Patterns.Model.ReferenceAttribute> and <xref:PostSharp.Patterns.Model.ParentAttribute> attributes describe how the objects of an <xref:PostSharp.Patterns.Model.AggregatableAttribute> class relate to each other: a child belongs to one parent instance. A static field or property belongs to no instance, so it cannot take part in the parent/child graph. When one of these attributes is applied to a static field or a static automatic property, PostSharp reports COM012 and ignores the attribute: the object stored in the member gets no parent.

`<Attribute>` is the name of the attribute class, for example `ChildAttribute`.

## Resolution

* When each instance owns its own object, make the field or property an instance member.
* When the object is shared by all instances, remove the attribute from the static member.
