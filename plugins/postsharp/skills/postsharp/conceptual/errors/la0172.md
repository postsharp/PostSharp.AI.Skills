# LA0172: Async Interception Advice Applied to an Unsupported Method

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply the advice "<Advice>" to target "<Method>": async interception can be applied only to methods that return Task or Task<T> and have no by-reference parameter. Add a non-async OnMethodInvokeAdvice to the group and, if the method returns an awaitable type, set the UnsupportedTargetAction property of the master advice to Fallback, or to Ignore to skip the method.` |

## Cause

An advice marked with <xref:PostSharp.Aspects.Advices.OnMethodInvokeAsyncAdvice> intercepts the task that a method returns, and supports only the methods that return a <xref:System.Threading.Tasks.Task> or a <xref:System.Threading.Tasks.Task`1> and have no `ref` or `out` parameter. PostSharp reports LA0172 on the target method in the following cases:

* The method is `async void`, or returns another awaitable type, such as <xref:System.Threading.Tasks.ValueTask`1>, or a task with a by-reference parameter, and the <xref:PostSharp.Aspects.Advices.OnMethodInvokeBaseAdvice.UnsupportedTargetAction> property of the master advice of the group keeps its default value, <xref:PostSharp.Aspects.UnsupportedTargetAction.Fail>.
* The method is not advised semantically, for example a method that returns `void` or a value, and the group of the advice has no advice marked with <xref:PostSharp.Aspects.Advices.OnMethodInvokeAdvice> to intercept it. The <xref:PostSharp.Aspects.Advices.OnMethodInvokeBaseAdvice.UnsupportedTargetAction> property does not suppress the error in this case.

`<Advice>` is the advice method, and `<Method>` is the target method.

## Resolution

* Make the target method return a <xref:System.Threading.Tasks.Task> or a <xref:System.Threading.Tasks.Task`1>, without `ref` or `out` parameters.
* Add an advice marked with <xref:PostSharp.Aspects.Advices.OnMethodInvokeAdvice> to the group, and set the <xref:PostSharp.Aspects.Advices.OnMethodInvokeBaseAdvice.UnsupportedTargetAction> property of the master advice to <xref:PostSharp.Aspects.UnsupportedTargetAction.Fallback>, so that the non-async advice intercepts the unsupported methods (see <xref:la0173?text=LA0173>).
* Set the property to <xref:PostSharp.Aspects.UnsupportedTargetAction.Ignore> to skip the `async void` methods and the methods that return another awaitable type.
* Do not apply the aspect to the method.
