# PS0167: Attribute with a Namespace in a Configuration File

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The attribute '<Attribute>' of the element '<Element>' cannot have the namespace '<XmlNamespace>'. Remove the namespace prefix of the attribute.` |

## Cause

In some sections of a PostSharp configuration file, such as the `Multicast` section and the logging profiles, each XML element describes a CLR object, and each XML attribute of the element sets a field or a property of this object. These attributes must have no namespace: only the element has the prefix of its `clr-namespace`.

PostSharp reports PS0167 when an attribute has a namespace prefix, and ignores the element. Namespace declarations (`xmlns`) and the `Condition` attribute are not concerned, and an attribute in the PostSharp namespace is reported as <xref:ps0206?text=PS0206>. `<Element>` is the expanded name of the element, which starts with its XML namespace in braces.
