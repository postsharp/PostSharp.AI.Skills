# PS0158: Required Attribute Missing in a Configuration Element

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The <Element> element does not have a <Attribute> attribute.` |

## Cause

Two elements of a PostSharp configuration file, such as `postsharp.config`, require an attribute:

* A `Property` element requires a `Name` attribute.
* A `Service` element requires a `TypeName` attribute. PostSharp checks it after it evaluates the expressions of the attribute, so an expression that evaluates to an empty string is also reported. For a `Service` element, the message gives the configuration file without a line number.

PostSharp reports PS0158 when the attribute is missing or empty. Attribute names are case-sensitive, so `name` is not the `Name` attribute. PostSharp then reports <xref:ps0084?text=PS0084> and stops the build, because it cannot initialize the project.

## Resolution

* Add the `Name` attribute to the `Property` element, or the `TypeName` attribute to the `Service` element, with the exact case.
* When a `TypeName` attribute is an expression, check that the properties it uses are defined.
