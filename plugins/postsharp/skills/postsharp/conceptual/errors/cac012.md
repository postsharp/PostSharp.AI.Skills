# CAC012: Invalidating and Cached Methods Use Different Caching Services

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Caching |
| **Message** | `The [InvalidateCache] aspect applied to <InvalidatingMethod> cannot invalidate <CachedMethod>: <InvalidatingMethod> uses <InvalidatingService>, and <CachedMethod> uses <CachedService>, so the invalidation would remove the item from another cache. Apply the same UseDependencyInjection setting of [CacheConfiguration] to both methods.` |

## Cause

The <xref:PostSharp.Patterns.Caching.InvalidateCacheAttribute> aspect removes items from the caching service of its own method, `<InvalidatingMethod>`. PostSharp determines this service at build time, from the <xref:PostSharp.Patterns.Caching.CacheConfigurationAttribute.UseDependencyInjection> property of the <xref:PostSharp.Patterns.Caching.CacheConfigurationAttribute> of the declaring class, its base classes or its assembly:

* With `true`, an instance method of a class uses the caching service that its object receives from dependency injection.
* Otherwise, or for a static method or a method of a struct, the method uses the default caching service, <xref:PostSharp.Patterns.Caching.CachingServices.DefaultService>.

PostSharp reports CAC012 when the cached method, `<CachedMethod>`, uses the other service, because the invalidation would then never reach its items. `<InvalidatingService>` and `<CachedService>` are `the default caching service` or `the caching service from dependency injection`.

## Resolution

* Set <xref:PostSharp.Patterns.Caching.CacheConfigurationAttribute.UseDependencyInjection> to the same value for both classes, for example with a <xref:PostSharp.Patterns.Caching.CacheConfigurationAttribute> on the assembly, and make the invalidating method an instance method of a class, whose objects the container creates.
* Otherwise, remove the `[InvalidateCache]` aspect, and invalidate the item imperatively with the `Invalidate` methods of the <xref:PostSharp.Patterns.Caching.ICachingService> that the cached method uses.
