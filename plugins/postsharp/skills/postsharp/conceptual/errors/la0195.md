# LA0195: Event Interception Applied to an Interface Event

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `"<AspectOrAdvice>" cannot intercept "<Event>" because it is an instance event of an interface.` |

## Cause

Since C# 8, an interface can give its events a default implementation with `add` and `remove` accessors. PostSharp cannot intercept the instance events of an interface: an <xref:PostSharp.Aspects.EventInterceptionAspect>, or an event advice such as <xref:PostSharp.Aspects.Advices.OnEventAddHandlerAdvice>, reports LA0195 when it targets a non-static event whose declaring type is an interface. `<AspectOrAdvice>` is the aspect type, or the advice method.
