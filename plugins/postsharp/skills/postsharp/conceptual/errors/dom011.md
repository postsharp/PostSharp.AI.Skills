# DOM011: Property Getter Calls a Virtual Method

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Model |
| **Message** | `NotifyPropertyChangedAttribute: automatic analysis of property <Property> failed. Method <Method> contains a call to virtual method <VirtualMethod>. Calls to virtual methods cannot be analyzed. To fix this error, remove the calls to virtual methods. To ignore this error, add the [SafeForDependencyAnalysis] attribute to property <Property>.` |

## Cause

The <xref:PostSharp.Patterns.Model.NotifyPropertyChangedAttribute> aspect finds the fields and properties on which each property depends by analyzing the code of its getter at build time, and of the methods that the getter calls. It cannot analyze a call to a virtual, abstract or interface method, because the method that runs is chosen at run time, and an override in another class or assembly can read other fields.

PostSharp reports DOM011 on the property when its getter, or a method of the class that the getter calls, calls such a method and uses its return value. `<Method>` is the method that contains the call: the getter itself, or one of the methods that it calls. Calls to methods that return `void`, to `ToString` and `GetHashCode`, and to methods that PostSharp knows to have no side effect, are not reported.

## Resolution

* When the method does not need to be virtual, make it non-virtual, so that the aspect analyzes its code.
* Otherwise, add the <xref:PostSharp.Patterns.Model.SafeForDependencyAnalysisAttribute> attribute to the property. The aspect then skips the calls that it cannot analyze, but still finds the dependencies that the getter reads directly. Declare the dependencies of the virtual method with <xref:PostSharp.Patterns.Model.Depends.On*> in the getter; without them, the property is not notified when these dependencies change.
