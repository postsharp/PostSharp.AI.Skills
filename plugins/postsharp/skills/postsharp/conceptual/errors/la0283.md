# LA0283: Several Members of the Imported Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [ImportMember] to a member of its type, but several members of "<TargetType>" match: <MemberNames>. Specify the name of the member.` |

## Cause

An advice parameter annotated with <xref:PostSharp.Aspects.Advices.ImportMemberAttribute> without a member name receives the field or the property of the target type whose type matches the type of the parameter: a parameter passed by value accepts a member whose type can be assigned to it without a conversion other than boxing, and a parameter passed by reference, or an <xref:PostSharp.Aspects.ILocationBinding`1>, requires exactly the type of the member. When several members match, PostSharp cannot choose one, and reports LA0283 on each target, whatever the value of <xref:PostSharp.Aspects.Advices.ImportMemberAttribute.IsRequired>. `<MemberNames>` lists the matching members.

When the aspect requests fields with <xref:PostSharp.Aspects.Advices.IntroduceFieldAdviceInstance>, the requested fields of the matching type are the only candidates, so the error can also mean that the aspect requests several fields of the same type.

## Resolution

* Specify the name of the member in the constructor of <xref:PostSharp.Aspects.Advices.ImportMemberAttribute>. When the targets name the member differently, give several names, in order of precedence.
* Change the type of the advice parameter, or pass it by reference, so that only one member matches.
