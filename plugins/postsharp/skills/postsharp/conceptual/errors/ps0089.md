# PS0089: Field Accessed by Reference Escapes Its Aspect

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp |
| **Message** | `The field "<Field>" is loaded by reference, which prevents aspects from intercepting this access. To call an instance method of the field, use the Post.GetValue method. To change a member of the field or pass the field by reference, copy it to a local variable, change or pass the local variable, and assign the local variable back to the field [in method "<Method>"].` |

## Cause

An aspect that intercepts a field, such as a <xref:PostSharp.Aspects.LocationInterceptionAspect>, turns the field into a property: PostSharp replaces each read and each assignment of the field with a call of the getter or the setter, which run the aspect. A reference to the field cannot be replaced in this way. The C# compiler loads the address of a field instead of its value in the following cases:

* The code changes a member of a structure stored in the field, as in `this.location.X = x`, or reads a member of it, as in `this.location.X`.
* The code calls an instance method of the structure stored in the field.
* The code passes the field to a `ref`, `out` or `in` parameter.

PostSharp then leaves the access as it is and reports PS0089 on its line: the build succeeds, but the aspect does not see this access. PostSharp does not report the message when the code sets the field to its default value, or calls a method of a structure of the `System` namespace, such as <xref:System.DateTime>. `<Method>` is the method that contains the access.

## Resolution

* To change a member of the structure, copy the field to a local variable, change the local variable, and assign it back to the field. Better, make the structure immutable and assign a new value to the field.
* To call an instance method of the structure, pass the field to <xref:PostSharp.Post.GetValue``1(``0)>, as in `Post.GetValue( this.location ).ToString()`: the method is called on a copy of the value, which the getter returns.
* To pass the field by reference, copy it to a local variable, pass the local variable, and assign it back to the field after the call.
