# CAC007: [InvalidateCache] Names No Method

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Caching |
| **Message** | `Invalid [InvalidateCache] aspect on <Method>: the constructor parameters should contain at least one method name.` |

## Cause

The <xref:PostSharp.Patterns.Caching.InvalidateCacheAttribute> aspect removes from the cache the values of the cached methods whose names you pass to its constructor. The method names are a `params` array, so C# accepts the attribute without any argument, or with only the declaring type. The aspect then has nothing to invalidate, and PostSharp reports CAC007.

`<Method>` is the invalidating method, the one to which the aspect is applied. PostSharp reports the message on the declaration of this method.

## Resolution

Pass the names of the cached methods that the invalidating method makes stale to the <xref:PostSharp.Patterns.Caching.InvalidateCacheAttribute> aspect, preferably with the `nameof` operator. When the cached methods belong to another type, pass this type as the first argument. If the method does not invalidate any cached method, remove the aspect.
