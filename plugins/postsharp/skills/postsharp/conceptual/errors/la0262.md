# LA0262: Struct Field Imported by Reference in an Async Method or Iterator

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [ImportMember] and passed as out or ref to the field "<Field>" of a struct, but "<TargetMethod>" is an async method or an iterator, which works on a copy of the struct. Pass the parameter by value or as in.` |

## Cause

An advice parameter annotated with <xref:PostSharp.Aspects.Advices.ImportMemberAttribute> and passed as `ref` or `out` receives a reference to a field of the target object, so that the advice can change the field. An async method or an iterator runs in a state machine, which holds a copy of `this` when the target type is a struct. A reference to a field of this copy would not change the struct of the caller, so PostSharp reports LA0262 when the advice is woven into the state machine.

The message concerns only the instance fields of a struct: a static field, or a field of a class, can be imported by reference in an async method or an iterator.

## Resolution

Choose one of the following:

* Declare the target type as a class, when it needs to change its own state from an async method or an iterator.
* Pass the parameter by value or as `in`, when the advice only reads the field. The advice then reads the field of the copy that the state machine holds.
* Make the field static, when its value does not belong to one object.
