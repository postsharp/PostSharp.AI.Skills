# LA0239: Required Current Task Not Available

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [CurrentTask] with IsRequired set to true, but the method "<TargetMethod>" cannot provide its task: only an async method that returns Task, Task<T>, ValueTask or ValueTask<T>, uses the default method builder, and is not implemented with runtime async can.` |

## Cause

A parameter annotated with <xref:PostSharp.Aspects.Advices.CurrentTaskAttribute> receives the task that the caller of the async method observes. PostSharp reads it from the method builder of the state machine that the C# compiler generates. When <xref:PostSharp.Aspects.Advices.CurrentTaskAttribute.IsRequired> is `true`, the parameter must never be `null`, so PostSharp reports LA0239 on each target method that cannot provide its task:

* A method that is not async, or an `async void` method, which has no task.
* An async method whose method builder is not <xref:System.Runtime.CompilerServices.AsyncTaskMethodBuilder>, <xref:System.Runtime.CompilerServices.AsyncTaskMethodBuilder`1>, <xref:System.Runtime.CompilerServices.AsyncValueTaskMethodBuilder> or <xref:System.Runtime.CompilerServices.AsyncValueTaskMethodBuilder`1>, for instance a method annotated with `[AsyncMethodBuilder( typeof( PoolingAsyncValueTaskMethodBuilder ) )]`, or a method that returns a custom task type.
* An async method that the C# compiler implements with runtime async (`<Features>runtime-async=on</Features>`), which has no method builder. Without `IsRequired`, the parameter is `null` in such a method, and PostSharp reports the warning <xref:la0240?text=LA0240> instead.

PostSharp can also report LA0239 when it generates the code of the advice, when another transformation of the method prevents it from modifying the state machine.

## Resolution

* Make the method return a <xref:System.Threading.Tasks.Task> or a <xref:System.Threading.Tasks.ValueTask>, with the default method builder.
* Or set <xref:PostSharp.Aspects.Advices.CurrentTaskAttribute.IsRequired> to `false`, and handle a `null` task in the advice.
* Or apply the aspect only to methods that can provide their task. In a type-level aspect, a <xref:PostSharp.Aspects.Advices.MatchPointcut> skips the methods that cannot provide their task instead of reporting the error.
