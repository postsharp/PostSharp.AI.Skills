# LA0136: Validation Aspect on a Property Without Setter

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Aspect "<Aspect>" cannot be applied to property "<Property>" because it is read-only.` |

## Cause

An aspect that implements <xref:PostSharp.Aspects.ILocationValidationAspect`1>, such as a contract, validates the values that are assigned to a field, a property or a parameter. For a property, PostSharp inserts the validation into the setter. When the property has no setter, for example a property with an expression body that only returns a field, there is no assignment to validate, so PostSharp reports LA0136.

## Resolution

* Give the property a setter, which can be private, and assign the value through the property.
* Otherwise, apply the aspect where the value is assigned: to the backing field, or to the parameter that receives the value.
