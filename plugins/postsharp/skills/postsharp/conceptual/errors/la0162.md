# LA0162: Imported Member Field Without a Member Name

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot import a member into field "<Field>": the advice "<Advice>" has a null or empty array of member names. Specify the name of at least one member to import.` |

## Cause

An aspect imports a member of its target class with a field annotated with <xref:PostSharp.Aspects.Advices.ImportMemberAttribute>. PostSharp finds the member by the names that the constructor of the attribute receives, in the <xref:PostSharp.Aspects.Advices.ImportMemberAttribute.MemberNames> property, and does not use the name of the field. When this array is empty or `null`, PostSharp does not know which member to import and reports LA0162 on the field.

The usual cause is the attribute without arguments, `[ImportMember]`, which C# accepts because the constructor takes a `params` array. `<Advice>` is the type of the advice, <xref:PostSharp.Aspects.Advices.ImportMemberAttribute>.

## Resolution

Pass the name of the member to import to the constructor of <xref:PostSharp.Aspects.Advices.ImportMemberAttribute>, for example `[ImportMember( "Name" )]`. You can also pass several possible names, in order of precedence.
