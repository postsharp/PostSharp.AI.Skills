# THR006: Method Cannot Be Executed in the Background

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Threading |
| **Message** | `Method "<Method>" cannot be enhanced with the [Background] aspect. This aspect can only be applied to methods that have no ref, out or in parameters and whose return type is void, Task or Task<T>.` |

## Cause

The <xref:PostSharp.Patterns.Threading.BackgroundAttribute> aspect executes a method in the thread pool, or in a new thread when <xref:PostSharp.Patterns.Threading.BackgroundAttribute.IsLongRunning> is `true`. The caller does not wait for the method to complete, so it cannot receive a return value or the values of `ref` and `out` parameters, unless the method returns a task that the caller can await.

PostSharp therefore reports THR006 when a method with the aspect:

* has a return type that is neither `void` nor `Task` or `Task<T>`, for example `int`, `string` or `ValueTask<T>`;
* has a `ref`, `out` or `in` parameter.

## Resolution

* When the caller needs the result of the method, make the method `async` and return a `Task<T>`. The caller awaits the task, which completes when the method completes in the background.
* When the caller does not need a result, make the method return `void` or `Task`.
* Replace `ref`, `out` and `in` parameters with the return value of the task, or with ordinary parameters.
