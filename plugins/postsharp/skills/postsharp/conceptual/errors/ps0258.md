# PS0258: Invalid Item in a Configuration Collection

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The type <ItemType> is not a valid item for a collection of type <CollectionType>.` |

## Cause

Some sections of `postsharp.config`, such as the `Logging` section, describe CLR objects in XML, as <xref:configuration-serialization> explains. When a child element is named after a property that is a collection, such as the `Profiles` of the `Logging` section, each element that it contains describes an item that PostSharp adds to the collection.

PostSharp reports PS0258 when the type of an item, `<ItemType>`, does not fit the item type of the collection, `<CollectionType>`: for the `Profiles` collection, each item must be a `LoggingProfile` element. PostSharp skips the item. The location of the message is the element of the collection property, not the item.

## Resolution

* Wrap the item in an element of the item type of the collection. For logging options, add a `LoggingProfile` element with a `Name`, and put the options in its `DefaultOptions` or `ExceptionOptions` element.
* Check the XML namespace of the item: an `xmlns` attribute on the item, or on one of its parents, decides in which CLR namespace and assembly PostSharp looks for its type.
