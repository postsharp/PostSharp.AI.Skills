# LA0165: Async Interception Advice Does Not Return a Task

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Advice "<Advice>" is not valid on method "<Method>": method return type must be "<ReturnType>".` |

## Cause

An advice method marked with <xref:PostSharp.Aspects.Advices.OnMethodInvokeAsyncAdvice> intercepts async methods, as <xref:PostSharp.Aspects.MethodInterceptionAspect.OnInvokeAsync*> does in a <xref:PostSharp.Aspects.MethodInterceptionAspect>. It must have the same signature as `OnInvokeAsync` and return a <xref:System.Threading.Tasks.Task>, so that PostSharp can await the advice and return its task to the caller. `<ReturnType>` is always `System.Threading.Tasks.Task`.
