# LA0223: Instance Passed by Reference to an Advice on a Class

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [This] and passed by reference, which is supported only when the type "<InstanceType>" is a struct.` |

## Cause

A parameter annotated with <xref:PostSharp.Aspects.Advices.ThisAttribute> receives the instance of the target. When the parameter is passed by reference, with `in` or `ref`, it receives the address of the instance, so that the advice reads a struct without copying it, or changes it. Only a struct has such an address: the instance of a class is a reference already. When the advice applies to an instance member of a type that is not a struct, PostSharp reports LA0223 on the target member.

`<InstanceType>` is the type that declares the target member. On a static target, the parameter receives no instance, and this check does not apply.

When the advice uses a pointcut that skips the targets whose signature does not match, such as <xref:PostSharp.Aspects.Advices.MatchPointcut>, PostSharp skips the target instead of reporting the error.

## Resolution

* Pass the parameter by value. Its type can be <xref:System.Object>, the type of the instance, or a type parameter of the advice, which PostSharp infers from the target. The parameter then receives the reference to an object, or a copy of a struct.
* Otherwise, apply the aspect only to members of structs.
