# LA0174: Aspect Cannot Advise the Method Semantically

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply the aspect "<Aspect>" to method "<Method>": semantic advising currently can be applied only to iterator and enumerable methods, async methods and any methods returning Task, Task<T>, IEnumerable, IEnumerable<T>, IEnumerator, or IEnumerator<T> without by-reference parameters. You can suppress this error message by setting the UnsupportedTargetAction property on the aspect.` |

## Cause

By default, <xref:PostSharp.Aspects.OnMethodBoundaryAspect> and <xref:PostSharp.Aspects.OnExceptionAspect> advise semantically the methods that return an awaitable type, also when they are not `async`: `OnExit` runs when the task completes, not when the method returns it. For such a method, which has no state machine, PostSharp generates one. It can do so only for a method that returns a <xref:System.Threading.Tasks.Task>, a <xref:System.Threading.Tasks.Task`1> or an enumerable type, and has no `ref` or `out` parameter.

PostSharp reports LA0174 on the target method when it should advise the method semantically, cannot generate the state machine, and the `UnsupportedTargetAction` property of the aspect keeps its default value, <xref:PostSharp.Aspects.UnsupportedTargetAction.Fail>. The typical case is a method that returns a <xref:System.Threading.Tasks.ValueTask`1> without the `async` keyword.

## Resolution

* Set the <xref:PostSharp.Aspects.OnMethodBoundaryAspect.UnsupportedTargetAction> property of the aspect to <xref:PostSharp.Aspects.UnsupportedTargetAction.Fallback>, so that the aspect wraps the method itself, or to <xref:PostSharp.Aspects.UnsupportedTargetAction.Ignore> to skip the method.
* Make the method return a <xref:System.Threading.Tasks.Task> or a <xref:System.Threading.Tasks.Task`1>, or remove its `ref` and `out` parameters.
* Exclude the method from semantic advising with the <xref:PostSharp.Aspects.OnMethodBoundaryAspect.SemanticallyAdvisedMethodKinds> property.
