# LA0230: Group of an Advice Cannot Be Inferred

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The group of the advice "<Advice>" cannot be inferred because several groups of "<AspectClass>" have no advice of its kind yet: the groups of <Groups>. Set the Group property of the advice and of the advices of the group that it must join to the same value.` |

## Cause

Advices of the same family, such as the method boundary advices, are woven in groups. PostSharp forms the groups of each class of the aspect separately. An advice with a pointcut starts a group, and an advice with the <xref:PostSharp.Aspects.Advices.GroupingAdvice.Group> property joins the group of this name. An advice that has neither joins the group of its class that has no advice of its kind yet, or starts a group that applies to the target of the aspect when every group of the class already has one.

When several groups of the class have no advice of its kind, for instance two groups started by entry advices with different pointcuts and one exit advice, PostSharp does not choose between them, and reports LA0230 on the advice. Declaration order never decides. `<AspectClass>` is the class that declares the advice, and `<Groups>` names the first advice of each candidate group.

## Resolution

* Set the <xref:PostSharp.Aspects.Advices.GroupingAdvice.Group> property of the advice, and the same value on the advices of the group that it must join. Setting it on the advice alone gives the advice a new group without pointcut, which applies to the target of the aspect.
* Or give the advice a pointcut, when it must start a group of its own.
