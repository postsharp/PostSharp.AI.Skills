# LA0270: Empty Name of a Requested Field

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The aspect "<Aspect>" applied to "<Target>" attempts to introduce a field with an empty or white-space name with IntroduceFieldAdviceInstance. Set the Name property to null to identify the field by its type.` |

## Cause

An aspect attempts to introduce a field by returning an <xref:PostSharp.Aspects.Advices.IntroduceFieldAdviceInstance> from <xref:PostSharp.Aspects.Advices.IAdviceProvider.ProvideAdvices*>. Its <xref:PostSharp.Aspects.Advices.IntroduceFieldAdviceInstance.Name> property is either a name, which finds an existing field of this name or names the new field, or `null`, which attempts to introduce a field by its type. PostSharp reports LA0270 when the name is an empty string or contains only white space, because no field can have this name.

`<Target>` is the declaration to which the aspect is applied, where the error is located.

## Resolution

Set the <xref:PostSharp.Aspects.Advices.IntroduceFieldAdviceInstance.Name> property to `null` to identify the field by its type, or to a valid field name. When the name comes from a property of the aspect, make `null` its default value, or convert an empty value to `null`.
