# THR021: Method Has Several Access-Level Attributes

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Threading |
| **Message** | `Method <Method> has more than one access-level attribute ([Reader], [Writer], [UpgradeableReader] or [Yielder]). Apply only one of them.` |

## Cause

In a class with the <xref:PostSharp.Patterns.Threading.ReaderWriterSynchronizedAttribute> aspect, each public or internal method declares the access that it needs to the object with one access-level attribute: <xref:PostSharp.Patterns.Threading.ReaderAttribute>, <xref:PostSharp.Patterns.Threading.WriterAttribute>, <xref:PostSharp.Patterns.Threading.UpgradeableReaderAttribute> or <xref:PostSharp.Patterns.Threading.YielderAttribute>. The aspect takes the matching lock when the method starts, so it must know which single lock to take.

PostSharp reports THR021 when a method has more than one of these attributes.

## Resolution

Keep only the attribute that gives the method the access that it needs:

* <xref:PostSharp.Patterns.Threading.WriterAttribute> when the method modifies the object. The write lock also allows the method to read the object.
* <xref:PostSharp.Patterns.Threading.UpgradeableReaderAttribute> when the method reads the object and only sometimes modifies it, so that other readers are not blocked until it needs to write.
* <xref:PostSharp.Patterns.Threading.ReaderAttribute> when the method only reads the object.
