# SR0009: Serializer of the Base Type Is Not Visible from the Derived Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply [PSerializable] to type '<Type>' because the serializer '<Serializer>' is not visible from '<Type>'.` |

## Cause

When a [<xref:PostSharp.Serialization.PSerializableAttribute>] class derives from a class whose serializer is written by hand, the serializer that PostSharp generates for the derived class is a nested class of `<Type>` that derives from the serializer of the base class. A class can derive only from a class that it can see, so the serializer of the base class must be visible from `<Type>`.

PostSharp reports SR0009 on `<Type>` when the serializer `<Serializer>` of its base class is not visible from it: typically a `private` nested class of the base class.
