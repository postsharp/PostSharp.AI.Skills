# SR0011: Default Constructor of the Base Serializer Is Not Accessible

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply [PSerializable] to type '<Type>' because the default constructor of the serializer '<Serializer>' is not accessible from the serializer generated for '<Type>'.` |

## Cause

When a [<xref:PostSharp.Serialization.PSerializableAttribute>] class derives from a class whose serializer is written by hand, the serializer that PostSharp generates for the derived class derives from the serializer of the base class, and its constructor calls the parameterless constructor of the base serializer. This constructor must be accessible from the generated serializer.

PostSharp reports SR0011 on the parameterless constructor of `<Serializer>` when the serializer generated for `<Type>` cannot call it, typically because it is `private`. A base serializer that has no parameterless constructor at all is reported with <xref:sr0010?text=SR0010> instead.
