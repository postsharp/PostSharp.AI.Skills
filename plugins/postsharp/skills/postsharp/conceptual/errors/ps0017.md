# PS0017: Invalid Value of a PostSharp Property

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The value "<Value>" of "<Expression>" is invalid. Expecting <ExpectedValues>.` |

## Cause

Some properties of the PostSharp compiler accept only a fixed list of values, for example `DebuggerExtensionsMode`, which the `PostSharpDebuggerExtensionsMode` MSBuild property sets. You can set these properties with MSBuild properties, as <xref:msbuild-properties> describes, or with `Property` elements in `postsharp.config`. PostSharp reports PS0017 when it reads a property whose value is not one of the accepted values. The comparison ignores case.

* `<Expression>` is the expression that PostSharp evaluated, such as `{$DebuggerExtensionsMode}` for the `DebuggerExtensionsMode` property.
* `<Value>` is the value of the expression.
* `<ExpectedValues>` lists the accepted values, separated by `|`, or names the expected type, such as `Int32`, for a property that expects a number.

When PostSharp reads the property while it initializes the project, as it does for `DebuggerExtensionsMode`, it also reports <xref:ps0084?text=PS0084>, which says that the project could not be initialized, and does not build the project.
