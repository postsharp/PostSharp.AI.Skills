# DOM021: Recordable Class Has a Field of a Mutable Value Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Model |
| **Message** | `The type of field <Field> is not compatible with the [Recordable] aspect: mutable value types are not allowed. Make the type a readonly struct, or add the [NotRecorded] attribute to the field.` |

> [!WARNING]
> Undo/Redo was deprecated in PostSharp 2026.0 and will not be maintained. The API will be removed in the future.

## Cause

The <xref:PostSharp.Patterns.Recording.RecordableAttribute> aspect records each assignment of a field of the class, so that the assignment can be undone. When the field is of a value type whose own fields can change, code can change the value in place, for example with `this.position.X = 5`, which the aspect cannot record.

PostSharp reports DOM021 on a field of the class when its type is a struct that is neither a primitive type, a type of the `System` namespace, nor immutable. A struct is immutable when it is a `readonly struct`, when all its fields are read-only and of immutable types, or when it has the <xref:PostSharp.Patterns.Threading.AssumeImmutableAttribute> attribute. Fields of delegate types, and fields with the <xref:PostSharp.Patterns.Recording.NotRecordedAttribute> attribute, are not checked.

## Resolution

* Make the struct immutable, for example a `readonly struct`. Code then changes the field by assigning a new value, which the aspect records.
* When the changes of the field do not need to be undone, add the <xref:PostSharp.Patterns.Recording.NotRecordedAttribute> attribute to the field.
