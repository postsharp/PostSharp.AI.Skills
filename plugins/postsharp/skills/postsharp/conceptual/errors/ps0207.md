# PS0207: Configuration File Changes a Sealed Property

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot set property '<PropertyName>' because it is sealed.` |

## Cause

A `Property` element of a `postsharp.config` file with the `Sealed="true"` attribute defines a property that no later `Property` element can change. See <xref:configuration-schema#property>. This lets the configuration file at the root of a repository impose a value on every project below it.

PostSharp loads the `postsharp.config` files from the root directory down to the directory of the project, and their `Property` elements in the order of the file. It reports PS0207 on a `Property` element that sets a property that an earlier element sealed, and keeps the sealed value. Since the error occurs while PostSharp loads the configuration of the project, it also reports <xref:ps0084?text=PS0084> and stops the build.

## Resolution

* Remove the `Property` element that changes the sealed property, so that the project uses the sealed value.
* When the project must have another value, remove the `Sealed` attribute from the element that seals the property, or move that element to a configuration file that does not apply to this project.
