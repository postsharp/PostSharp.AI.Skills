# LA0191: Instance-Scoped Aspect Applied to an Interface

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply the aspect "<Aspect>" to "<Target>": instance-scoped aspects cannot be applied to interfaces or to members of interfaces. Apply the aspect to the classes that implement the interface.` |

## Cause

An instance-scoped aspect, such as an <xref:PostSharp.Aspects.InstanceLevelAspect> or an aspect that implements <xref:PostSharp.Aspects.IInstanceScopedAspect>, has one instance per instance of its target class. PostSharp stores this aspect instance in a field of the class and initializes it in the constructors. An interface has no instances, fields or constructors, so PostSharp reports LA0191 when an instance-scoped aspect is applied to an interface, or to a member of an interface such as a default interface method.

Multicasting does not apply an <xref:PostSharp.Aspects.InstanceLevelAspect> to interfaces, so the message usually comes from an aspect that provides other aspects with <xref:PostSharp.Aspects.IAspectProvider> and does not check the kind of its target.

## Resolution

Apply the instance-scoped aspect to the classes only:

* In an aspect provider, skip the interfaces: return no aspect instance when the target type is an interface.
* When you apply the aspect yourself, apply it to the classes that implement the interface. To reach all of them, apply to the interface an aspect with <xref:PostSharp.Extensibility.MulticastInheritance.Multicast> inheritance that provides the instance-scoped aspect to the classes.
