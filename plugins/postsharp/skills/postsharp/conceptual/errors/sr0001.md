# SR0001: PSerializable Applied to an Interface

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply [PSerializable] to type '<Type>' because it is an interface.` |

## Cause

[<xref:PostSharp.Serialization.PSerializableAttribute>] generates a serializer and a deserializing constructor for the type to which it is applied, and serializes the fields of this type. An interface has neither fields nor constructors, so only classes and structs can be serializable.

C# does not let you write `[PSerializable]` on an interface. The attribute reaches an interface when it is added programmatically, typically by an aspect that implements <xref:PostSharp.Aspects.IAspectProvider> and returns an <xref:PostSharp.Aspects.AspectInstance> of <xref:PostSharp.Serialization.PSerializableAttribute> for a set of types that includes an interface. PostSharp then reports SR0001 on the interface.

## Resolution

Exclude the interfaces from the types to which the aspect provider adds [<xref:PostSharp.Serialization.PSerializableAttribute>], for example with the <xref:System.Type.IsInterface> property, and add the attribute to the classes and structs that implement the interface.
