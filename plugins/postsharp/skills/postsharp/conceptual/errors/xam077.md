# XAM077: Execute Method of a Command Has an Invalid Signature

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Xaml |
| **Message** | `Error in the [Command] aspect applied to property <Property>: the signature of method <Method> is incorrect. The Execute method must be an instance method with the signature "void MyExecute()" or "void MyExecute(ParamType)".` |

## Cause

The <xref:PostSharp.Patterns.Xaml.CommandAttribute> aspect implements the <xref:System.Windows.Input.ICommand.Execute(System.Object)> method of the command by calling the `Execute` method of the class: the method that follows the naming conventions, such as `ExecuteSave` for a `SaveCommand` property, or the method named by the <xref:PostSharp.Patterns.Xaml.CommandAttribute.ExecuteMethod> property. The aspect reports XAM077 when this method:

* returns a value instead of `void`;
* is `static`;
* has more than one parameter.

The visibility of the method does not matter, and its single parameter, when it has one, can be of any type: it receives the command parameter.

PostSharp reports the message on the command property, not on the method. In the current version, `<Method>` shows the name of an internal type of the aspect, `PostSharp.Patterns.Xaml.CommandAttribute+ExecuteMethodWrapper`, instead of the name of the method.

## Resolution

Change the method to a `void` instance method with zero or one parameter. When the caller needs a result, expose it in a property of the view model, which the view can bind to. When the method needs several values, pass them in one object as the command parameter.
