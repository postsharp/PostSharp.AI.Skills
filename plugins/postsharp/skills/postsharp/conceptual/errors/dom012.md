# DOM012: Depends.On Called Too Far from the Property Getter

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Model |
| **Message** | `Depends.On cannot be called in method <Method>: call it in the getter of the property, or in a method that the getter calls directly.` |

## Cause

<xref:PostSharp.Patterns.Model.Depends.On*> declares the dependencies of a property for the <xref:PostSharp.Patterns.Model.NotifyPropertyChangedAttribute> aspect, which reads the call when it analyzes the getter at build time. The call has no effect at run time. It replaces the automatic analysis of the method that contains it, so it belongs in the getter of the property.

The aspect accepts the call in the getter and in a method that the getter calls directly. When it finds the call in a method that the getter reaches only through another method, it reports DOM012 on the property, not on the call. `<Method>` is the method that contains the call.

## Resolution

Move the call to <xref:PostSharp.Patterns.Model.Depends.On*> into the getter of the property. Because the call replaces the automatic analysis of the getter, including the methods that it calls, list all the dependencies of the property in the call.
