# PS0251: Property Element Contains Text in a Configuration File

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The element "<ParentElement>/<PropertyElement>" cannot contain text, because it sets the member "<PropertyElement>" of "<ParentElement>". Give an object value as a child element, give a simple value as an attribute of "<ParentElement>", and write notes as XML comments.` |

## Cause

Some sections of a `postsharp.config` file, such as the `Logging` element, describe objects in XML. In these sections, an element represents an object, its attributes set the simple properties of the object, and a child element named after a property sets a property whose value is an object or a collection. The value of this property element is the element, or the elements, that it contains. For example, the `Profiles` element of `Logging` contains `LoggingProfile` elements, and the `DefaultOptions` element of a `LoggingProfile` contains one `LoggingOptions` element.

A property element can contain elements, comments and white space, but not text. PostSharp reports PS0251 when it contains text, where `<ParentElement>` is the object element and `<PropertyElement>` is the property element. The text is often a note written without the `<!--` and `-->` of an XML comment, or a simple value, such as a number, written as the content of an element instead of as an attribute; in the latter case, PostSharp also reports <xref:ps0252?text=PS0252>, because the element contains no child element. The message is an error, but PostSharp goes on reading the file to report the other mistakes it finds.

## Resolution

* When the text is a note, make it an XML comment: `<!-- ... -->`.
* When the text is a simple value, such as `<ExecutionTimeThreshold>1000</ExecutionTimeThreshold>`, set it as an attribute of the parent element instead: `<LoggingProfile Name="Orders" ExecutionTimeThreshold="1000">`.
* When the text is left over from an edit, remove it.

<xref:configuration-schema> shows which properties are attributes and which are elements.
