# LA0004: Introduced Interface Already Implemented by the Target Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot introduce the interface <Interface> into the type <TargetType> because this type already implements it. To keep the existing implementation, set OverrideAction to Ignore.` |

## Cause

An aspect introduces an interface into its target type with <xref:PostSharp.Aspects.Advices.IntroduceInterfaceAttribute>, with an <xref:PostSharp.Aspects.Advices.IntroduceInterfaceAdviceInstance> returned by an advice provider, or as a <xref:PostSharp.Aspects.CompositionAspect>. When the target type already implements this interface, directly or through a base type, PostSharp follows the `OverrideAction` of the introduction. Its default value, <xref:PostSharp.Aspects.Advices.InterfaceOverrideAction.Fail>, reports LA0004 on the target type instead of replacing the existing implementation.

## Resolution

* Set the <xref:PostSharp.Aspects.Advices.IntroduceInterfaceAttribute.OverrideAction> property of the introduction to <xref:PostSharp.Aspects.Advices.InterfaceOverrideAction.Ignore>: the target type keeps its own implementation, and the aspect introduces the interface only into the types that do not implement it. A <xref:PostSharp.Aspects.CompositionAspect> sets its <xref:PostSharp.Aspects.CompositionAspect.OverrideAction> property in its constructor.
* Otherwise, remove the interface from the target type, or do not apply the aspect to this type.
