# DOM028: Method Assigns the Fields of a Structure Field One by One

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp.Patterns.Model |
| **Message** | `The method "<Method>" uses an indirect access to field "<Field>" of type "<FieldType>" which is a value type. Such changes may not be observable. Please consider assigning the structure as a whole instead of its individual fields.` |

## Cause

The <xref:PostSharp.Patterns.Model.NotifyPropertyChangedAttribute> aspect detects the changes of a field when the field is assigned. When a field holds a structure, a statement such as `this.location.X = x` changes the structure in place, through a reference to the field, without assigning the field: the aspect does not see the change and does not notify the properties that depend on the field.

PostSharp reports DOM028 on each method of the class that assigns a field of a structure held in a field of the class, in the form `this.field.member = value`. `<FieldType>` is the name of the structure type. The message is a warning: the build succeeds, but the change raises no notification.

The same code also makes PostSharp report the warning <xref:ps0089?text=PS0089>, because the aspect cannot intercept an access to the field by reference.
