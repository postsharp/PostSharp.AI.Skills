# DOM001: Property Getter Reads a Field the Aspect Cannot Track

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Model |
| **Message** | `NotifyPropertyChangedAttribute: automatic analysis of property <Property> failed. Method <Method> contains direct access to field <Field>. Only fields of the current instance, constants and read-only fields of immutable types can be analyzed. To solve this error, make the field read-only if its value never changes, or expose the value as a property of an object that implements INotifyPropertyChanged. To ignore the dependency to the field <Field>, add the [SafeForDependencyAnalysis] attribute to the property <Property>, or specify the dependencies of the property explicitly with Depends.On.` |

## Cause

The <xref:PostSharp.Patterns.Model.NotifyPropertyChangedAttribute> aspect analyzes the getter of each property at build time to find the fields and properties that its value depends on, so that it can raise the `PropertyChanged` event when one of them changes. The aspect detects the changes of the fields of the current instance only. It therefore reports DOM001 when the getter reads another field, because nothing would notify the property when that field changes:

* a static field that is not read-only, or a read-only static field of a mutable type;
* a field of another object, for example `this.customer.DiscountRate`, even when that object is of the same class.

Constants and read-only fields of immutable types, such as `int`, `string`, `decimal` or an enum, are accepted, because their value cannot change.

`<Method>` is the method that reads the field: the getter itself, or a method of the same class that the getter calls, which the aspect analyzes too. PostSharp reports the message on the property.

## Resolution

* When the value of the field never changes, make the field `readonly` or `const`, with an immutable type.
* When the value is held by another object, expose it as a property of a class that implements `INotifyPropertyChanged`, for example with the <xref:PostSharp.Patterns.Model.NotifyPropertyChangedAttribute> aspect, and read it in the canonical form `this.field.Property`. The aspect then subscribes to the changes of this object.
* When you know the dependencies of the property better than the aspect does, add the <xref:PostSharp.Patterns.Model.SafeForDependencyAnalysisAttribute> attribute to the property, and declare the dependencies that the aspect cannot find with <xref:PostSharp.Patterns.Model.Depends.On*>. The aspect then ignores the field, and does not notify the property when the field changes.
