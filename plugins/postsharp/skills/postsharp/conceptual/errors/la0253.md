# LA0253: Location-Level Aspect on an Extension Property

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The aspect "<Aspect>" cannot be applied to the extension property "<Property>" because an extension property has no implementation of its own. Use a method-level aspect, which is applied to the accessors of the property.` |

## Cause

The C# compiler implements a property of a C# 14 extension block as static accessor methods of the enclosing static class. The property that you declare in the extension block becomes a property of a compiler-generated metadata type, and this property has no implementation: its accessors only throw. An aspect that remains on this property, such as a <xref:PostSharp.Aspects.LocationInterceptionAspect>, therefore has nothing to intercept, and PostSharp reports LA0253 instead of applying it.

A method-level aspect, such as an <xref:PostSharp.Aspects.OnMethodBoundaryAspect>, does not remain on the property: PostSharp multicasts it to the implementations of the accessors, so it does not cause this message.

`<Property>` is the property of the metadata type, so its name contains the name of this compiler-generated type, which starts with `<G>$`.

PostSharp does not report LA0253, and skips the aspect without a message, when the <xref:PostSharp.Aspects.Aspect.UnsupportedTargetAction> property of the aspect is <xref:PostSharp.Aspects.UnsupportedTargetAction.Ignore>.

## Resolution

Derive the aspect from a method-level aspect class, such as <xref:PostSharp.Aspects.OnMethodBoundaryAspect> or <xref:PostSharp.Aspects.MethodInterceptionAspect>, and apply it to the extension property or to its accessors. PostSharp applies it to the static methods that implement the accessors. In the advices, the method is the accessor, for example `get_FullName`, not the property.
