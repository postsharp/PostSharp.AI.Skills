# LA0238: Awaited Task Bound in a Method That Is Not Async

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by <Binding>, but "<TargetMethod>" is not transformed as an async method, so it has no awaited task.` |

## Cause

In an <xref:PostSharp.Aspects.Advices.OnMethodYieldAdvice>, a parameter annotated with <xref:PostSharp.Aspects.Advices.AwaitedTaskAttribute> receives the task that the async method awaits, and a parameter annotated with <xref:PostSharp.Aspects.Advices.AwaitedMethodAttribute> receives the method that returned it. PostSharp records these values at each `await` expression when it transforms the state machine of an async method.

An iterator also has a state machine, and the yield advice runs at its `yield return` statements, but an iterator awaits nothing. When the yield advice is applied to a method that PostSharp does not transform as an async method, such as an iterator, there is no awaited task or method to pass, and PostSharp reports LA0238 on the target method. `<Binding>` is `[AwaitedTask]` or `[AwaitedMethod]`. The error is reported when PostSharp generates the code of the advice, so a <xref:PostSharp.Aspects.Advices.MatchPointcut> does not skip such a target.

## Resolution

* Apply the aspect only to async methods.
* Or, when the aspect must also handle iterators, move the `[AwaitedTask]` and `[AwaitedMethod]` parameters to an aspect that is applied only to async methods.
