# PS0105: Attribute on a Parameter of an Excluded Method

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply the custom attribute "<Attribute>" on parameter "<Parameter>" of method "<Method>": the attribute cannot be applied to the parameters of a <Reason>.` |

## Cause

The <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute.TargetMemberAttributes> property of the usage of an attribute class, or the <xref:PostSharp.Extensibility.MulticastAttribute.AttributeTargetMemberAttributes> property of an instance, filters the members that the attribute applies to by visibility, scope, virtuality and other attributes. For an attribute that targets parameters, the filter applies to the method that declares the parameter.

When the attribute is multicast, PostSharp skips the parameters of the methods that the filter excludes. When you apply the attribute directly to such a parameter, PostSharp reports PS0105 instead, because it cannot honor both the filter and your request. `<Reason>` names the attribute of the method that the filter excludes, for example `private member` or `static member`.

## Resolution

* Apply the attribute to a parameter of a method that the filter accepts, for example to the parameter of the public method that passes the value to the excluded method.
* When the attribute must apply to such methods too, widen the `TargetMemberAttributes` filter of the attribute class, or set <xref:PostSharp.Extensibility.MulticastAttribute.AttributeTargetMemberAttributes> on the instance.
* Otherwise, remove the attribute from the parameter.
