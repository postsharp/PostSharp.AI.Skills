# XAM058: Property Change Handler Has an Invalid Signature

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Xaml |
| **Message** | `Error in the [<Aspect>] aspect applied to property <Property>: the change handling method <Method> does not have a correct signature. Correct signatures are: "void MyPropertyChangedHandler(DependencyProperty property, <DeclaringType> instance)" for static methods and "void MyPropertyChangedHandler(DependencyProperty property)" for instance methods. Parameters "property" and "instance" are optional and may be omitted in the method signature.` |

## Cause

The <xref:PostSharp.Patterns.Xaml.DependencyPropertyAttribute> and <xref:PostSharp.Patterns.Xaml.AttachedPropertyAttribute> aspects call a change handler method after the value of the property changes. They find the method by its name: `On` followed by the name of the property and `Changed`, or the name that you set in the <xref:PostSharp.Patterns.Xaml.DependencyPropertyBaseAttribute.PropertyChangedMethod> property of the aspect. PostSharp reports XAM058 when the parameters of this method do not match one of the supported signatures:

* A static method takes no parameter, the <xref:System.Windows.DependencyProperty>, the instance, or the <xref:System.Windows.DependencyProperty> followed by the instance. The instance parameter is of the type that declares the property, <xref:System.Windows.DependencyObject> or `object`.
* An instance method takes no parameter, or the <xref:System.Windows.DependencyProperty>.
* No parameter can be `out`.

The handler does not receive the old or the new value: it reads the property instead. `<DeclaringType>` is the short name of the class. The current version of the message shows the name of the property without its type, such as `Quantity`. PostSharp reports the message on the property.

## Resolution

Change the parameters of the change handler to one of the supported signatures, and read the new value from the property. When the method has the name of the convention but is not meant to handle the changes of the property, rename it, or set <xref:PostSharp.Patterns.Xaml.DependencyPropertyBaseAttribute.PropertyChangedMethod> to the name of another method.
