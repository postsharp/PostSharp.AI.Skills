# PS0253: Configuration Object Has the Wrong Type for Its Property

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The type <ObjectType> cannot be converted to <MemberType>.` |

## Cause

Some sections of `postsharp.config`, such as the logging profiles of the `Logging` section, describe CLR objects in XML, as <xref:configuration-serialization> explains. A child element named after a property or a field sets it to the object that its own child element describes. The name and the XML namespace of that inner element give the type of the object.

PostSharp reports PS0253 when this type, `<ObjectType>`, cannot be assigned to the type of the property or the field, `<MemberType>`. The location of the message is the element of the property in `postsharp.config`.

## Resolution

* Use an element of the type of the property, or of a type derived from it. For the `DefaultOptions` and `ExceptionOptions` of a logging profile, this is a `LoggingOptions` element.
* Check the XML namespace of the element: an `xmlns` attribute on the element, or on one of its parents, decides in which CLR namespace and assembly PostSharp looks for the type.
* Set run-time options, such as the options of a logging backend, in the code of the application. See <xref:logging-customizing>.
