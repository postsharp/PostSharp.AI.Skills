# LA0101: Pointcut Method Not Found

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot find the method "<Method>" named by the MethodPointcut of the advice "<Advice>": type "<AspectType>" has no instance method of this name that takes one parameter of type Object or of the reflection type of the aspect target, and returns IEnumerable<T> of Object or of the reflection type of the advice targets.` |

## Cause

A <xref:PostSharp.Aspects.Advices.MethodPointcut> selects the targets of an advice with a method of the aspect class, which it names. PostSharp looks in the aspect class for a method with this name and the following signature:

* It is an instance method, not a static one.
* Its only parameter is of type <xref:System.Object> or of the reflection type of the declarations to which the aspect applies, such as <xref:System.Type> for a <xref:PostSharp.Aspects.TypeLevelAspect>.
* It returns an <xref:System.Collections.Generic.IEnumerable`1> exactly, not an array or a list, of <xref:System.Object> or of the reflection type of the declarations to which the advice applies, such as <xref:System.Reflection.MethodInfo> or <xref:System.Reflection.MethodBase> for an <xref:PostSharp.Aspects.Advices.OnMethodEntryAdvice>.

When no method matches, PostSharp reports LA0101 on the advice method. PostSharp then also reports <xref:la0049?text=LA0049>, which says that the advice has no pointcut: it ignores the pointcut that it could not resolve. Fixing LA0101 removes <xref:la0049?text=LA0049> too.
