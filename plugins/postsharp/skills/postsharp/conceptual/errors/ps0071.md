# PS0071: Attribute Applied to a Kind of Declaration It Does Not Support

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply the custom attribute "<Attribute>" to the <Kind> "<Declaration>": the attribute cannot be applied to this kind of declaration. Valid targets are: <ValidTargets>.` |

## Cause

The <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute.ValidOn> property of the <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute> of an aspect class lists the kinds of declarations that the aspect can apply to, as <xref:PostSharp.Extensibility.MulticastTargets> flags. It is often narrower than the <xref:System.AttributeUsageAttribute> of C#, which the base aspect classes of PostSharp set broadly so that you can apply an aspect to a container, such as a class, and multicast it to its members.

When you apply the aspect directly to a declaration that is neither in <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute.ValidOn> nor a container of such declarations, the C# compiler accepts the attribute, but PostSharp reports PS0071. For example, an aspect valid on properties only can be applied to a class, which multicasts it to the properties of the class, but not to a field.

`<Kind>` is the kind of the declaration, such as `field`, `method` or `class`, and `<ValidTargets>` lists the targets that the aspect allows.

## Resolution

* Apply the aspect to a declaration that `<ValidTargets>` lists, for example turn the field into a property, or apply the aspect to a container of such declarations.
* When the aspect is designed to work on this kind of declaration, add it to the <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute.ValidOn> property of the `[MulticastAttributeUsage]` of the aspect class. The base class of the aspect must allow it too, or PostSharp reports <xref:ps0072?text=PS0072>.
