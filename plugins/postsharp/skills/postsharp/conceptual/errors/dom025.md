# DOM025: Property Depends on a Variable Assigned in a Try Statement

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Model |
| **Message** | `NotifyPropertyChangedAttribute: automatic analysis of property <Property> failed. Method <Method> depends on a variable that is assigned inside a try statement. This is not currently supported. To ignore this message, add the [SafeForDependencyAnalysis] attribute to the property <Property>, and call Depends.On to specify its dependencies explicitly.` |

## Cause

The <xref:PostSharp.Patterns.Model.NotifyPropertyChangedAttribute> aspect analyzes the getter of each property, and the methods of the same class that it calls, to find what the property depends on. When the code reads a local variable, the analysis follows the assignments of this variable. It does not support an assignment that is inside a `try` statement, in the `try` block or in one of its `catch` or `finally` blocks.

PostSharp reports DOM025 on `<Property>` when `<Method>`, the getter or a method that it calls, reads a local variable that is assigned inside a `try` statement.

## Resolution

* Remove the `try` statement from the getter and from the methods that it calls, for example by testing that a divisor is not zero instead of catching the exception.
* Otherwise, add <xref:PostSharp.Patterns.Model.SafeForDependencyAnalysisAttribute> to the property, and call <xref:PostSharp.Patterns.Model.Depends.On*> in its getter with the properties that it depends on. The attribute makes you responsible for the dependencies that the analysis does not find.
