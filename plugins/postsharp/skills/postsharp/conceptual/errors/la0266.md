# LA0266: Overloaded Method Imported as IMethodBinding

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [ImportMember] to an IMethodBinding, but the type "<TargetType>" has several methods named "<MethodName>": <Methods>. IMethodBinding selects a method by its name only. Import the method as a delegate, whose signature selects the overload.` |

## Cause

A parameter of type <xref:PostSharp.Aspects.IMethodBinding> annotated with <xref:PostSharp.Aspects.Advices.ImportMemberAttribute> imports a method of the target type by its name. <xref:PostSharp.Aspects.IMethodBinding> has no signature that could select one overload, so the name must designate a single method. When the target type, or one of its base types, has several methods of this name that are not generic and do not return by reference, PostSharp reports LA0266. An override does not count as a separate method.

PostSharp reports LA0266 whether or not <xref:PostSharp.Aspects.Advices.ImportMemberAttribute.IsRequired> is `true`, on each target of the advice. `<Methods>` lists the overloads.

## Resolution

* Import the method as a delegate. The delegate type selects the overload, as when C# converts a method group to a delegate: for an instance method, its first parameter receives the object, and the other parameters receive the arguments. Make the advice generic, with a `[This]` parameter of the type parameter, when the delegate type must name the target type.
* Rename one of the overloads in the target type.
