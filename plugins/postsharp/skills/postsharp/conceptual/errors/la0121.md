# LA0121: No ValidateValue Method for the Type of the Location

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Location "<Location>" is of type "<LocationType>", which cannot be matched to any ValidateValue method of aspect "<AspectType>".` |

## Cause

A validation aspect checks the value of a parameter, a return value, a property or a field with a `ValidateValue` method. An aspect has one `ValidateValue` method for each <xref:PostSharp.Aspects.ILocationValidationAspect`1> interface that it implements, or one for each method that has the <xref:PostSharp.Aspects.Advices.LocationValidationAdvice> attribute. PostSharp chooses the method whose value parameter accepts the type of the location.

PostSharp reports LA0121 when no method accepts it. `<LocationType>` is the type of the location `<Location>`. For the return value of an `async` method, it is the type of the result of the task, and PostSharp also reports LA0121 for the return value of a `void` method, which has no value to validate.

## Resolution

* Implement <xref:PostSharp.Aspects.ILocationValidationAspect`1> for the type of the location, or add a `ValidateValue` advice method for this type.
* Otherwise, remove the aspect from the location, or use an aspect made for this type.
