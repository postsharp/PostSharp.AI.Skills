# PS0252: Configuration Element Needs Exactly One Child Element

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The element <ParentElement>/<MemberElement> must have exactly one child element.` |

## Cause

Some sections of `postsharp.config`, such as the logging profiles of the `Logging` section, describe CLR objects in XML, as <xref:configuration-serialization> explains. An XML attribute sets a property or a field of a simple type. A child element named after a property or a field sets it to an object: this member element must contain exactly one element, which describes the object.

PostSharp reports PS0252 when a member element whose property or field is not a collection contains no element, or several. `<ParentElement>` is the element of the object, and `<MemberElement>` the element of the property. The location of the message is the member element in `postsharp.config`.

## Resolution

* When the member element contains several elements, merge them into one: set all the properties of the object as attributes of the same element.
* When the member element is empty, add the element of the object, for example `<LoggingOptions />` under `DefaultOptions`, or remove the member element to keep the default value of the property.
