# PS0079: Undefined Task in a Configuration File

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The task "<Task>" is not defined. Check the name of the element, or add the plug-in that defines the task.` |

## Cause

The PostSharp compiler runs a pipeline of tasks, which PostSharp and its plug-ins define. A configuration file, such as `postsharp.config` or a `.psproj` file, can add or configure tasks with a `Tasks` section, in which the name of each element is the name of a task. PostSharp reports PS0079 when the name of an element, `<Task>`, matches no task of the loaded plug-ins: the name is misspelled, or the plug-in that defines the task is not loaded. The message points to the element in the configuration file.

PS0079 is also reported, without a location, when a plug-in adds a task to the project programmatically under a name that no plug-in defines.

PostSharp then cannot set up the project and also reports <xref:ps0084?text=PS0084>.

## Resolution

* When the task is not needed, remove its element from the configuration file. Most projects need no `Tasks` section: the aspects and the packages of PostSharp add the tasks they need.
* When the name is misspelled, correct it.
* When the task comes from a plug-in, make sure that the project references the package of the plug-in, or that a `Using` element of the configuration file loads it.
