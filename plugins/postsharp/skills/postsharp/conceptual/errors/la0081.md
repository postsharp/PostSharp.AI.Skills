# LA0081: Imported Property Has Another Type Than the Field

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot bind field "<Field>" to property "<Property>": the type of the property differs from the TValue type argument of the field.` |

## Cause

An aspect imports a property of its target class with a field of type <xref:PostSharp.Aspects.Advices.Property`1> or <xref:PostSharp.Aspects.Advices.Property`2> annotated with <xref:PostSharp.Aspects.Advices.ImportMemberAttribute>. PostSharp binds the `Get` and `Set` delegates of the field to the accessors of the property, and the `TValue` type argument of the field must be exactly the type of the property. A type to which the property is assignable, such as `object` for a `string` property, is not accepted.

PostSharp reports LA0081 when it finds the property but its type differs. `<Property>` is the name of the property, without its type. PostSharp reports the error on the target type, not on the field of the aspect.
