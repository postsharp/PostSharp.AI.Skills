# LA0042: Aspects Initialized from a Static Method

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot call AspectUtilities.InitializeCurrentAspects from the static method "<Method>": this call initializes the aspects of the current instance, so it must be made from an instance method.` |

## Cause

The constructors of a class enhanced by aspects initialize the aspects of each new object. When an object is created without a constructor, for example by a custom deserializer that calls <xref:System.Runtime.CompilerServices.RuntimeHelpers.GetUninitializedObject(System.Type)>, you initialize its aspects yourself by calling <xref:PostSharp.Aspects.AspectUtilities.InitializeCurrentAspects>. PostSharp replaces this call, at build time, with a call to the `InitializeAspects` method of the current object, `this`.

A static method has no current object, so PostSharp reports LA0042 when the call is in a static method, including a static factory method that creates the object. `<Method>` is the static method that contains the call. The message is reported on the line of the call.
