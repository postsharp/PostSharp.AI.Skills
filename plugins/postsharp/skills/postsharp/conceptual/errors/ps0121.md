# PS0121: Object Construction Names an Unknown Property or Field

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot find in the type "<AspectType>" a property or field named "<Name>" specified in the ObjectConstruction object.` |

## Cause

An <xref:PostSharp.Aspects.IAspectProvider> can describe the aspect that it provides with an <xref:PostSharp.Reflection.ObjectConstruction> instead of an instance. PostSharp then builds a custom attribute of type `<AspectType>` from this description, and sets each entry of <xref:PostSharp.Reflection.ObjectConstruction.NamedArguments> as a property or a field of the attribute. The names are not checked when you create the <xref:PostSharp.Reflection.ObjectConstruction>, so a misspelled name shows up only at build time.

PostSharp reports PS0121 when a name `<Name>` is neither a property nor a field of the aspect class. The message has no location. PostSharp then reports <xref:la0117?text=LA0117>, which names the aspect provider and the target of the aspect, and skips the aspect.

## Resolution

Use only the names of properties or fields of the aspect class as keys of <xref:PostSharp.Reflection.ObjectConstruction.NamedArguments>. To get the name checked by the C# compiler, write it with the `nameof` operator, for example `nameof(LogAttribute.Category)`.
