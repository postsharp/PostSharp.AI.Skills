# LA0080: Imported Property Not Found in the Target Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot bind field "<Field>" to type "<TargetType>": cannot find a property named "<PropertyName>"<Index> in type "<TargetType>" or its ancestors.` |

## Cause

An aspect imports a property of its target class with a field of type <xref:PostSharp.Aspects.Advices.Property`1> or <xref:PostSharp.Aspects.Advices.Property`2> annotated with <xref:PostSharp.Aspects.Advices.ImportMemberAttribute>. PostSharp looks for a property with the name given to the attribute in the target type and in its base types; for a <xref:PostSharp.Aspects.Advices.Property`2> field, the property must be an indexer with one parameter of the `TIndex` type. When the <xref:PostSharp.Aspects.Advices.ImportMemberAttribute.IsRequired> property is `true`, PostSharp reports LA0080 for each target type where it finds no such property. When <xref:PostSharp.Aspects.Advices.ImportMemberAttribute.IsRequired> is `false`, which is the default, the field stays `null` instead.

The property is not found in the following cases:

* No property has this name, for example because of a typo.
* The property is a `private` property of a base class.
* The field is a <xref:PostSharp.Aspects.Advices.Property`2>, but the property is not an indexer, or its parameter has another type.

`<PropertyName>` lists the names given to the attribute. `<Index>` describes the index parameter for a <xref:PostSharp.Aspects.Advices.Property`2> field, and is empty otherwise. PostSharp reports the error on the target type, not on the field of the aspect.

## Resolution

* Correct the name given to <xref:PostSharp.Aspects.Advices.ImportMemberAttribute>, or pass several names when the property can have one of several names.
* Make the property of the base class accessible to the target class, for example `protected` instead of `private`.
* When the aspect can work without the property, set <xref:PostSharp.Aspects.Advices.ImportMemberAttribute.IsRequired> to `false` and check that the field is not `null` before using it.
