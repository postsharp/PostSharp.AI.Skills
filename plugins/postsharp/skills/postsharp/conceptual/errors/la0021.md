# LA0021: Aspect Serializer Not Derived from AspectSerializer

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The type "<SerializerType>" cannot be used as the serializer of the aspect "<Aspect>" because it is not derived from the PostSharp.Aspects.Serialization.AspectSerializer class.` |

## Cause

PostSharp serializes the aspect instances at build time and deserializes them at run time, as <xref:aspect-serialization> describes. By default, it chooses the serializer from the aspect class: <xref:PostSharp.Aspects.Serialization.PortableAspectSerializer> for a class annotated with <xref:PostSharp.Serialization.PSerializableAttribute>. You can choose another serializer with the `SerializerType` property of an aspect configuration attribute, such as <xref:PostSharp.Aspects.Configuration.AspectConfigurationAttribute.SerializerType> or the one of <xref:PostSharp.Aspects.Configuration.OnMethodBoundaryAspectConfigurationAttribute>, or with the <xref:PostSharp.Aspects.Aspect.SerializerType> property of the aspect.

PostSharp creates an instance of this type and calls its methods, so the type must be derived from <xref:PostSharp.Aspects.Serialization.AspectSerializer>. PostSharp reports LA0021 when it is not, for example when the serializer class has `Serialize` and `Deserialize` methods but no base class. `<SerializerType>` is the configured type, and `<Aspect>` the aspect class.

PostSharp does not stop after reporting LA0021. When the type has a public parameterless constructor, the build then fails with an unhandled exception (<xref:ps0099?text=PS0099>) because PostSharp cannot convert the instance to <xref:PostSharp.Aspects.Serialization.AspectSerializer>; otherwise, it also reports <xref:la0022?text=LA0022> and <xref:la0001?text=LA0001>. This is why no example can show this message alone.

## Resolution

* Derive the serializer from <xref:PostSharp.Aspects.Serialization.AspectSerializer>, override its `Serialize` and `Deserialize` methods, and give it a public parameterless constructor.
* Unless the aspect needs a serializer of its own, remove the `SerializerType` property and annotate the aspect class with <xref:PostSharp.Serialization.PSerializableAttribute>.
* To build the aspect at run time instead of serializing it, set `SerializerType` to <xref:PostSharp.Aspects.Serialization.MsilAspectSerializer>.
