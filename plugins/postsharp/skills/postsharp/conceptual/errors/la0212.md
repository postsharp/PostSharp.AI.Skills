# LA0212: Bound Advice Parameter Must Be Out or Ref

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" must be passed by reference (out or ref) because it is bound by <Binding>.` |

## Cause

Each binding attribute accepts some parameter modes in each kind of advice. A parameter annotated with <xref:PostSharp.Aspects.Advices.ReturnValueAttribute> must be `out` or `ref` in the following advices, because the return value does not exist yet when they run, and the advice can only set it:

* <xref:PostSharp.Aspects.Advices.OnMethodEntryAdvice> and <xref:PostSharp.Aspects.Advices.OnMethodExceptionAdvice>, where the parameter sets the value that the method returns when the advice sets the flow behavior to <xref:PostSharp.Aspects.FlowBehavior.Return?text=FlowBehavior.Return>.
* <xref:PostSharp.Aspects.Advices.OnMethodInvokeAdvice>, where the advice assigns the value that the intercepted method returns.

When the parameter is passed by value or as `in`, PostSharp reports LA0212 on the parameter. `<Binding>` is the binding attribute as you write it, `[ReturnValue]`. For the other modes and advices, see [Reading and setting the return value](xref:advice-parameter-binding#reading-and-setting-the-return-value).

## Resolution

Declare the parameter as `out`, or as `ref` when the advice also reads the value that another advice set. To read the return value of the method, use the `[ReturnValue]` parameter of an <xref:PostSharp.Aspects.Advices.OnMethodSuccessAdvice> or an <xref:PostSharp.Aspects.Advices.OnMethodExitAdvice> instead.
