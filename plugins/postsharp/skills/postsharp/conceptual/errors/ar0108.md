# AR0108: Protected Declaration Used Outside of Derived Types

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp |
| **Message** | `Cannot use <ReferencedKind> <ReferencedDeclaration> in <ReferencingKind> <ReferencingDeclaration> because the [Protected] constraint restricts it to the type that declares it and to the types derived from that type.` |

## Cause

The <xref:PostSharp.Constraints.ProtectedAttribute> constraint restricts a declaration that must be `public` or `internal` for technical reasons to the type that declares it and to the types derived from it, as the `protected` keyword would. PostSharp reports AR0108 on each method or type that uses the declaration from a type that does not derive from the top-level type that declares it: it calls the method or constructor, reads the field, or uses the type in a signature. Nested types of the declaring type have access.

`<ReferencingDeclaration>` is the declaration that holds the reference, and the message is reported at its location, not at the line of the reference.

AR0108 is a warning by default. Its severity comes from the <xref:PostSharp.Constraints.ProtectedAttribute.Severity> property of the constraint, which you can set to <xref:PostSharp.Extensibility.SeverityType.Error>.

## Resolution

* Go through a member of the declaring type that is not restricted, instead of using the declaration directly.
* When the referencing type is a specialization of the declaring type, derive it from the declaring type.
* When the reference is an exception that you accept, suppress the warning on the referencing declaration with <xref:PostSharp.Extensibility.SuppressWarningAttribute>. This does not work when the severity of the constraint is <xref:PostSharp.Extensibility.SeverityType.Error>.
