# THR023: Dispatched Method Is Static

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Threading |
| **Message** | `Method <Method> cannot be enhanced with the [Dispatched] aspect because it is a static method.` |

## Cause

The <xref:PostSharp.Patterns.Threading.DispatchedAttribute> aspect executes a method in the thread of the object, typically the UI thread. The aspect takes the dispatcher of the object: the object implements <xref:PostSharp.Patterns.Threading.IDispatcherObject>, as UI controls do, or captures the synchronization context of the thread that creates it. A static method has no object, so the aspect cannot know in which thread to execute it.

PostSharp reports THR023 when the aspect is applied to a static method, in any execution mode.

## Resolution

* Make the method an instance method of the object that belongs to the UI, such as a view or a control, and call it on an instance.
* When the method must remain static, remove the aspect and dispatch the call yourself, for example with the `Post` or `Send` method of the `SynchronizationContext` of the UI thread.
