# DOM027: AggregateAllChanges Applied to a Property That Is Not a Collection

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Model |
| **Message** | `The [AggregateAllChanges] attribute cannot be applied to the property <Property> because its type does not implement the ICollection or ICollection<T> interface.` |

## Cause

By default, the <xref:PostSharp.Patterns.Model.NotifyPropertyChangedAttribute> aspect notifies a property that depends on a collection only when the collection itself is replaced. The <xref:PostSharp.Patterns.Model.AggregateAllChangesAttribute> attribute, on the property that holds the collection, makes the aspect also notify the dependent properties when the content of the collection changes.

The attribute supports only collections: PostSharp reports DOM027 when the type of the property implements neither <xref:System.Collections.ICollection> nor <xref:System.Collections.Generic.ICollection`1>.

## Resolution

* When the property holds an object that notifies its changes, remove the attribute. The aspect already tracks the dependencies in the form `this.ShippingAddress.City`.
* When the property holds a collection, give the property a type that implements <xref:System.Collections.Generic.ICollection`1>, such as `ObservableCollection<T>`, instead of an interface such as `IEnumerable<T>`.
