# LA0069: Statically Scoped Aspect Cannot Introduce an Interface

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot introduce an interface from the aspect "<Aspect>" applied to "<Target>" because the aspect is statically scoped. Derive the aspect from InstanceLevelAspect or implement IInstanceScopedAspect, and do not apply it to a static member.` |

## Cause

The target type of an interface introduction implements the interface by delegating each of its members to the aspect instance, so each object of the target type needs its own aspect instance. Such an aspect is instance-scoped: it implements <xref:PostSharp.Aspects.IInstanceScopedAspect>, as <xref:PostSharp.Aspects.InstanceLevelAspect> does, and is applied to a type or to a non-static member.

An aspect that does not implement <xref:PostSharp.Aspects.IInstanceScopedAspect>, such as a <xref:PostSharp.Aspects.TypeLevelAspect>, is statically scoped: it has a single instance for its whole target. When such an aspect introduces an interface with <xref:PostSharp.Aspects.Advices.IntroduceInterfaceAttribute> or an <xref:PostSharp.Aspects.Advices.IntroduceInterfaceAdviceInstance>, PostSharp reports LA0069. An instance-scoped aspect applied to a static member is statically scoped too.

`<Target>` is the declaration to which the aspect is applied: the target type, or the member whose declaring type receives the interface.

## Resolution

* Derive the aspect from <xref:PostSharp.Aspects.InstanceLevelAspect> instead of <xref:PostSharp.Aspects.TypeLevelAspect>.
* When the aspect must derive from another class, implement <xref:PostSharp.Aspects.IInstanceScopedAspect>.
* Do not apply the aspect to a static member.
