# LA0104: Pointcut Returns a Parameter That Cannot Be Found

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Error while evaluating the MethodPointcut "<PointcutMethod>" on "<AspectTarget>": cannot find a parameter of "<DeclaringType>.<Member>". The pointcut method must return parameters of methods of the current assembly, not parameters of indexers.` |

## Cause

A <xref:PostSharp.Aspects.Advices.MethodPointcut> selects the targets of an advice with a method of the aspect class. PostSharp runs this method at build time and maps each <xref:System.Reflection.ParameterInfo> that it returns to a parameter of a method of the project. PostSharp reports LA0104 on the pointcut method, and skips the parameter, when it cannot do so:

* The parameter belongs to an indexer, because the pointcut method got it from <xref:System.Reflection.PropertyInfo.GetIndexParameters*?displayProperty=nameWithType>. The <xref:System.Reflection.ParameterInfo.Member> of such a parameter is a property, not a method.
* PostSharp cannot find the method that declares the parameter in the current assembly.

`<DeclaringType>.<Member>` is the member that declares the parameter, for instance `PriceList.Item` for an indexer, and not the parameter itself.

## Resolution

Return the parameters of methods only. To select the parameters of an indexer, return the parameters of its accessors, such as `get_Item`: the methods of the type returned by <xref:System.Type.GetMethods*?displayProperty=nameWithType> already include them.
