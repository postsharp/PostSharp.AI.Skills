# COM004: Relationship Attribute Applied to a String, Delegate or Value Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Common |
| **Message** | `Cannot apply the [<Attribute>] attribute to "<Member>" because its type is a string, a delegate, or a value type.` |

## Cause

The <xref:PostSharp.Patterns.Model.AggregatableAttribute> aspect tracks relationships between objects. A string, a delegate, a primitive type, an enum or another value type holds a value, not an object of the graph, so it can be neither a child, nor a reference, nor a parent. PostSharp reports COM004 when a field or an automatic property of such a type has a <xref:PostSharp.Patterns.Model.ChildAttribute>, <xref:PostSharp.Patterns.Model.ReferenceAttribute> or <xref:PostSharp.Patterns.Model.ParentAttribute> attribute.

A value type can take part in a relationship only when it implements <xref:PostSharp.Patterns.Model.IAttachable> or when a type adapter registered for it allows it, for example for an `ImmutableArray<T>` of objects.
