# DIA004: Logging Profile Not Found

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Diagnostics |
| **Message** | `Cannot find a logging profile named '<ProfileName>'. Define this profile in the Logging element of a postsharp.config file, or use the name of an existing profile, such as Default or Exceptions.` |

## Cause

A logging profile gives the build-time options of the logging aspects: the levels, and what the records include. An aspect selects a profile by name, with the constructor of <xref:PostSharp.Patterns.Diagnostics.LogAttribute> or the <xref:PostSharp.Patterns.Diagnostics.LogAttributeBase.ProfileName> property. When it gives no name, the aspect uses the `Default` profile.

PostSharp defines the `Default`, `Exceptions` and `Audit` profiles, and adds the profiles of the `Logging` element of the `postsharp.config` files of the project. Names are not case-sensitive. When the name of the aspect matches none of these profiles, PostSharp reports DIA004 on the method to which the aspect is applied. This happens when the name is misspelled, or when the `postsharp.config` file that defines the profile is not one that the project reads, for example because it is in a sibling directory instead of the directory of the project or one of its parents.

* Correct the name of the profile in the aspect.
* Define the profile in the `Logging` element of a `postsharp.config` file in the directory of the project or in one of its parents, as <xref:logging-customizing> describes.
