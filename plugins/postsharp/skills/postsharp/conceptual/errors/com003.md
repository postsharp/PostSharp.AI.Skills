# COM003: Relationship Attribute Applied to a Non-Automatic Property

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Common |
| **Message** | `Cannot apply the [<Attribute>] attribute to the "<Property>" property because it is not an automatic property. Apply it instead to the backing field.` |

## Cause

The <xref:PostSharp.Patterns.Model.AggregatableAttribute> aspect tracks the parent/child relationships of an object through the fields that store them. On an automatic property, PostSharp finds the field that the compiler generates. On a property with its own `get` or `set` accessor, PostSharp cannot tell which field the property reads or writes, if any, so it reports COM003 when the property has a <xref:PostSharp.Patterns.Model.ChildAttribute>, <xref:PostSharp.Patterns.Model.ReferenceAttribute> or <xref:PostSharp.Patterns.Model.ParentAttribute> attribute.
