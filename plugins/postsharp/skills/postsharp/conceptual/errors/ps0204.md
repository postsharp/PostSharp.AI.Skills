# PS0204: Invalid Property Name in Configuration File

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Invalid property name "<PropertyName>": the name of a property must start with a letter and contain only letters and digits.` |

## Cause

The `Property` element of a `postsharp.config` file defines a property of the project, which other elements read in expressions such as `{$LoggingEnabled}`. See <xref:configuration-schema#property>. Because expressions refer to properties by name, the name of a property must start with a letter and contain only letters and digits. A hyphen, a dot, an underscore or a space makes it invalid. Spaces before and after the name are ignored.

PostSharp reports PS0204 on the `Property` element, and ignores the property. Since the error occurs while PostSharp loads the configuration of the project, it also reports <xref:ps0084?text=PS0084> and stops the build.
