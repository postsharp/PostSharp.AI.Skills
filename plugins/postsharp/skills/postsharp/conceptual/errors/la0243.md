# LA0243: Return Value Set Both by Reference and on MethodExecutionArgs

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp |
| **Message** | `The advice "<Advice>" has both a MethodExecutionArgs parameter and the [ReturnValue] parameter "<Parameter>", passed as out or ref. The value of the [ReturnValue] parameter is used, and MethodExecutionArgs.ReturnValue is ignored.` |

## Cause

In a method boundary advice, a [<xref:PostSharp.Aspects.Advices.ReturnValueAttribute>] parameter passed as `out` or `ref` is the variable that holds the return value of the method: the value that the advice writes to it is the value that the method returns. When the advice also has a <xref:PostSharp.Aspects.MethodExecutionArgs> parameter, the woven code does not copy <xref:PostSharp.Aspects.MethodExecutionArgs.ReturnValue> over this variable, so a value that the advice assigns to <xref:PostSharp.Aspects.MethodExecutionArgs.ReturnValue> has no effect.

PostSharp reports LA0243 for the `<Parameter>` parameter when the advice `<Advice>` is an <xref:PostSharp.Aspects.Advices.OnMethodEntryAdvice>, <xref:PostSharp.Aspects.Advices.OnMethodSuccessAdvice>, <xref:PostSharp.Aspects.Advices.OnMethodExceptionAdvice> or <xref:PostSharp.Aspects.Advices.OnMethodExitAdvice> with both parameters. The build continues, and the value of the parameter wins.

## Resolution

Set the return value in one place:

* Assign the value to the `out` or `ref` [<xref:PostSharp.Aspects.Advices.ReturnValueAttribute>] parameter, and remove the <xref:PostSharp.Aspects.MethodExecutionArgs> parameter. Bound parameters such as [<xref:PostSharp.Aspects.Advices.DeclarationAttribute>] or [<xref:PostSharp.Aspects.Advices.DeclarationNameAttribute>] give the other values that the advice reads from <xref:PostSharp.Aspects.MethodExecutionArgs>.
* Or pass the [<xref:PostSharp.Aspects.Advices.ReturnValueAttribute>] parameter by value, so that it only reads the return value, and assign the new value to <xref:PostSharp.Aspects.MethodExecutionArgs.ReturnValue>.
