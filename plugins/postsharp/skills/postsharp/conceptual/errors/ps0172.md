# PS0172: Strict Inheritance Requested on a Property or Event

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot use inheritance of attribute '<AttributeType>' on <DeclarationKind> '<Declaration>': strict attribute inheritance is not supported on properties and events.` |

## Cause

Aspect inheritance makes PostSharp apply an aspect to the declarations that derive from the one where you apply it, as <xref:aspect-inheritance> describes. With <xref:PostSharp.Extensibility.MulticastInheritance.Strict> inheritance, an aspect on a method also applies to the methods that override or implement it. PostSharp does not support this on properties and events.

PostSharp reports PS0172 when you apply an attribute to a property or an event and set its <xref:PostSharp.Extensibility.MulticastAttribute.AttributeInheritance> property to <xref:PostSharp.Extensibility.MulticastInheritance.Strict>. `<DeclarationKind>` is `property` or `event`. PostSharp then stops processing the multicast attributes and also reports <xref:ps0055?text=PS0055>. When the <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute> of the attribute class requests strict inheritance instead, PostSharp reports <xref:ps0171?text=PS0171>.

## Resolution

* Apply the aspect to each overriding or implementing property or event too.
* Or apply the aspect to the base class with <xref:PostSharp.Extensibility.MulticastInheritance.Multicast> inheritance: PostSharp copies the aspect to each derived class, then multicasts it to the members of the derived class.
