# LA0255: Redundant Group Property of an Advice

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp |
| **Message** | `The <Property> property of the advice "<Advice>" is redundant: without it, the advice is in the same group. Remove the <Property> property.` |

## Cause

PostSharp groups the advices of each class of an aspect separately. An advice without pointcut and without the <xref:PostSharp.Aspects.Advices.GroupingAdvice.Group> property joins the group of its class that has no advice of its kind yet, or starts a group that applies to the target of the aspect. The <xref:PostSharp.Aspects.Advices.GroupingAdvice.Group> property selects a group by name, which is needed only when this inference gives another group or cannot choose one.

PostSharp reports LA0255 when the groups of the class would be the same without the <xref:PostSharp.Aspects.Advices.GroupingAdvice.Group> property of the advice. `<Property>` is always `Group`. When several advices are reported, each property is redundant together with the ones reported before it, so you can remove all of them.

A class of the aspect can join a group of another class by its name. PostSharp does not report a <xref:PostSharp.Aspects.Advices.GroupingAdvice.Group> property when a base class of the aspect, or a class of the same project derived from the class of the advice, selects the same group name.
