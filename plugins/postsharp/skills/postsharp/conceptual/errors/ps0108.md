# PS0108: Inheritance of the Attribute Set by Its Class

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot set the property <Property> of the multicast attribute [<AttributeType>] on "<Declaration>": the [MulticastAttributeUsage] of the attribute class sets Inheritance, and an instance cannot override it.` |

## Cause

The <xref:PostSharp.Extensibility.MulticastAttribute.AttributeInheritance> property of a multicast attribute determines whether the attribute is inherited by derived classes, overriding methods and implementations of interfaces. When the class of the attribute does not decide, each instance can set it. When the `[MulticastAttributeUsage]` of the attribute class sets <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute.Inheritance>, the aspect developer has decided for every usage, and PostSharp reports PS0108 when an instance applied in your code sets <xref:PostSharp.Extensibility.MulticastAttribute.AttributeInheritance> to another value. Setting it to the same value is allowed.

`<Property>` is always `AttributeInheritance`. Because the attribute is invalid, PostSharp also stops with <xref:ps0055?text=PS0055>.

## Resolution

* Remove <xref:PostSharp.Extensibility.MulticastAttribute.AttributeInheritance> from the attribute, and apply the attribute to the derived declarations that need it.
* When the attribute class is yours and its usages must choose, remove <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute.Inheritance> from its `[MulticastAttributeUsage]`.
