# PS0072: MulticastAttributeUsage More Permissive Than the Base Class

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `On type "<Type>", [MulticastAttributeUsage] cannot be more permissive than the information inherited from base classes (property <Property>).` |

## Cause

An attribute class inherits the <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute> of its base classes, and its own `[MulticastAttributeUsage]` can only restrict it: a base aspect class relies on the restrictions that it declares, for example on the kinds of declarations that its advices can handle. PostSharp combines the usages from the root base class down to the attribute class, and reports PS0072 when a class allows something that a base class forbids. `<Property>` names the property of <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute> at fault:

* <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute.ValidOn>: the class adds targets that a base class does not allow.
* <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute.AllowMultiple> or <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute.AllowExternalAssemblies>: the class sets the property to `true` when a base class sets it to `false`.
* <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute.TargetMemberAttributes>, <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute.TargetTypeAttributes>, <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute.TargetParameterAttributes>, or their `TargetExternal...` counterparts: the class allows visibilities or other attributes that a base class excludes.

`<Type>` is usually the class whose `[MulticastAttributeUsage]` is too permissive. Because PostSharp cannot know where the attribute applies, it also stops with <xref:ps0055?text=PS0055>.

## Resolution

* When the base class is yours, and its advices support what the derived class needs, make the `[MulticastAttributeUsage]` of the base class allow it.
* Otherwise, remove the property from the `[MulticastAttributeUsage]` of the derived class, or restrict it to what the base class allows. A base aspect class of PostSharp also declares a usage: for example, <xref:PostSharp.Aspects.OnMethodBoundaryAspect> is valid on methods and constructors only.
