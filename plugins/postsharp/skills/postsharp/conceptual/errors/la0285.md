# LA0285: Required Match Pointcut Applies to No Method

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The advice "<Advice>" has a MatchPointcut with IsRequired = true, but it applies to no method of "<TargetType>": no method is named "<MethodName>", or no method with this name has a signature that matches the parameters of the advice.` |

## Cause

A <xref:PostSharp.Aspects.Advices.MatchPointcut> selects the methods of the target type that have a given name, and skips silently the methods whose signature does not match the parameters of the advice. When <xref:PostSharp.Aspects.Advices.MatchPointcut.IsRequired> is `true`, PostSharp reports LA0285 for each aspect instance whose advice applies to no method of `<TargetType>`:

* no method that `<TargetType>` declares is named `<MethodName>`, for instance after the method is renamed. Inherited methods are not selected;
* or no method with this name matches the advice: an argument is missing or has an incompatible type, or, when <xref:PostSharp.Aspects.Advices.MatchPointcut.MatchParameterCount> is `true`, the number of parameters differs.

PostSharp reports the error on the target type.

## Resolution

* Use the name of the method that the target type declares in the pointcut, or rename the method back.
* Change the parameters of the advice so that they match the signature of the method.
* When the target type may legitimately lack the method, set <xref:PostSharp.Aspects.Advices.MatchPointcut.IsRequired> to `false`, which is the default value, or do not apply the aspect to this type.
