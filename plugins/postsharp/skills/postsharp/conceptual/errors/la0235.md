# LA0235: Argument Passed by Reference in an Interception Advice

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by <Binding> and passed as out or ref, but a value that an interception advice writes to it does not reach the intercepted method. Change the argument through the Arguments object passed to the binding, or pass the parameter by value or as in.` |

## Cause

In a method boundary advice, an <xref:PostSharp.Aspects.Advices.ArgumentAttribute> parameter passed as `out` or `ref` changes the argument that the method body sees. In an <xref:PostSharp.Aspects.Advices.OnMethodInvokeAdvice>, it does not: the advice calls the intercepted method through <xref:PostSharp.Aspects.IMethodBinding.Invoke*>, which passes the arguments of the <xref:PostSharp.Aspects.Arguments> object, not the parameter of the advice. PostSharp reports LA0235 on each `out` or `ref` `[Argument]` parameter of an interception advice.

`<Binding>` is the attribute as written, such as `[Argument(0)]`.
