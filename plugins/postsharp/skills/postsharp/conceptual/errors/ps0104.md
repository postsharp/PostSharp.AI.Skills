# PS0104: Multicast Attribute Targets Parameters of an External Method

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply the multicast attribute "<Attribute>" to the parameters or the return value of the method "<Method>" because the method is located outside the current assembly.` |

## Cause

With the <xref:PostSharp.Extensibility.MulticastAttribute.AttributeTargetAssemblies> property, you can multicast an attribute to the declarations of a referenced assembly, when the <xref:PostSharp.Extensibility.MulticastAttributeUsageAttribute.AllowExternalAssemblies> property of its usage allows it. PostSharp then processes the methods of the referenced assembly that the current assembly uses. It cannot add an attribute to the parameters or the return value of such a method, because they belong to the other assembly, which PostSharp does not modify. PostSharp reports PS0104 for each external method that the attribute reaches when the attribute targets parameters (<xref:PostSharp.Extensibility.MulticastTargets.Parameter>) or return values (<xref:PostSharp.Extensibility.MulticastTargets.ReturnValue>).

`<Attribute>` is the attribute class, and `<Method>` the external method. The location of the message is the method in the source of the other assembly, when PostSharp can find it.

## Resolution

* Multicast the attribute to the parameters of the methods of the current assembly, for example to the methods that call the external method, by removing <xref:PostSharp.Extensibility.MulticastAttribute.AttributeTargetAssemblies>.
* When you own the other assembly, apply the attribute in that assembly.
* Narrow <xref:PostSharp.Extensibility.MulticastAttribute.AttributeTargetElements> so that the attribute does not target parameters or return values in the external assembly.
