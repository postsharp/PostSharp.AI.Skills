# LA0065: Unsupported Aspect Dependency Custom Attribute

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot find a parser for the aspect dependency custom attribute "<AttributeType>" used on "<Declaration>". Use a dependency custom attribute of PostSharp, such as [AspectTypeDependency] or [AspectRoleDependency], instead of a class derived from AspectDependencyAttribute.` |

## Cause

Aspect dependencies order aspects and advices, and declare requirements and conflicts between them. You express them with custom attributes derived from <xref:PostSharp.Aspects.Dependencies.AspectDependencyAttribute>. Although this class is public and abstract, PostSharp processes only the derived classes that it knows: <xref:PostSharp.Aspects.Dependencies.AspectTypeDependencyAttribute>, <xref:PostSharp.Aspects.Dependencies.AspectRoleDependencyAttribute>, <xref:PostSharp.Aspects.Dependencies.AspectEffectDependencyAttribute>, <xref:PostSharp.Aspects.Dependencies.AdviceDependencyAttribute> and <xref:PostSharp.Aspects.Dependencies.ProvideAspectRoleAttribute>. When a dependency custom attribute of another class is applied to an aspect class, an advice method or the assembly, or is added to the configuration of an aspect instance, PostSharp cannot read it and reports LA0065.

`<AttributeType>` is the class of the custom attribute, and `<Declaration>` is the aspect class or the advice method that carries it.

## Resolution

Express the dependency with a custom attribute of PostSharp:

* <xref:PostSharp.Aspects.Dependencies.AspectTypeDependencyAttribute> relates the aspect to another aspect class.
* <xref:PostSharp.Aspects.Dependencies.AspectRoleDependencyAttribute> relates it to the aspects that play a role, such as <xref:PostSharp.Aspects.Dependencies.StandardRoles.Validation>.
* <xref:PostSharp.Aspects.Dependencies.AspectEffectDependencyAttribute> relates it to the aspects that have an effect.
* <xref:PostSharp.Aspects.Dependencies.AdviceDependencyAttribute> orders the advices of the same aspect.

These classes are sealed, so you cannot derive a custom attribute of your own from them.
