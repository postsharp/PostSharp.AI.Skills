# CAC013: Cache Aspect on an Unsupported Async Method

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Caching |
| **Message** | `Cannot add the [Cache] aspect to the <Method> method because it is an async iterator, or an async method that does not return Task<T>, such as ValueTask<T>, which the asynchronous advice does not support. To cache the result of an async method, make it return Task<T>. Otherwise, set the UnsupportedTargetAction property of [Cache] to Ignore to skip the method, or to Fallback to cache the object that the method returns, if this object can be consumed several times.` |

## Cause

The <xref:PostSharp.Patterns.Caching.CacheAttribute> aspect caches the result of an async method only when the method returns <xref:System.Threading.Tasks.Task`1>. It does not support the following methods:

* an async method, declared with the `async` keyword, that returns another type, such as <xref:System.Threading.Tasks.ValueTask`1>;
* an async iterator, which returns <xref:System.Collections.Generic.IAsyncEnumerable`1> or <xref:System.Collections.Generic.IAsyncEnumerator`1> and contains `await` and `yield return`.

For such a method, the synchronous advice could only cache the object that the method returns, and a <xref:System.Threading.Tasks.ValueTask`1> may be awaited only once. PostSharp therefore reports CAC013 when the <xref:PostSharp.Patterns.Caching.CacheAttribute.UnsupportedTargetAction> property of the aspect has its default value, <xref:PostSharp.Aspects.UnsupportedTargetAction.Default>.

A method that returns a <xref:System.Threading.Tasks.ValueTask`1> or an <xref:System.Collections.Generic.IAsyncEnumerable`1> without the `async` keyword is not affected: the aspect caches the object that it returns.

## Resolution

* Make the method return <xref:System.Threading.Tasks.Task`1>, so that the aspect caches its result.
* To leave the method without caching, set the <xref:PostSharp.Patterns.Caching.CacheAttribute.UnsupportedTargetAction> property of the aspect to <xref:PostSharp.Aspects.UnsupportedTargetAction.Ignore>: the calls to the method then proceed without the cache.
* To cache the object that the method returns, set it to <xref:PostSharp.Aspects.UnsupportedTargetAction.Fallback>. Do this only when this object can be consumed several times, which is not the case of most <xref:System.Threading.Tasks.ValueTask`1> objects.
