# PS0127: License Does Not Cover a Required Package

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `<Text>` |

## Cause

PostSharp checks that the licenses of the build, the license keys and the license servers that the project and the machine register, cover each part of PostSharp that the project uses. When a license requirement is not satisfied, the licensing services of PostSharp compose a message, `<Text>`, which says what is required and names the products that cover it, and PostSharp reports it under PS0127, without a location. The licensing services also decide whether it is an error or a warning; it is usually an error.

PostSharp reports PS0127 in the following situations:

* The project uses premium features, such as the pattern libraries or some aspect features, on more lines of code than PostSharp Essentials, the free edition, allows. PostSharp reports PS0127 once for each premium package that the project used without a license, and then <xref:ps0243?text=PS0243> with the number of lines of code.
* The license of the build does not include the free edition. When PostSharp finds no license at all, it reports <xref:ps0242?text=PS0242> instead.
* The project uses a compiler extension written outside PostSharp, which requires the Framework package, and no license covers it. PostSharp then also reports <xref:ps0278?text=PS0278>, which names the extension.

This message depends on the license of the build, so no example can show it.

## Resolution

* Read `<Text>`: it names the products whose license covers what the project requires. Register a license key of one of them, as <xref:deploying-keys> describes.
* When you expected your license to cover the project, check that PostSharp uses it: an invalid, expired or revoked key is reported earlier in the build, by <xref:ps0301?text=PS0301> or <xref:ps0304?text=PS0304>. Capture the licensing trace with the `PostSharpTrace=Licensing` MSBuild property, as <xref:license-troubleshooting> describes, to see which licenses PostSharp found.
* When the project exceeds the free limit, reduce the use of premium features, as <xref:ps0243?text=PS0243> explains. <xref:express-limitations> lists the free and premium features.
