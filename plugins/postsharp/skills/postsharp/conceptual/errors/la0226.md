# LA0226: Argument Name Not Found

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [Argument("<Name>")], but "<TargetMethod>" has no parameter named "<Name>".` |

## Cause

The <xref:PostSharp.Aspects.Advices.ArgumentAttribute.%23ctor(System.String)> constructor binds a parameter of an advice to the argument of the target method that has a given name. PostSharp looks for the name in each target method of the advice, with a case-sensitive comparison. When a target method has no parameter of this name, it reports LA0226 on that method.

When the advice uses a pointcut that skips the targets whose signature does not match, such as <xref:PostSharp.Aspects.Advices.MatchPointcut>, PostSharp skips the target instead of reporting the error.

## Resolution

* Rename the parameter of the target method, or the name given to the <xref:PostSharp.Aspects.Advices.ArgumentAttribute>, so that they match, including the case.
* Select the argument by its index or by its type when the target methods do not name it in the same way.
* Otherwise, apply the aspect only to methods that have a parameter of this name.
