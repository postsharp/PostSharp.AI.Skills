# LA0037: Composition Aspect Introduces a Type That Is Not an Interface

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot compose the type "<Type>" into the type "<TargetType>" because "<Type>" is not an interface.` |

## Cause

A <xref:PostSharp.Aspects.CompositionAspect> makes its target class implement interfaces, and delegates their members to an implementation object that its <xref:PostSharp.Aspects.CompositionAspect.CreateImplementationObject*> method creates. The types that the aspect introduces are the ones that its <xref:PostSharp.Aspects.CompositionAspect.GetPublicInterfaces*> method returns. A class can implement interfaces but cannot inherit from a second class, so each of these types must be an interface. PostSharp reports LA0037 for the first one that is not.

`<Type>` is the type returned by the aspect, and `<TargetType>` is the class to which the aspect is applied. The mistake usually comes from returning the class of the implementation object instead of the interface it implements.
