# COM008: Child Collection Is Not an Advisable Collection

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp.Patterns.Threading, PostSharp.Patterns.Model |
| **Message** | `The type of the child field or property "<Member>" is not supported. A child collection must be an AdvisableCollection<T>, an AdvisableDictionary<TKey, TValue> or an AdvisableHashSet<T>. The field or property can also have an interface type, as long as it is assigned to one of these collections at run time.` |

## Cause

A threading model such as <xref:PostSharp.Patterns.Threading.FreezableAttribute> or <xref:PostSharp.Patterns.Threading.ReaderWriterSynchronizedAttribute>, and the `[Recordable]` aspect, propagate their behavior to the children of an object: the fields and properties marked with <xref:PostSharp.Patterns.Model.ChildAttribute>. For a child collection, PostSharp adds this behavior to the collection object at run time, which only the advisable collections of the `PostSharp.Patterns.Collections` namespace allow. The standard collections, `List<T>`, `Collection<T>`, `ObservableCollection<T>`, `Dictionary<TKey, TValue>` and `HashSet<T>`, cannot be enhanced, so PostSharp reports COM008 when a child field or property has one of these types.

## Resolution

* Change the type of the field or property to the advisable collection that matches the standard one: <xref:PostSharp.Patterns.Collections.AdvisableCollection`1> instead of `List<T>`, `Collection<T>` or `ObservableCollection<T>`, <xref:PostSharp.Patterns.Collections.AdvisableDictionary`2> instead of `Dictionary<TKey, TValue>`, and <xref:PostSharp.Patterns.Collections.AdvisableHashSet`1> instead of `HashSet<T>`.
* Otherwise, give the field or property an interface type, such as `IList<T>`, and assign it an advisable collection.
