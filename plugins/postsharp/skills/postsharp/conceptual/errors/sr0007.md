# SR0007: Serializer of the Base Type Has Not Been Generated

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply [PSerializable] to type '<Type>' because the serializer of its base type has not been generated, although the base type is [PSerializable]. Make sure that PostSharp processes the project that defines the base type.` |

## Cause

[<xref:PostSharp.Serialization.PSerializableAttribute>] generates a serializer for `<Type>` that extends the serializer of its base type. When the base type is [<xref:PostSharp.Serialization.PSerializableAttribute>], PostSharp generates the serializer of the base type when it builds the assembly that defines the base type, as a nested class named `Serializer`.

PostSharp reports SR0007 when the base type has the [<xref:PostSharp.Serialization.PSerializableAttribute>] attribute but no serializer. This happens when the base type is in another assembly that was built without PostSharp: the project of this assembly references the `PostSharp.Redist` package, which contains [<xref:PostSharp.Serialization.PSerializableAttribute>], but not the `PostSharp` package, which contains the compiler, or it sets the `SkipPostSharp` MSBuild property to `True`.

## Resolution

Build the project that defines the base type with PostSharp: add a reference to the `PostSharp` package, and remove the `SkipPostSharp` property if the project sets it. See <xref:postsharp-components> and <xref:msbuild-properties>.
