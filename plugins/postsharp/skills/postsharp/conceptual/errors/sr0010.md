# SR0010: Serializer of the Base Type Has No Default Constructor

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply [PSerializable] to a type derived from '<BaseType>' because the serializer '<Serializer>' of '<BaseType>' does not have a default constructor.` |

## Cause

When a [<xref:PostSharp.Serialization.PSerializableAttribute>] class derives from a class whose serializer is written by hand, the serializer that PostSharp generates for the derived class derives from the serializer of the base class. The constructor of the generated serializer has no parameter, and calls the constructor of the base serializer that has no parameter either.

PostSharp reports SR0010 on `<BaseType>` when its serializer `<Serializer>` has no parameterless constructor, for example because its only constructor takes an option. A parameterless constructor that exists but cannot be accessed from the generated serializer is reported with <xref:sr0011?text=SR0011> instead.
