# PS0255: Configuration Cannot Set or Read a Property

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot <Operation> the value of <Member>: <Reason>` |

## Cause

Some sections of `postsharp.config`, such as the logging profiles of the `Logging` section, describe CLR objects in XML, as <xref:configuration-serialization> explains. PostSharp creates the objects during the build and sets their properties and fields with reflection: an XML attribute or a child element sets the member of the same name, and the items of a collection are added to the collection that the property returns.

PostSharp reports PS0255 when setting or reading the member throws an exception. `<Operation>` is `set` or `get`, `<Member>` is the property or the field, and `<Reason>` is the message of the exception. The most common cause is a read-only property, whose setter does not exist. A setter can also reject the value. The location of the message is the XML attribute or element in `postsharp.config`.

## Resolution

* Remove the attribute or the element that sets a read-only property. Check in the API reference which properties of the type can be set.
* When the setter rejects the value, change the value: `<Reason>` says what is wrong.
* Set run-time options, such as the logging backend, in the code of the application. See <xref:logging-customizing>.
