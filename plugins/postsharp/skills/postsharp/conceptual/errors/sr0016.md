# SR0016: PSerializable Type Already Has a Nested Serializer Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Cannot apply [PSerializable] to type '<Type>' because it already contains a nested type named 'Serializer'.` |

## Cause

[<xref:PostSharp.Serialization.PSerializableAttribute>] generates the serializer of a type as a nested class named `Serializer`. PostSharp reports SR0016, on the `[PSerializable]` type, when this type already contains a nested type of this name, whatever its kind and visibility.
