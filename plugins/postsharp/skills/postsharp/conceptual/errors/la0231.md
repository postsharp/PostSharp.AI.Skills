# LA0231: Group Property Set Twice in One Group

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The advices <Advices> are in one group and set <Property> to different values, but <Property> applies to the whole group. Set it on one advice of the group only.` |

## Cause

Some properties of the advices apply to the whole group of advices: the pointcut, <xref:PostSharp.Aspects.Advices.Advice.Description>, <xref:PostSharp.Aspects.Advices.OnMethodBoundaryAdvice.SemanticallyAdvisedMethodKinds> and <xref:PostSharp.Aspects.Advices.OnMethodBoundaryAdvice.UnsupportedTargetAction>. A group has one value of each, so you can set them on any advice of the group, but on one advice only.

PostSharp reports LA0231 on each advice of the conflict when two advices of one group set one of these properties to different values. The same value on several advices is accepted. When two advices of one group have a pointcut, PostSharp reports <xref:la0259?text=LA0259> instead.

`<Advices>` lists the advices that set the property, and `<Property>` names it.

## Resolution

Set the property on one advice of the group only, with a value that fits the whole group, or set the same value on each advice. When the advices must have different values, put them in different groups with the <xref:PostSharp.Aspects.Advices.GroupingAdvice.Group> property or with pointcuts.
