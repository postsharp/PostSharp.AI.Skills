# LA0265: Required Method Not Found for IMethodBinding

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [ImportMember] with IsRequired set to true, but the type "<TargetType>" has no accessible method named "<MemberName>" that is not generic and does not return by reference.` |

## Cause

A parameter of type <xref:PostSharp.Aspects.IMethodBinding> annotated with <xref:PostSharp.Aspects.Advices.ImportMemberAttribute> receives an object that calls a method of the target type, selected by its name. The candidates are the methods of the target type and the accessible methods of its base types. PostSharp excludes the generic methods, whose type arguments an <xref:PostSharp.Aspects.IMethodBinding> cannot supply, and the methods that return by reference.

When no method remains, the parameter normally receives `null`. When <xref:PostSharp.Aspects.Advices.ImportMemberAttribute.IsRequired> is `true`, PostSharp reports LA0265 instead, for each target of the advice. A field or a property of the name does not count: <xref:PostSharp.Aspects.IMethodBinding> imports methods only.

The message is reported on the target of the advice, and `<MemberName>` lists the names given to the attribute.

## Resolution

* Define a method of the expected name in the target type, or correct the name given to the attribute.
* To import a field or a property, use a parameter of the type of the member or of type <xref:PostSharp.Aspects.ILocationBinding`1> instead of <xref:PostSharp.Aspects.IMethodBinding>.
* When the advice can work without the method, set <xref:PostSharp.Aspects.Advices.ImportMemberAttribute.IsRequired> to `false`, which is the default, and handle a `null` binding.
