# LA0227: No Argument of the Bound Type

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `The parameter "<Parameter>" of the advice "<Advice>" is bound by [Argument] to an argument of its type, but "<TargetMethod>" has no parameter whose type can be assigned to "<ParameterType>" without conversion, except boxing, or has exactly this type when the advice parameter is passed by reference.` |

## Cause

The constructor of <xref:PostSharp.Aspects.Advices.ArgumentAttribute> without parameters binds a parameter of an advice to the argument of the target method whose type matches the type of the advice parameter. An argument matches when:

* the advice parameter is passed by value, and the type of the argument can be assigned to `<ParameterType>` without conversion, except boxing. For instance, an <xref:System.Object> parameter matches an argument of any type, but a `long` parameter does not match an `int` argument;
* the advice parameter is passed by reference, with `in`, `ref` or `out`, and the argument has exactly its type;
* the advice parameter is of a type parameter of the advice, which matches any argument.

When no argument of a target method matches, PostSharp reports LA0227 on that method. When several arguments match, PostSharp reports <xref:la0228?text=LA0228>, unless the <xref:PostSharp.Aspects.Advices.ArgumentAttribute.AmbiguityResolution> property selects one of them. When the advice uses a pointcut that skips the targets whose signature does not match, such as <xref:PostSharp.Aspects.Advices.MatchPointcut>, PostSharp skips the target instead of reporting the error.

## Resolution

* Add a parameter of the expected type to the target method.
* Change the type of the advice parameter to a type that the argument can be assigned to, or pass the parameter by value to accept boxing.
* Otherwise, apply the aspect only to methods that have an argument of this type, or use <xref:PostSharp.Aspects.Advices.MatchPointcut> in a type-level aspect to skip the other methods.
