# LA0184: Advice Applied to a Virtual Method of Another Assembly

| | |
|---|---|
| **Severity** | Warning |
| **Reported by** | PostSharp |
| **Message** | `Applying the advice "<Advice>" to virtual external method "<Method>" may lead to unexpected behavior. Applying OnMethodEntryAdvice, OnMethodSuccessAdvice, OnMethodExitAdvice, OnMethodExceptionAdvice, and OnMethodInvokeAdvice on external virtual methods is not fully supported.` |

## Cause

When you multicast an aspect to a method of another assembly with <xref:PostSharp.Extensibility.MulticastAttribute.AttributeTargetAssemblies>, PostSharp cannot modify the method itself. Instead, it advises the calls that the current project makes to the method. When the method is virtual, such a call can reach an override, but the advice still runs for the method of the base type: the advice describes a method that is not the one that executes, and an override that is itself advised can run the advice twice.

PostSharp reports LA0184 for each advice of an aspect built from advices, <xref:PostSharp.Aspects.Advices.OnMethodEntryAdvice>, <xref:PostSharp.Aspects.Advices.OnMethodSuccessAdvice>, <xref:PostSharp.Aspects.Advices.OnMethodExitAdvice>, <xref:PostSharp.Aspects.Advices.OnMethodExceptionAdvice> or <xref:PostSharp.Aspects.Advices.OnMethodInvokeAdvice>, that is applied to a virtual or abstract method of another assembly. The warning is reported on the advice method of the aspect, `<Advice>`. Aspects derived from <xref:PostSharp.Aspects.OnMethodBoundaryAspect>, <xref:PostSharp.Aspects.OnExceptionAspect> or <xref:PostSharp.Aspects.MethodInterceptionAspect> report <xref:la0183?text=LA0183> in the same situation.

## Resolution

* Apply the aspect to the methods of the current project that call the external method, rather than to the external method itself.
* When you own the library, apply the aspect in the library, so that PostSharp modifies the virtual method and its overrides directly.
* Exclude the virtual methods from the multicast with <xref:PostSharp.Extensibility.MulticastAttribute.AttributeTargetMemberAttributes> set to <xref:PostSharp.Extensibility.MulticastAttributes.NonVirtual>.
