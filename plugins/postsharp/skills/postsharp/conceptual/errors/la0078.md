# LA0078: Imported Member Field Is Static

| | |
|---|---|
| **Severity** | Error |
| **Reported by** | PostSharp |
| **Message** | `Field "<Field>" cannot be annotated by [ImportMember] because it is static.` |

## Cause

An aspect imports a member of its target class with a field annotated with <xref:PostSharp.Aspects.Advices.ImportMemberAttribute>. PostSharp assigns this field in each instance of the aspect, with delegates bound to the target object of this instance. A static field is shared by all the instances of the aspect, so it cannot hold the member of each target object, and PostSharp reports LA0078.
